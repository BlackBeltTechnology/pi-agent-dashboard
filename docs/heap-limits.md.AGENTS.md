# heap-limits.md — index

V8 heap reference. Config keys `sessionHeap` (`maxOldSpaceMb` 512, `initialOldSpaceMb`, `maxSemiSpaceMb`) + `serverHeap` (`maxOldSpaceMb` 1536, replaced hardcoded 8192). Floor 64 MB; invalid → `loadConfig` default, never throws; no `0` sentinel. DISTINCT from `memoryLimits` (event store). Transport argv, not `NODE_OPTIONS` (allow-list rejects `--initial-old-space-size`; env leaks to every Node grandchild; tmux panes never see spawn env). Per-mechanism: headless/wt argv, tmux/wsl-tmux `-e NODE_OPTIONS`, last-resort fallback logged `[heap]` + `/api/health` `sessionHeapFallback`, forbidden on headless. Strip gated on `PI_DASHBOARD_HEAP_FLAG` marker. Effect boundary: session = next spawn (reload counts), server = cold start only. `heap_size_limit` carries ~192 MB V8 overhead. Telemetry fields + the two non-comparable percentage bases (84% vs crash point, ~69% vs `heapSizeLimit`). Subagent coupling formula `maxOldSpaceMb/(n+1)`. See change: bound-session-heap-and-gc-telemetry.
