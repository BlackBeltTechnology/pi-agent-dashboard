# plugin-seams.md — index

Plugin authoring guide. 3 seams: `ctx.credentials` store (`~/.pi/agent/plugin-credentials.json` 0600, namespace=manifest id, caps 64 KiB/256 keys/2 MiB); `ctx.oauth.startFlow({key,loginFlow,persist})` served by `/api/provider-auth/flow/:flowId` + `createLoopbackCallback`; bridge→server request lane (`requestPluginServer`/`registerPiRequestHandler`, 256 KiB, 15 s). Trust boundary + fixture gate (`PI_DASHBOARD_FIXTURE_PLUGINS=1`). `editor-pane-tab` slot (`pathPrefix` regex, reserved `diff|term|url|live`, `openPluginTabRoute`/`openPluginTab`, `ctx.openEditorTab` own-prefix + `editor_tab_open`); `pluginMeta` prompt metadata (≤2048 bytes → `metadata.plugin` → `params._pluginMeta`). Lazy claim `module` (`PluginClaim.module`, `lazyClaim` in `lazy-claim.tsx`, generator emits `lazyClaim(() => import(...))`; eager predicate/shouldRender/labelComponent; `does not export`/renderChunk build fails; first-party adoption list). `editor-pane-file-handler` slot (claim fields; `FileHandlerProps` snapshot/save/setDirty; keep-alive cap 3; `setDirty("unknown")` never evicted); `POST /api/file/write-binary` (query `cwd,path,mode,expectSha1,claim`; 200/409/403/422/503); `ctx.registerFileValidator` (worker pool 2 workers, queue 8, 5 s terminate, fail-closed). `ctx.serveApp` (trusted only; `dir` in package or `ctx.dataDir`; `.gz` negotiation; `crossOriginFrame`; per-request csp fn); `ctx.dataDir` (0700). Consumer: `craft-web-plugin` → `craft-web-plugin.md`.
