# plugin-seams.md — index

Plugin authoring guide. 3 seams: `ctx.credentials` store (`~/.pi/agent/plugin-credentials.json` 0600, namespace=manifest id, caps 64 KiB/256 keys/2 MiB); `ctx.oauth.startFlow({key,loginFlow,persist})` served by `/api/provider-auth/flow/:flowId` + `createLoopbackCallback`; bridge→server request lane (`requestPluginServer`/`registerPiRequestHandler`, 256 KiB, 15 s). Trust boundary + fixture gate (`PI_DASHBOARD_FIXTURE_PLUGINS=1`). `editor-pane-tab` slot (`pathPrefix` regex, reserved `diff|term|url|live`, `openPluginTabRoute`/`openPluginTab`, `ctx.openEditorTab` own-prefix + `editor_tab_open`); `pluginMeta` prompt metadata (≤2048 bytes → `metadata.plugin` → `params._pluginMeta`). See change: expose-plugin-credential-and-oauth-seams, add-browser-editor-pane-tab, add-skill-atlas-screen.
