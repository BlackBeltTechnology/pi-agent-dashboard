# identity-auth-plugin-guide.md — index

Build a dashboard AUTH plugin on the identity plane. Three-way split (D18): core = seam only, `keycloak-resolver` = token validation only, YOUR plugin = login UI (separate-view kind) +/or authorization policy. Trust via `identity.trustedResolverPlugins` + `identity.trustedPolicyPlugin` (never `manifest.priority`); enforcement = resolver active AND login descriptor registered, latched at startup; disarm-not-fail. Login plugin: drop-in `~/.pi/dashboard/plugins/`, `ctx.fastify` pages outside `/api/ /v1/ /editor/ /live/`, `ctx.registerBrowserLoginConfig({loginUrl, logoutUrl, tokenUrl, postLogoutUrl, label, endsProviderSession, silentSignIn})`, sanitized same-origin paths, D22 handoff `#pi_handoff` ≤60 s → `POST tokenUrl {code,verifier}` → `{access_token,expires_in}`, bearer in memory only, no cookies. Custom resolver: `PrincipalResolverFn` three-valued outcome (claim/`null`/`reject`→401), curated `AuthContext`, fail-closed. Authorization: session roads = exact `(iss,sub)` owner equality, core-enforced, deny=404, NOT policy-controllable; host policy `HostAccessPolicyFn` non-session only, action constants `workspace|openspec|branch|terminal|system.read/write|domain.event`, default 500 ms, false/throw/timeout/non-boolean ⇒ deny+audit; product authz (roles) in YOUR plugin, read `request.principal`. NOT YET IMPLEMENTED: `ctx.identity`, `plugin:<id>:<action>`, `GET /api/identity/me`, full core non-session classification, host-policy road wiring (tasks 18.14/18.27/18.28), `pi-dashboard login --local` (18.23/18.24). Break-glass `local-operator`; never a localhost bypass. Tests: `tests/e2e/identity-matrix/`, `packages/fixture-policy-plugin/`, `spike/identity-login-plane/`.
