# identity-auth-plugin-guide.md — index

Build a dashboard AUTH plugin on the identity plane. Three-way split (D18): core = seam only, `keycloak-resolver` = token validation only, YOUR plugin = login UI (separate-view kind) +/or authorization policy. Trust via `identity.trustedResolverPlugins` + `identity.trustedPolicyPlugin` (never `manifest.priority`); enforcement = resolver active AND login descriptor registered, latched at startup; disarm-not-fail. Login plugin: drop-in `~/.pi/dashboard/plugins/`, `ctx.fastify` pages outside `/api/ /v1/ /editor/ /live/`, `ctx.registerBrowserLoginConfig({loginUrl, logoutUrl, tokenUrl, postLogoutUrl, label, endsProviderSession, silentSignIn})`, sanitized same-origin paths, D22 handoff `#pi_handoff` ≤60 s → `POST tokenUrl {code,verifier}` → `{access_token,expires_in}`, bearer in memory only, no cookies. Custom resolver: `PrincipalResolverFn` three-valued outcome (claim/`null`/`reject`→401), curated `AuthContext`, fail-closed. Authorization: session roads = exact `(iss,sub)` owner equality, deny=404, NOT policy-controllable, decided centrally by `preHandler` `identity/identity-road-gate.ts`. Host policy `HostAccessPolicyFn` non-session only, decided per Fastify route PATTERN (`identity/http-road-classification.ts`) / WS type (`identity/ws-road-classification.ts`); roads identity/session/session-handler/non-session/unclassified; actions `<family>.read|write` (families workspace/openspec/branch/terminal/files/config/providers/plugins/packages/access/gateway/system) + `terminal.create`; plugin routes `plugin:<id>:read|write` via `identity/route-owner-registry.ts`, resource `{kind,route|ws,pluginId?}`; unclassified ⇒ 403+`unclassified` audit; inert plane ⇒ no-op; default 500 ms, false/throw/timeout/non-boolean ⇒ deny+audit. `GET /api/identity/me` → `{enforced,principal,localOperator,can}` advisory. Product authz (roles) in YOUR plugin, read `request.principal`. NOT YET IMPLEMENTED: `ctx.identity`, cross-plugin action namespacing, bootstrap-disclosure gating, domain-event fan-out wiring, `/editor/`+`/live/` classification, non-auditing probe mode (tasks 18.27/18.37), `pi-dashboard login --local` (18.23/18.24). Break-glass `local-operator`; never a localhost bypass. Tests: `tests/e2e/identity-matrix/`, `packages/fixture-policy-plugin/`, `spike/identity-login-plane/`.
