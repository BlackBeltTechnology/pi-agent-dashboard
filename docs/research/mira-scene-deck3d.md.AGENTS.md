Research dossier. Mira-Scene (arXiv 2609.23796, VAST-AI-Research + HKU, v2 2026-09-22) = single-image → editable 3D scene: per-object meshes + layout + floor + equirect environment panorama. Canonical Coordinate Map (CCM) + scene Point Cloud Map (PCM) → robust geometric pose alignment; replaces sparse unbounded pose regression. Claim vs SAM3D +39.8% 3D-IoU / +16.5% 2D-IoU (0.727/0.520, 0.783/0.672). Fits deck3d `packages/deck3d` prop pipeline (`props generate` Hunyuan precedent; prop contract = self-contained GLB, no external uri, 8 MiB cap, sha256, base64). BLOCKER = compute: Linux + NVIDIA + CUDA only, per-stage conda envs, ≥32 GB VRAM (SAM3D), host macOS arm64 → no local run. Licence null → internal decks only. Gaps: no `props import` command, no optimizer (>8 MiB scenes), `licence: "generated"` hides provenance, no equirect/skybox in `src/runtime/scene.ts`. Options: A standalone skill + import, B `--backend mira-scene`, C + env backdrop; compute rent vs owned GPU. Next = spike (1 case, 1 rented A100, 4 measurements). Explore-mode output, no implementation. Sources: github.com/VAST-AI-Research/Mira-Scene, huggingface.co/Yang-Tian/Mira-Scene.
