TypeSafe `jev` (System One) = calibrated classifier-as-a-service: `Choice`/`Score`/`Noul` in one parallel call, `confidence` from `probabilities`, text state ≤ ~32k tok, TS + Python SDK + HTTP. Verdict: replaces agent-prose snap judgments. Tier 1: skill/subagent selection (cookbook `skill_suggestion`, wrong loads 16.8%→7.3%), `ship-change`/`autofix` safe-fix gate (`Choice` fix-kind + `Noul` injection detector, conf ≥ 0.85), `distill-hermes-memory-into-skills` route classifier (0.7 boundary testable — PILOT 1), `add-supervised-tool-approval` risk `Score` on args, pi-flows `typesafe-decision` step w/ fallback to `agent-decision`. Tier 2: distiller chunk triage, audit finding severity, PR-description verification Nouls, kb_search rerank (`consolidate-retrieval-planes`, eval via `tsx packages/kb/eval/run-fixtures.ts`). Web design: L1/L2 stay deterministic; `runL4` (`validators.ts`, today `status:"skipped"` self-graded) + anti-slop A1–A7/B1–B6 = source-observable Nouls ✓ (PILOT 2); render-observable stays vision. Unknowns: pricing, rate limits, data residency, no image input. Risks: confident-wrong > none, mark advisory; escalation path mandatory.
