# research/point2part-mesh-part-editor.md — index

Research dossier. Point2Part (arXiv 2609.38180, CMU, 2026-09-29) = point-prompted joint 3D part PARTITION — exclusive + exhaustive by argmax, no overlap/gap. One model, three tasks: image→closed part meshes, mesh→closed part meshes, mesh→per-face labels (input geometry unchanged). Backbone Hunyuan3D 2.1 (HY3D-2.1); prompt encoder + part decoder (Mask2Former-style dynamic classifier), per-part SDF + marching cubes → watertight parts; FlashVDM-style 128³→512³ octree.
