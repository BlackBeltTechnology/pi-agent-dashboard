Research artifact. Explore-mode + spike, no OpenSpec change, no repo code change. Source: github.com/opensec-git/Pi-Bolt (release `bolt-v0.9.6`, 2026-10-20). Question: can Pi-Bolt (AOT-compiled pi v1.3.0 fork, JSC/Bun, `pi-bolt` beside pi, `~/.pi/agent` unchanged) replace stock pi under dashboard for perf; can server use same toolchain. Measured (macOS arm64, n=5–7): empty ready 141→35 ms; real config ready 3062→2160 ms; 60k stream +bridge CPU 1130→340 ms; large-session resume peak RSS +45% (~490→~710 MB REGRESSION). Extension parity 141/141 `get_commands`. Interpreted bridge not bottleneck (JIT-off ≈ JIT-on). 5 integration breaks with code refs: (1) `process.execPath`=`pi-bin` not node — `packages/shared/src/server-launcher.ts:220`, `packages/extension/src/openspec-cli-shim.ts`; fix real-node resolver; (2) `pi_version_update` never sent — `packages/extension/src/model-tracker.ts` `readRunningPiVersion` argv1=`/$bunfs/root/pi`; fix execPath walk-up; (3) `session_unregister` lost — `packages/extension/src/bridge-handlers/lifecycle.ts` `sendShutdownUsageThenUnregister`; fix await WS flush; (4) `node:v8` JSC-synthesized heap cap ~260 MB, `NODE_OPTIONS` ignored — `packages/server/src/spawn-process/heap-args.ts`, `packages/extension/src/process-metrics.ts`; fix gate on `process.versions.bun`; (5) bridge `console.*` on RPC stdout — keeper discards by default. Spawn fit: `packages/shared/src/tool-registry/definitions.ts` `piExecutorDef` `overrideStrategy("pi")` = config override. Server via AOT: NOT recommended (Bun/JSC only; node-pty beta; jiti/no-build conflict; stalls are spawn/IO-bound). Recommendation: opt-in runtime, not default; runtime-neutral hardening change; separate `pi-hermes-memory` quick-check stall (~1.25 s both runtimes); re-measure RSS before default switch. Pitfalls: bare positional arg to pi = real LLM prompt (~$0.31 Opus); spike against live dashboard registers sessions — use fake gateway + `PI_CODING_AGENT_DIR`. Reproduce: `gh release download bolt-v0.9.6`, `shasum -a 256 -c`, RPC `get_state` ready bench, fake SSE provider bench, `PI_TIMING=1`.
