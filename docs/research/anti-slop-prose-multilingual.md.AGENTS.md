Research dossier, explore-mode no change no impl, date 2026-10-20. Goal: skill making AI text read human for YouTube (scripts, titles, descriptions, community posts), multilingual. Framing B chosen (anti-slop prose + originality); A detector-evasion rejected (arms race, noisy detectors, misses YouTube policy risk: inauthentic content, synthetic disclosure, spam). Non-goal: detector-score loop. Locales v1 en+hu. Placement: new pkg `packages/anti-slop-prose` + zero-dep Node linter; NOT in `packages/anti-slop` (npm `@blackbelt-technology/anti-slop-frontend` [V], no code there, skills only). Cross-link later from `anti-slop-frontend` B6. Two-layer model: universal structural tells (low burstiness, triads, not-X-but-Y, hook/3-sections/conclusion skeleton, hedge stacking, no numbers/names/dates, moral endings, no first-hand claim) + per-locale lexicon/typography/calques; locale rules OVERRIDE universal. Finding: `anti-slop-frontend` A3 bans all `—`/`–` [V]; wrong for hu spaced ` – ` (gondolatjel); English punctuation leak = hu tell. Rules U1–U10 (thresholds [H]): U1 lexicon hard 0/soft ≤2/1k; U2 sentence CV ≥0.45; U3 locale punctuation 0; U4 not-X-but-Y ≤1; U5 triads ≤1/300w; U6 template open/close 0; U7 rhetorical Q ≤1/500w; U8 specificity ≥1/150w (backbone; fail → ask user 2-3 real specifics, never invent stats); U9 moral ending ≤1; U10 `**Label:**` bullets/emoji headers 0. HU-T: T1 unspaced `—` flag, spaced ` – ` ok; T2 `„…”` (inner `»…«`); T3 sentence case titles; T4 `1 000,5`, `október 20.`. HU-C calques (nyelvművelés [R]): C1 egy density, C2 által, C3 rendelkezik vmivel, C4 kerül pseudo-passive, C5 számára, C6 nem csupán…hanem, C7 Ön/te drift (default tegezés). HU-L lexicon seed hard: merüljünk el, a mai rohanó világban, izgalmas utazás, játékváltó; soft: kulcsfontosságú, zökkenőmentes, átfogó, összességében. Lexicon drifts per model gen. Form profiles: voiceover (≤~25 words, no parens/lists), title (≤~70 chars, no "X: The Ultimate Y"), description (first ~150 chars pass U8, hashtags ≤3), community. Series check: opener/CTA n-gram overlap + structure fingerprint across last N scripts, allow-list brand intros; no known prose linter does this [H]. Architecture: lint → rewrite → voice (`youtube-srt` corpus) → re-lint max N; script = deterministic findings JSON, skill = judgment. Spike: 3-4 models × 20 topics × {hu,en} (~160 gens) vs manual SRTs/hu blogs (NOT auto-subs); log-odds informative Dirichlet (Monroe/Colaresi/Quinn 2008 [R]); Kobak 2024 academic cross-check [R]; packs record calibration model+date, mirror `packages/anti-slop/UPSTREAM.md`.
