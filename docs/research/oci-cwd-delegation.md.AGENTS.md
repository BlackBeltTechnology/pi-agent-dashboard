Research dossier. Explore-mode, no change / no impl. Date 2026-09-14. Status: OPEN — research, continue later. Problem: sharing working tree between worktrees + remote machines hard; git fails binaries/untracked/ignored/`.pi/` state. Q1 (OCI image from CWD): YES daemon-free via `crane append`, `oras push`, `umoci unpack`/`repack`, `buildah from`/`mount`/`commit`; docker build rejected (slow context tar). Q2 (remote mount): overlay mount (`podman`/`buildah mount`, Linux-only, upperdir = diff) vs extract + mtree (`bsdtar --format=mtree`, portable macOS/Linux, size+mtime diff → whiteouts `.wh.*`). Q3 (changes → layer): checkpointing state valid (Dagger/BuildKit/Modal/Codespaces), building images anti-pattern; caveats: whole-file granularity (kopia CDC wins on binaries), layer accumulation (consume into CWD, rebuild base, never stack), spurious mtime/uid/gid/xattr churn (normalize uid/gid, retain mtime), macOS vs Linux case-insensitivity (`COPYFILE_DISABLE=1`), symlink forest (never dereference), absolute paths in `.pi/settings.json` (solve via fixed `/workspace`), no merge semantics (lease model mandatory, caller CWD frozen; 3-way merge fallback); pair with session-diff for text half. Q4 (fast delegation): 4-layer split by churn frequency: L0 deps (lockfile hash, ~500MB, weekly), L1 HEAD (commit sha, ~50MB, or remote git fetch), L2 dirty (tracked mod + untracked, ~KBs, prompt-frequency), L3 ignored-wanted (`.pi/`, build out, `.env*`, ~MBs); push only missing blobs; worker runs pi session, commits upperdir → L4 tar with whiteouts; return apply ~50 lines tar extract on macOS; `zot` sidecar in `docker/compose.yml` or `oras cp`/`skopeo`. Alternatives fork: checkpoint semantics (OCI layers or kopia CDC + lease) vs live-sync (Mutagen, persistent conflict debt); git/rsync/NFS/virtiofs/ZFS rejected. Dashboard hang points: spawn dialog peer compute registration, `spawn-preflight.ts` CWD digest snapshot hook, `/workspace` container alignment, session-diff binary counterpart. 5 open questions: lease vs concurrent edit, git hybrid vs pure OCI, worker OS matrix (Linux overlay vs macOS mtree), L0 return filtering, L2/L3 size telemetry. Spikes: measure L2/L3 sizes in repo, `bsdtar` mtree prototype, `umoci` macOS check, `zot` sidecar footprint.
