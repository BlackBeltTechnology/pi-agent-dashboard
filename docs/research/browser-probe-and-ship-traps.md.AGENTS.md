# research/browser-probe-and-ship-traps.md — index

Research dossier. METHOD half of 2026-08-26/27 marketing-site session — reusable HOW for verifying static-site visual/UI claims with headless-browser probes + the ship traps that cost time. Siblings: `marketing-site-static-rewrite.md` (WHAT shipped), `webgl-field-and-glass-bands.md` (visual system). FINDING 1 (permanent tooling, no OpenSpec change): `site/design-scratch/scripts/serve.mjs` — zero-dep static server, default root `site/`, port `8791`, `--port`/`--root`, `cache-control: no-store`, path-traversal guard (normalize then confirm inside ROOT — `/../../.ssh/id_rsa` otherwise readable); needed because `field.js` ES module imports BLOCKED under `file://`. `shoot.mjs` — screenshot + layout-audit driver, flags `--themes/--widths/--sections/--page/--base/--out/--settle/--audit/--links`; every assertion = defect the page ACTUALLY shipped: doc/nav overflow (`scrollWidth - clientWidth`, visible only at 900px & 1024px), `position:sticky` silently overwritten to `relative`, dead in-page anchors after section deleted, broken `<img>`, any `pageerror`; `process.exit(failures ? 1 : 0)` = gate; `--links` anchors ONLY — `<link rel=preconnect>` targets are origins not pages, 404 by design (`fonts.googleapis.com`/`fonts.gstatic.com`). FINDING 2: screenshot proves PAINT not BEHAVIOUR — cannot assert sticky AFTER `window.scrollTo(0, document.body.scrollHeight)` + 600ms wait, `document.elementFromPoint` at element centre hits its own `href` (click target vs decoration under overlay), `scrollWidth - clientWidth` on `.nav` AND `documentElement`, `naturalWidth > 0` per img; prefer measured predicate over rendered pixel; `--audit` numbers-only. FINDING 3: headless Chromium reports LIGHT scheme regardless of host OS — system theme silently shoots light; MUST set `localStorage.setItem('pi-theme', 'dark'|'light'|'system')` via `page.addInitScript` BEFORE first paint; UI click NOT a substitute (lab panel + header controls `display:none` ≤720px); system path = `newPage({ colorScheme })` / `page.emulateMedia({ colorScheme })` live OS flip; `waitUntil:"commit"` proves no-flash inline script resolved pre-paint. FINDING 4: probes run from repo root — `/tmp` dies `ERR_MODULE_NOT_FOUND: playwright`; else `createRequire('/abs/path/in/repo/x.js')('playwright')`; launch `--enable-unsafe-swiftshader` for WebGL software raster or canvas silently blank. FINDING 5: probe omitting `await browser.close()` HANGS the tool call (abort also killed backgrounded server — same process group); ALWAYS `try{…}finally{await browser.close()}`; recovery `pkill -f <script>.mjs` + `nohup … & disown`; `setsid` does NOT exist on macOS. FINDING 6: pixel asserts in-repo — `pngjs`, `pixelmatch`, `sharp`, `jimp` in root node_modules; `PNG.sync.read()` on Playwright screenshot buffer = WCAG contrast sampling (see glass doc Finding H); animation proof = 2 screenshots ~1.2s apart, `Buffer.compare` differs. FINDING 7: moving-backdrop contrast = multi-frame + per-element boxes — whole-band rect with children hidden gave meaningless `1.00:1` (rect included opaque-card regions, raw field pixels); correct: enumerate text runs directly on translucent surface (walk ancestors, skip background alpha > 0.9), hide ONLY those, sample inside each element's own bbox across SIX frames. FINDING 8: audit BUILT artifact then LIVE URL — `--base` any origin; 21 runs vs `site/dist` local, 9 vs `https://pi-dashboard.dev` post-deploy; live is ONLY check covering build allowlist, `CNAME`, `/app/` neutral-shell subpath; post-deploy assert deployed-only facts: computed `backdrop-filter` = `url("#chroma")` @1440px, `none` @390px (mobile fallback real in prod). FINDING 9: `git` loses `.git/index.lock` to dashboard polling — `git stash push`/`git pull --rebase` failed twice "Unable to create '.git/index.lock': File exists" with background `git status --porcelain` visible in `ps`; retry backoff ~8 attempts 2s apart (won on attempt 2); NEVER delete a lock you did not place = index corruption. FINDING 10: stage by PATH when tree holds other agents' work — uncommitted `.dockerignore`, `openspec/changes/…`, `docs/features.md`, `docs/user-features.md`, `docs/AGENTS.md` rows; `git add -A` sweeps them into site commit; stage explicit paths + verify `git diff --cached --name-only`; check `git rev-list --left-right --count origin/<branch>...HEAD` BEFORE push — first push carried unrelated `plan(fix-runaway-keeper-log-growth)` left on `develop`; publishing someone else's commit = human decision, not side effect. FINDING 11: `deploy-site.yml` `paths: ["site/**"]` — design scratch under `site/` would deploy production per mockup tweak → `- "!site/design-scratch/**"` added.
