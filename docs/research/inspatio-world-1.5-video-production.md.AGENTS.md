InSpatio-World 1.5 (arXiv 2604.07209, InSpatio Team) — real-time camera-controllable 4D world model, SOTA WorldScore, Apache-2.0 code + no-license-tag weights. Backbone Wan2.1-T2V-1.3B, causal DiT 1.42B Self-Forcing-style; per autoregressive block render source views → 3D via depth → forward-splat to target cameras → encode Wan2.1 VAE or TAEHV → 4 flow-matching steps KV-cache → decode TAEHV/Wan VAE; 3 latents = 12 frames 832×480 (first block 9). Components DiT 1.42B bf16 + Wan VAE 127M + umT5-XXL 5.7B bf16 + TAEHV 11.3M MIT + DA3NESTED-GIANT-LARGE 1.7B depth/poses + Florence-2 captioner. Blanchon one-GH200: compiled fp8 TAEHV ~0.57 s/block = 21 fps; v1.0 `--use_tae --compile_dit` = 24 fps H-series. Inputs 1/4 image or video + prompt + traj; `run_inference.sh --video in.mp4 --target_traj target_tcw.txt`; traj = one OpenCV w2c 4×4 16 row-major per line first-frame-normalized DA3 scale; output `output/<id>/{source,render,mask,pred}.mp4` 15 fps images. Setup Python 3.10 CUDA 12.6 conda `inspatio_world_test`, `pipeline/download.sh`. v1.0 extras 3-line pitch/yaw/displacement traj, `--freeze_repeat/--freeze_frame` bullet-time, `--rotation_only`, warper|ply. Blanchon pip `inspatio-world` prepare/generate/`--moves`, `WorldModel.from_pretrained(WorldConfig(dit_precision="fp8"))`; claims parity tokenizer identical DA3 bit-exact VAE 2e-4/6e-4 splat ≤7 px.
