# research/sub1b-stt-diarization-benchmark.md — index

Sub-1B open-source STT+diarization benchmark. 4 engines: MOSS-Transcribe-Diarize 0.9B Q5_K GGUF ~1x RT local (OpenMOSS-Team, Apache-2.0, joint ASR+diarization EN/ZH/HU), Soniox cloud stt-async-v3, Parakeet-tdt-0.6b-v3 ASR-only ~18x RT, Parakeet+Sortformer/pyannote ~10x RT local speaker-aware. 3 real 60s clips HU single/HU multi/EN multi. Verdicts: Soniox cleanest HU, MOSS usable one-model local d/hu/en, Parakeet+Sortformer fastest local speaker-aware no-tuning. Gotchas: MOSS build -DGGML_METAL=OFF (AMD RX 580 Abort trap), Sortformer torch ceiling Intel Mac torch 2.2.2 vs NeMo 2.6.1 (llvmlite/numba/SequenceParallel/numpy workarounds). Artifacts ~/moss-bench/ (outside repo). Procedure = skill benchmark-moss-gguf-vs-soniox. Comprehensive prose doc per user request.
