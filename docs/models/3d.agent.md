# 3d.md — 3D generation models index

Pull-only condensed map. Source: `docs/models/3d.md`. 45 3D-generation models from AI Search transcripts (2026-04-05 → 2026-10-04). Facts as stated in video. Verify numbers before use.

Columns: Vendor · Open (open weights) · Local (runnable locally per video) · Size · Access · Good for · Weak spots. Full table + sources in source file.

## Released, open, local (open-source)
- 4D Anyone — ✅/✅, 12 GB. GitHub local install. Single video of moving person → 4D gaussian splat.
- Animate — ✅/✅, Nvidia GPU ≥ 18 GB VRAM. Single image → rigged 3D asset.
- AnyRecon — ✅/✅, 614 MB (+ VAE 2.1). 2–5 unaligned photos → coherent 3D scene.
- ARTI — Nvidia, ✅/✅, ~765 MB/model. Text/paths/waypoints → real-time 3D human motion; drives Unitree G1 in sim.
- Articraft — ✅/✅. Coding agent (GPT/Gemini/Claude) writes program → articulated objects.
- Block 3D — ✅/✅. Text → 3D in ~5 s. Weak: quality/detail.
- Commodo 1.1 (Kinematic Motion Diffusion) — Nvidia, ✅/✅. Text → human/robot motion; Isaac Sim.
- Cube Part — Roblox, ✅/✅, < 10 GB. Text → object split into part meshes.
- Deja View — Nvidia, ✅/✅, 117 M params ~468 MB. Multi-image scene reconstruction.
- Fire 3D — ✅/✅, single GPU. Photos/video → simulation-ready scene, per-object meshes.
- GNM (Generative Anthropometric Model) — Google, ✅/✅. Slider head meshes, 253 identity + 383 expression controls.
- Lito — Apple, ✅/✅. Surface light field tokenization; reflections/lighting faithful.
- Lyra 2 — Nvidia, ✅/✅, 131 MB. Video → 3DGS env; Isaac Sim export.
- MAC (Multi-Agent CAD) — ✅/✅. Text → printable CAD. Model-agnostic (demo Qwen).
- Mama — ✅/✅. Multi-view video → multi-person 3D motion.
- Marigold V2 — ✅/✅. Single image depth/normal/albedo. Weak: ~17 GB (low res) / ~29 GB (high res) VRAM.
- Mesh Flow — Meta, ✅/✅. Real meshes via Mesh VAE latent sampling.
- Mirror Scene — ✅/✅, ~6.1 GB. Image → editable separate objects; Blender/physics export.
- MoCap Anything v2 — ✅/✅. Single video → joint rotations; human/animal/fictional.
- One Video One World — ✅/✅. Video → animated 3D world. Weak: > 40 GB VRAM; non-commercial components.
- Pager (Panoramic Geometry) — Google & Meta, ✅/✅, ~6 GB. 360° panorama → scene geometry.
- Pixel3D — ✅/✅, 24 GB all models. Best single-image → 3D per video.
- Proxy Pose — ✅/✅, 30 GB (quantised available; LoRA 600 MB). Tracks 3D pose of clicked object; 2.1-class video model.
- RecGen — ✅/✅. RGBD images → full scene geometry, textures, positions.
- Triplat — ✅/✅, ~4.4 GB/model. Triangle-primitive splats → physics/game engines.
- Unimate — ✅/✅. Animates non-human skeletons from rigged model + text. Weak: needs rigged input.
- Video MDM — ✅/✅. Text → 3D human motion from 2D video poses.
- WildDet 3D — ✅/✅. 3D bounding boxes, metric depth; runs on iPhone.
- WorldSculpt — ✅/✅. Scene → editable objects; Gaussian splat → mesh.
- World Tracing — ✅/✅, ~6.2 GB. Image/short video → layered 3D with hidden geometry; three models.
- PhysX Omni — ✅/✅. Physics-simulation-ready objects; joints, materials; training script + dataset released.
