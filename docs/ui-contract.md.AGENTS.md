(repo root) Cross-screen design control plane. Single source of truth for visual consistency. References design tokens only, never redefines, forbids raw hex/px. Token authority `packages/client/src/index.css`. Two-layer theme model. CSS layer = `base` theme: `:root` base dark (default) + `[data-theme="light"]` 44-token override = base light. Only theme `index.css` declares. Runtime palette layer: `packages/client/src/lib/theme/themes.ts` `THEMES` adds 8 palettes (dracula, nord, github, catppuccin, tokyo-night, rose-pine, solarized, gruvbox) × dark/light; `applyThemeVars` (`packages/client/src/hooks/useTheme.ts`) writes them as inline overrides of same token names on `<html>`. 9×2 = 18 palettes; `theme-gallery` spec owns contrast floor. Reciprocal note: `packages/dashboard-plugin-skill/.pi/skills/dashboard-plugin-scaffold/references/host-design.md` = derived plugin-author subset; update together. Prefer `--severity-{error,warning,success,info,neutral}-{bg,fg,border}`, `--status-*`, `--warn-*`; new surfaces use severity, not raw `--accent-*`. Carries spacing scale, type scale (floor: below `text-[11px]` non-essential), radius, elevation (`--elevation-rim` inset signature), component invariants, motion, WCAG 2.2 AA invariants. Colour-role table names accent fill `--accent-{purple,blue,green,orange,red,yellow}` (no contrast guarantee; check per use) vs accent text `--accent-<hue>-text` (AA 4.5:1 on `--bg-surface`/`--bg-tertiary`/`--bg-primary`/card fill). Light block declares six `--accent-<hue>-text` explicitly; does not override `--accent-<hue>`. Rule: coloured text uses `--accent-<hue>-text`, never `--accent-<hue>`; hue = secondary cue (back with word/icon/shape; solarized dark hues near-indistinguishable).
