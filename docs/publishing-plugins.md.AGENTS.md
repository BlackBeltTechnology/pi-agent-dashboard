# publishing-plugins.md — index

Publish new plugin package to npm. Lockstep versioning (`sync-versions.js`). First publish seeds 0.0.1 via one-shot manual publish + revert; OIDC Trusted Publisher after. Plugin server TS must be erasable (`erasableSyntaxOnly`, `import type`). Public host surface, `hostApi`, CSS contract, SDK preset `build:dashboard`, singleton guard, operator trust. See change: strip-only-native-ts-loader, decouple-plugins-from-core.
