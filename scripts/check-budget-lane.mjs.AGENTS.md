# check-budget-lane.mjs — index

Blocking budget-lane structural check, run by ci.yml (`ci` job step "Budget lane check", no `continue-on-error`) and, via `__tests__/budget-lane.test.mjs`, inside `npm test`. `*.budget.test.*` files run only in the nightly lane (`RUN_BUDGET_TESTS=1`, `test:budget`); every vitest config whose project collects one spreads `BUDGET_TEST_EXCLUDE` (vitest.workers.ts) into `exclude`. Exit 1 when (1) `vitest list --filesOnly` (root config; `packages/server/vitest.real-process.config.ts` when present) lists a budget file, (2) a `git ls-files` budget file is in no root-config project that excludes it with `**/*.budget.test.*` and includes it (`createVitest` in-process, `path.matchesGlob` against each project's `config.include`/`exclude` relative to `config.dir || config.root`), (3) that static judgement differs from vitest's own collection on the other tracked `*.test.*`/`*.spec.*` files (`driftFindings(staticSet, listedSet)`), or a `vitest list` fails (fail closed). Never sets `RUN_BUDGET_TESTS`; deletes it from its own env and every child's. A non-code name (`x.budget.test.ts.snap`) is not a budget file (C3). Exports `analyzeBudgetLane(root)`, `driftFindings`, `trackedFiles`, `main`, `BUDGET_EXCLUDE_ENTRY`, `REPO_ROOT`. `--root <dir>` runs against a fixture workspace; `GITHUB_ACTIONS` adds `::error file=<path>::` lines. See change: stabilize-blocking-test-lanes (D1).
