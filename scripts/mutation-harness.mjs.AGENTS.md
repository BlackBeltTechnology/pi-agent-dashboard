# mutation-harness.mjs — index

Manifest-driven mutation runner for the promise-rule ladder: breaks a covered behaviour in a real source file and asserts the target test goes RED (a file that stays green is protecting nothing). CRASH-SAFE: every mutation is journaled to `.mutation-journal/` (one entry file per mutation, temp+`linkSync`, base64 raw `Buffer`s, repo-relative path, owning pid) BEFORE the source is written, because `finally` unwinds a thrown error but not a dead process. `reconcile()` does a three-way compare (matches mutated → restore; matches original → drop; neither/missing/unreadable → CONFLICT, touch nothing, keep entry) and SKIPS entries whose owning pid is still alive — otherwise the harness's own `npx vitest` child reconciles its parent's live mutation and every mutation reports as survived. Durability = process death (page cache), NOT power loss; no `fsync` by decision. Single writer per worktree: a second entry for the same file is refused (EEXIST). Exports `verifyTeeth`, `runTestFile`, `reconcile`, `formatConflicts`, `prepareMutation`, `writeJournalEntry`, `beginMutation`, `endMutation`, `journalDir`, `JOURNAL_DIRNAME`. CLI: `node scripts/mutation-harness.mjs --reconcile` (the conflict unblock path, outside vitest). See changes: cleanup-async-semantics-server-extension, harden-mutation-harness-restore.
