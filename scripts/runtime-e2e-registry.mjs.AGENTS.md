# runtime-e2e-registry.mjs — index

Local npm registry fixture for the Electron runtime-overlay E2E (task 3.1; test-plan X10–X12). `config --dir DIR` → `DIR/config.yml` (storage in DIR; same ACL as `.github/verdaccio/config.yml`, first-party not proxied) for `VERDACCIO_CONFIG`. `publish --release base|good|broken`: base = root version (tag `base`, feeds bundle-server), good = nextPatch (tag `latest`), broken = nextPatch(good) (tag `broken`, server `src/cli.ts` = `BROKEN_CLI` exits 1). Publishes only the runtime closure (`runtimeClosure`: runtime set + bundledPlugins + first-party prod deps) from `npm pack` tarballs with `rewriteManifest` (version + first-party specs pinned; prepack/prepare/postpack dropped) — working tree untouched. `publishOrder`: deps first, server last after `generate-runtime-lock.mjs --server-dir`. Loopback-only (`assertLoopback`); idempotent (skips published name@version); appends `PW_RUNTIME_<RELEASE>` to `$GITHUB_ENV`. `versions` prints base/good/broken. Tests: `__tests__/runtime-release.test.mjs`. See change: electron-runtime-release-pipeline.
