# knip-config.mjs — index

Derives Knip entry points from the project's own manifest conventions and fails when `knip.json` does not carry one (`--check` is the default action). Exists because an unrooted graph does not merely under-report — it reports LIVE files as dead: with no config Knip claimed 723 findings / 90 unused files (`canvas-tool.ts` among them, imported on the next line by `bridge.ts`); rooted, 437 / 10, all ten exact-verified. Covers the three conventions Knip cannot infer: `pi-dashboard-plugin.{client,server,bridge}`, `pi.extensions`, and shell-invoked `scripts/**` (a DEAD script is therefore undetectable — the accepted blind spot). `readWorkspacePackages` derives manifests from `git ls-files` FIRST, falling back to the `SKIP_DIRS` filesystem walk outside a git checkout (the harness image carries source but no `.git`). The walk alone is a denylist and lost to the next build artifact: a locally built, gitignored `packages/electron/resources/server` bundle contributed 12 phantom workspaces and reddened both `#G1/#G2` and `lint-harness-scoping`'s tracked-only assertion. Tracked-ness is the property actually wanted. Glob matching is a single left-to-right pass (`globToRegExp`), not chained `.replace()`: chaining let the `*` pass rewrite the `**/` replacement, collapsing "any depth" to "one segment", and never expanded `{mjs,cjs,ts}` at all. Both failed safe but left the "a glob subsumes this entry" branch dead. Exports `globToRegExp`, `deriveEntries`, `normalizeEntry`, `owningWorkspace`, `missingEntries`, `readWorkspacePackages`. See change: add-knip-dead-code-oracle.
