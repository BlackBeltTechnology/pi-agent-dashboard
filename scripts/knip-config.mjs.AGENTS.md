# knip-config.mjs — index

Derives Knip entry points from the project's own manifest conventions and fails when `knip.json` does not carry one (`--check` is the default action). Exists because an unrooted graph does not merely under-report — it reports LIVE files as dead: with no config Knip claimed 723 findings / 90 unused files (`canvas-tool.ts` among them, imported on the next line by `bridge.ts`); rooted, 437 / 10, all ten exact-verified. Covers the three conventions Knip cannot infer: `pi-dashboard-plugin.{client,server,bridge}`, `pi.extensions`, and shell-invoked `scripts/**` (a DEAD script is therefore undetectable — the accepted blind spot). Walks the filesystem, NOT `git ls-files`: the harness image carries source but no `.git`. Glob matching is a single left-to-right pass (`globToRegExp`), not chained `.replace()`: chaining let the `*` pass rewrite the `**/` replacement, collapsing "any depth" to "one segment", and never expanded `{mjs,cjs,ts}` at all. Both failed safe but left the "a glob subsumes this entry" branch dead. Exports `globToRegExp`, `deriveEntries`, `normalizeEntry`, `owningWorkspace`, `missingEntries`, `readWorkspacePackages`. See change: add-knip-dead-code-oracle.
