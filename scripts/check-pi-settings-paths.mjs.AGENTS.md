# check-pi-settings-paths.mjs — index

Guard, run by ci.yml, on committed `.pi/settings.json` `packages[]`. Rule 1: no machine-specific absolute `source` (`absoluteSourceViolations`, kinds `absolute`/`parse`). Rule 2: no empty `extensions/skills/prompts/themes` array on a non-delta object entry (`emptyFilterViolations`, kind `empty-filter`; `autoload:false` deltas exempt) — empty filter on repo-root entry shadows global bridge → `REGISTER_TIMEOUT`. Exports also `main(inputs?)`, `CHECKED_FILES`, `CORRECTION`, `REPO_ROOT`. `CORRECTION` + `pi install` note print only for `absolute` hits. Flags POSIX `/x`, Windows `C:\x`/UNC, `~/x`; leaves `npm:`/`git:`/`https://`/`ssh://` alone; unparseable JSON fails closed (reported once). See issue #371, change: fix-switch-source-empty-overlay.
