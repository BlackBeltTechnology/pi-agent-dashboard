# knip-ratchet.mjs — index

Per-class dead-code ratchet for `ship-it` step 4.4 and the nightly job. Compares `knip --reporter json` counts against `knip-baseline.json` class by class — never a scalar total, which is gameable and self-deceiving (delete one dead file, add two dead exports, the total falls and the gate passes). The baseline is a debt ceiling: `--check-baseline-diff <ref>` rejects any raised class while lowering is always allowed, and a missing baseline is a hard error rather than an implicit "adopt today's counts". Owns nothing else — dependency classes are `off` in `knip.json` because `noUndeclaredDependencies` in `biome.json` already gates them. Exports `GATED_CLASSES`, `countIssues`, `ratchetDecision`, `baselineIncreases`. See change: add-knip-dead-code-oracle.
