# knip-ratchet.mjs — index

Per-class dead-code ratchet for `ship-it` step 4.4 and the nightly job. Compares `knip --reporter json` counts against `knip-baseline.json` class by class — never a scalar total, which is gameable and self-deceiving (delete one dead file, add two dead exports, the total falls and the gate passes). The baseline is a debt ceiling: `--check-baseline-diff <ref>` rejects any raised class while lowering is always allowed, and a missing baseline is a hard error rather than an implicit "adopt today's counts". A class whose baseline is absent, non-numeric or non-FINITE is ALSO a hard failure, not a skip (`Number.isFinite`, not `typeof`: `1e400` is valid JSON, parses to `Infinity`, and silences a class exactly like a deleted key): deleting `counts.exports` was the cheap bypass (that class went unmeasured while the command still exited 0), and `baselineIncreases` treats a deleted class as raising the ceiling to infinity. Both invocations are wired — the plain ratchet AND `--check-baseline-diff` (ship-it 4.4 vs `origin/develop`, nightly vs `HEAD~1`, since nightly runs ON develop) — because documenting the rule without wiring it left "never raise the ceiling" aspirational. Owns nothing else — dependency classes are `off` in `knip.json` because `noUndeclaredDependencies` in `biome.json` already gates them. Exports `GATED_CLASSES`, `countIssues`, `ratchetDecision`, `baselineIncreases`. See change: add-knip-dead-code-oracle.
