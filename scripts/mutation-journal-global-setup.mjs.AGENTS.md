# mutation-journal-global-setup.mjs — index

Root-level vitest `globalSetup` (registered in the ROOT `vitest.config.ts`) that reconciles mutation-harness residue before ANY test project starts. Root-level on purpose: `test.projects` run concurrently with `pool: "forks"`, so a per-project reconcile would race other projects' forks instead of preceding them. Throws rather than exits — the harness is a library with no exit, and a failing `it` would not stop the other projects. Fail-closed line is AMBIGUITY not residue: nothing-to-do → silent; live-owner entry → untouched; cleanly restored → `console.warn` each path and the run PROCEEDS; conflict/unreadable → THROW, nothing runs. Accepts `{ repoRoot }` as a test seam so tests never reconcile the real tree. See change: harden-mutation-harness-restore.
