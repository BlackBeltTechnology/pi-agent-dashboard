# verify-published-imports.mjs — index

Publish-correctness checker, run by ci.yml. For every non-private `packages/*`, asserts every module specifier in its **packed** file set (derived from `npm pack --dry-run`, so `files`/`.npmignore` match the registry exactly) is declared in that workspace's OWN manifest. Stricter than Biome: only `dependencies`/`peerDependencies`/`optionalDependencies` satisfy a shipped import — a `devDependency` does NOT, because npm never installs it for a consumer. Normalizes bare/scoped/deep-subpath/relative specifiers; relative imports must land inside the packed set. Faults are errors, never silent skips: pack failure (X1), unparseable source (X2). Uninstalled declared dep → `unverifiable-range` WARNING (X3). Reasoned allowlist (entry without a reason fails) carries three groups: `@pi/anthropic-messages` (E404 on registry, reached only through a guarded dynamic-import fallback); the `packages/pi-forms-bpmn` openforms-mui deps, which ARE ordinary registry packages (`react`, `zod`, `dayjs`, …) genuinely declared + version-ranged in the nested `.pi/skills/openforms-mui/tools/package.json` and installed by `scripts/ensure-openforms-deps.mjs` — allowlisted ONLY because this checker reads the workspace-root manifest and cannot see a nested one; and the `packages/browser-plugin` vendored playwright-core **internal aliases** (`@isomorphic/manualPromise`, `@isomorphic/time`, `@isomorphic/timeoutRunner`, `@utils/wsServer`), which are NOT registry packages at all — `tsconfig.base.json` `paths` maps them into the `relay/vendor/shims/` that ship in the same package, so declaring them would write unresolvable names into a published manifest. Keep the two rationales apart: a nested dependency is real and declared elsewhere, an alias resolves to a local shim; misreading one as the other produces a bogus allowlist entry. The browser-plugin importers are verbatim upstream under a never-edit + per-file SHA-256 integrity rule (`relay/vendor/NOTICE`, gated by `vendor-integrity.test.ts`), so those specifiers CANNOT be rewritten to relative paths; a new vendored specifier is the signal to re-check the shim mapping. Exports `analyzeRepository`, `analyzeWorkspace`, `listWorkspaces`, `packWorkspace`, `parsePackOutput`, `extractSpecifiers`, `packageNameOf`, `selectRange`, `rangeIsSatisfiable`, `verifyDeclaredRanges`, `validateAllowlist`, `ALLOWLIST`. Parses via the TypeScript compiler API. BOUNDED: proves declaration, NOT installability — a declared `^99.0.0` passes. See change: cleanup-undeclared-dependencies.
