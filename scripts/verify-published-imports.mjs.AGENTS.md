# verify-published-imports.mjs — index

Publish-correctness checker, run by ci.yml. For every non-private `packages/*`, asserts every module specifier in its **packed** file set (derived from `npm pack --dry-run`, so `files`/`.npmignore` match the registry exactly) is declared in that workspace's OWN manifest. Stricter than Biome: only `dependencies`/`peerDependencies`/`optionalDependencies` satisfy a shipped import — a `devDependency` does NOT, because npm never installs it for a consumer. Normalizes bare/scoped/deep-subpath/relative specifiers; relative imports must land inside the packed set. Faults are errors, never silent skips: pack failure (X1), unparseable source (X2). Uninstalled declared dep → `unverifiable-range` WARNING (X3). Reasoned allowlist (entry without a reason fails) carries two groups: `@pi/anthropic-messages` (E404 on registry, reached only through a guarded dynamic-import fallback); and the `packages/pi-forms-bpmn` openforms-mui deps, which ARE ordinary registry packages (`react`, `zod`, `dayjs`, …) genuinely declared + version-ranged in the nested `.pi/skills/openforms-mui/tools/package.json` and installed by `scripts/ensure-openforms-deps.mjs` — allowlisted ONLY because this checker reads the workspace-root manifest and cannot see a nested one. The former `packages/browser-plugin` vendored-playwright alias group is GONE: the vendored relay now imports package-relative shim paths, so nothing needs an alias waiver. Exports `analyzeRepository`, `analyzeWorkspace`, `listWorkspaces`, `packWorkspace`, `parsePackOutput`, `extractSpecifiers`, `packageNameOf`, `selectRange`, `rangeIsSatisfiable`, `verifyDeclaredRanges`, `validateAllowlist`, `ALLOWLIST`. Parses via the TypeScript compiler API. BOUNDED: proves declaration, NOT installability — a declared `^99.0.0` passes. See change: cleanup-undeclared-dependencies. See change: serve-retained-remote-transcripts.

`extractSpecifiers` walks the AST iteratively (explicit stack, source order preserved): the bundled lazy full-`@mdi/js` chunk's deep `e.a=e.b=…=void 0` chain overflowed the recursive walk on CI Node 22. Regression test runs the real built chunk in a default-stack child `node` (build-conditional). See change: harden-ios-safari-memory-and-ws-diagnostics.
