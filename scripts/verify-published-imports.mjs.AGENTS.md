# verify-published-imports.mjs — index

Publish-correctness checker, run by ci.yml. For every non-private `packages/*`, asserts every module specifier in its **packed** file set (derived from `npm pack --dry-run`, so `files`/`.npmignore` match the registry exactly) is declared in that workspace's OWN manifest. Stricter than Biome: only `dependencies`/`peerDependencies`/`optionalDependencies` satisfy a shipped import — a `devDependency` does NOT, because npm never installs it for a consumer. Normalizes bare/scoped/deep-subpath/relative specifiers; relative imports must land inside the packed set. Faults are errors, never silent skips: pack failure (X1), unparseable source (X2). Uninstalled declared dep → `unverifiable-range` WARNING (X3). Reasoned allowlist (entry without a reason fails) seeded with `@pi/anthropic-messages` (E404 on registry). Exports `analyzeRepository`, `analyzeWorkspace`, `listWorkspaces`, `packWorkspace`, `parsePackOutput`, `extractSpecifiers`, `packageNameOf`, `selectRange`, `rangeIsSatisfiable`, `verifyDeclaredRanges`, `validateAllowlist`, `ALLOWLIST`. Parses via the TypeScript compiler API. BOUNDED: proves declaration, NOT installability — a declared `^99.0.0` passes. See change: cleanup-undeclared-dependencies.
