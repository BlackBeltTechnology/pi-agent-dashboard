# DOX — scripts/test-selection

Affected-test selector modules + the checked-in data that decides CI test selection. See change: speed-up-ci-affected-tests. Entry point: `../select-affected-tests.mjs`. Every file here except `timings.json` is a selector GLOBAL input (a diff to it runs full).

| File | Purpose |
|------|---------|
| `assigned.mjs` | Workflow step helper: `assigned.mjs <selection.json> <job-key> <out.txt>` writes one job's files one per line + `$GITHUB_OUTPUT` `empty`/`enumerated`/`count`. Exports `assignment()`. `ci-scenarios` files stay listed even when `enumerated:false`. |
| `check-result.mjs` | `ci-result` aggregate: `NEEDS_JSON=… check-result.mjs [selection.json]`. Exports `checkResult`, `expectedJobs`. Fails on `select` ≠ success, missing selection, any `failure`/`cancelled`, or an EXPECTED job (unit with a non-empty shard or unenumerated, real-process with files, ci-scenarios with flag on, every non-test job) not `success`. Skip passes only for an unexpected test job. |
| `covered-elsewhere.json` | TOP-LEVEL locations outside `packages/` whose vitest readers are all always-run or path-literal readers (docs, openspec, .github, docker, qa, tests, .pi, root *.md …). An unreached changed file there adds nothing. Sub-paths rejected by `scripts/__tests__/test-selection-data.test.mjs`. |
| `decide.mjs` | Pure decision fn. Exports `decide`, `assignShards` (greedy LPT, median for unknown, deterministic), `extractLocations` (string literals naming a top-level entry or `packages/<p>`; `../` stripped), `isGatedSource` (reads `process.env.RUN_CI_SCENARIOS`), `isGlobalInput`, `locationOf`, `globToRegExp`, `SHARD_COUNT` (4), `LAYERS`. Order: forced/global/unmapped → full; else graph ∪ open-edge ∪ always ∪ path-literal ∪ package-fallback ∪ trigger-map, slow tier removed LAST unless edited. Gated files → `ciScenariosFiles` only; real-process files → `realProcess` only. |
| `git-diff.mjs` | `resolveDiff({base, head, cwd, mergeBase})` → `{changed, base}` or `{full: reason}` (all-zero SHA, unresolvable ref, non-ancestor base); `changedFiles` uses `git diff --no-renames --name-only` (both rename sides + deletions). |
| `graph.mjs` | `buildTestIndex({root, withGraph})`: `createVitest` for root config AND `packages/server/vitest.real-process.config.ts`; per-test deps via each project's SSR `transformRequest` with PER-MODULE try/catch (failure = recorded leaf, e.g. `monaco-setup.ts`); open modules = computed `__vite_ssr_dynamic_import__` arg (`hasOpenDynamicImport`); setupFiles/globalSetup → `globalInputs`; literal `locations` + `gated` per test. ~7 s whole repo. |
| `nightly-report.mjs` | `nightly-tests.yml` report job. Exports `resolveAnchor`, `rangeText`, `summarizeReports`, `timingsFrom`, `buildIssueBody`, `syncIssue`. Anchor = newest green SCHEDULED develop run, ancestor of head, not this run. Issue label `nightly-tests`; only a `schedule` run touches the issue. Writes `<reports>/timings.json`. Exits 1 when red. |
| `slow-tier.json` | Slow-tier manifest — deliberate, logged deselection in affected mode (runs nightly / full / when edited). Seeded ONLY with `scripts/__tests__/async-semantics-mutation.test.mjs` (504 s). New entries need a measured duration in the PR. |
| `timings.json` | Per-file seconds (repo-relative) for shard balance, seeded from CI run 36753089286. NOT a global input. Refresh from the nightly `test-timings` artifact by hand. |
| `triggers.json` | `{ glob → testGlobs[] }` for outside-`packages/` inputs the literal layer cannot see: `biome.json`, `knip.json`, `knip-baseline.json`, and `scripts/**` → every `scripts/__tests__` test (scripts spawned by path). |
| `verify-executed.mjs` | Shard self-verification: `verify-executed.mjs <selection.json> <job-key> <report.json>`. Exports `verifyExecuted`, `assignedFor`. Fails naming every assigned file absent from `testResults[].name`; empty assignment passes; `enumerated:false` skips (except `ci-scenarios`). |
