# qa-smoke-guards.test.mjs — index

Fault-injects the clean-prefix QA smoke (`qa/tests/35-plugin-install-load.sh`) by stubbing `npm`/`pi-dashboard`/`curl` on PATH, so every anti-vacuity guard is driven deterministically on any machine. Pins X8 (empty prefix FAILS), X9 (throwing server entry FAILS while the smoke wrote `enabled:true`), X10 (`loaded:false` with NO `status.error` does NOT fail; `status.error` DOES), X11 (a `/plugins/` path outside the prefix FAILS), plus failed-install and never-200-health guards. Supplies minimal REAL fixture tarballs for both the dashboard and the plugin, because the smoke's local-tarball mode unpacks the plugin and identifies specs by reading their `package.json` (a registry spec would make `tar -xzOf` fail inside the smoke). Repo root derives from `import.meta.url`, not `process.cwd()`. See change: fix-browser-plugin-vendor-specifier-resolution.
