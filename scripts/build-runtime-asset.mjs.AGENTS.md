# build-runtime-asset.mjs — index

`node --import tsx … --version X --out DIR [--lock FILE]`: runs consumer `stageRuntime` (npm source; server@X `runtime-lock.json`) → `pruneBinLinks` (`.bin` symlinks removed, any other symlink throws — consumer refuses link members) → `breakHardLinks` (extra hardlink paths rewritten as copies, mode kept; esbuild postinstall hardlinks its binary on linux-arm64 → tar `h` member) → `tar -czf` of root entries (relative paths, no `./`) → `pi-dashboard-runtime-<X>-<platform>-<arch>.tgz` + `.sha512` (`<hex>  <name>`); final move via `moveFile` (EXDEV → copy + unlink: Windows tmp on C:, workspace on D:). `tarBin()` picks the packer: win32 prefers Git for Windows' GNU tar — System32 bsdtar 3.8.9 crashes packing the staged tree (STATUS_ACCESS_VIOLATION 0xC0000005, empty stderr; v0.11.0, 3/3 runs); GNU tar rejects an absolute `C:\...` arg as `host:remote`, so the `-tvzf` verify lists by basename with cwd at the file dir. Pack retries 3× on transient Windows file locks. Exports `buildRuntimeAsset`, `stagerDeps`, `pruneBinLinks`, `breakHardLinks`, `moveFile`. See change: electron-runtime-release-pipeline (R3).
