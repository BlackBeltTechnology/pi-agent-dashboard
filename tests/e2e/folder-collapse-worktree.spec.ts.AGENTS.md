# folder-collapse-worktree.spec.ts — index

L3 for `persist-folder-collapse-server-side` (test-plan #F4, #F7). A worktree session renders under `gitWorktree.mainPath`, so the collapsed folder is addressed by a path no session reports — the original leak. `beforeAll` resolves the fixture's default branch off the `isMain` entry (never assumes `main`), creates a worktree via `POST /api/git/worktree`, spawns a session in it, and polls `/api/sessions` until the bridge reports parentage; spawned in `beforeAll` ON PURPOSE, because a session created in a test body is in that test's reap delta and would be killed before the next test. #F4 collapse the main-path group → reload → still collapsed, zero expanded frames. #F7 open the session by ROUTE (`/session/:id`; a card click lands on a nested pill) → collapse → Seek → the rendered main-path group expands in <5s with no Retry toast. `afterAll` expands the folder, shuts the session down over the bus, and removes worktree + branch via `docker exec`.
