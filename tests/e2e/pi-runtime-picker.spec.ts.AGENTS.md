# pi-runtime-picker.spec.ts — index

L3 spec for the Settings → Developer "Pi runtime" picker (test-plan #F1-#F17, #X13). Every row is a CONVERGENCE property — the sync checkbox, the divergence banner and the two lanes must agree after a real fetch, a real click and (for #F9/#F10) a real POST round-trip. `/api/pi/installs` is stubbed by MERGING a candidate set into the real response shape: several states (two installs at different versions, a below-floor candidate, an unreadable version) are unproducible on a real harness host. #F5 walks the illegal edge — no reachable action may produce differing lanes while linked. #F8 snapshots every `aria-pressed` cell, force-clicks the disabled ones, and asserts the selection state is byte-identical after. The server-side seam `PI_DASHBOARD_PI_FIXTURE_DIR` covers the rows that must exercise the real enumerator and is asserted at L1. See change: select-pi-runtime-install.
