# helpers/folder-collapse.ts — index

Glue for the folder-collapse L3 specs. `busSend`/`setFolderCollapsedViaBus`/`pinViaBus`/`unpinViaBus` drive server-side setup+teardown over the browser bus — idempotent, unlike the pin DIALOG whose commit is disabled for an already-pinned path, and mandatory because collapse state lives in `preferences.json` and outlives the page, the context, and the spec file. `collapseFolderViaUi` clicks the header chevron and waits for the echo (there is no optimistic mirror, so that wait IS the round-trip assertion); `folderBodyCount` reads expanded/collapsed. `armExpandedFrameWatch`/`expandedFrameCount` install a MutationObserver BEFORE any page script and count every `folder-body-<cwd>` mount from mutation RECORDS — a post-hoc `querySelector` cannot see a body mounted and unmounted inside one task, which is exactly the expanded-then-corrected frame under test. `harnessContainer`/`inContainer` resolve the harness by its published `dashboardPort` for out-of-band fixture mutation. See change: persist-folder-collapse-server-side.
