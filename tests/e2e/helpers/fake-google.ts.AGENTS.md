# helpers/fake-google.ts — index

Fake Google for gmail-plugin L3 (design D8). Dual-use file. In-container (Node 24 type-stripping; ERASABLE TS only): `node fake-google.ts --port 18090` → `127.0.0.1` server: `/o/oauth2/v2/auth` 302 → `redirect_uri?code&state`; `/token` code grant (id_token claims-only, `iss`=base, `aud`=client, `sub`=hash(email), nonce echoed) + refresh grant (`invalidGrant` toggle); `/revoke` (`revokeDown` → 503); Gmail `messages`, `messages/m1`, `labels`, `drafts`, `messages/send` (records `to`). Control: `/_control/{health,state,config,reset}`. Host side: `startFakeGoogle(cid)` (idempotent, health-polled), `fakeGoogleControl`, `fakeGoogleState`, `fakeGoogleConsent` (follows auth URL inside container, returns Location) — all via `docker exec node -e fetch`. `FAKE_GOOGLE_BASE`. See change: add-gmail-plugin.
