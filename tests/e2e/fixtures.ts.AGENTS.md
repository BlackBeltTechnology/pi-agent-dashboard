# fixtures.ts — index

The suite's `test`/`expect` entry point — EVERY spec imports from here, not `@playwright/test` (guard: `scripts/check-e2e-fixture-import.mjs`). Exports an `auto: true` reap fixture: probes `/api/health` through a shared latch, snapshots live session ids before/after each test body over `BusClient`, and shuts down ONLY the delta over the WS `shutdown` message (not REST — REST omits `closedReason:"manual"`, leaving cold-start recovery candidates). Liveness is judged with `isLiveSession`, never mere presence, because a closed session keeps its record until `session_removed`. Re-exports `expect` + the 4 Playwright types the suite uses. See change: fix-e2e-harness-memory-exhaustion. Refusal latch (D2): reap pre-snapshot hook `decidePreSnapshotError` → policy 403 (`network_not_allowed`|`host_not_allowed`) latches harness, sticky + persisted to `test-results/.harness-refused.json` (Playwright discards worker after a failed test), rest skipped; armed only when boot baseline admits credential-free client AND no `narrowTrust` active; 401/other 403 fail the test w/o latch; transport = warn-continue. Trust isolation (D3): exported `narrowTrust(request, patch, {touches?})` — ONLY sanctioned way to change `trustedNetworks`/`auth.bypassHosts|bypassUrls`/`allowedHosts`/`hostGate.mode`/`requireLocalProof` (lint-enforced); snapshots, registers restore. Scope `test` (call inside test/`beforeEach`, restored right after body in the reap fixture — runs on failure + timeout) vs `describe` (call from `beforeAll`; released when next spec FILE's first test starts + group sessions reaped — Playwright forbids `test.afterAll` inside a running hook). No operator credential (auth unconfigured) → fails calling test (dedicated narrow-booted leg). Worker-scoped auto fixture `trustBaselineAtWorkerStart` re-asserts boot baseline (kill-proof; never seed values) and latches on rejected credential. Per-test tripwire over 7 trust keys: leak attributed to owning test + healed; no-narrowing pre-read must equal baseline else re-assert + fail naming last released owner.
