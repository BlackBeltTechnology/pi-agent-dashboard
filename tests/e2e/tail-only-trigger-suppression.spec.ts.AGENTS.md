# tail-only-trigger-suppression.spec.ts — index

L3 for D7's suppression model (F5, F6, F8, F20). Asserts the NEGATIVE case — a programmatic ascent into the proximity band produces ZERO `history_backfill` frames — because a missing stamp is invisible to the pure predicate's own tests (it is handed `suppressed:false` and answers correctly). Every negative row is PAIRED with a positive control on the same session and watcher, so a dead session cannot pass as "suppressed". F6 asserts EXACTLY one (zero = the stamp swallowed the intent; >1 = the splice chain-loaded). F19 is NOT asserted — `turnIndex` is assigned in the reducer's `turnUsage` arm to the last USER message, which in `tail-only` sits in the gap and is never reduced, so all bars get `turnIndex: -1` and scroll-to-turn is UNREACHABLE (measured: 21 bars, 0 `turn-bar`); the assumption is pinned instead.
