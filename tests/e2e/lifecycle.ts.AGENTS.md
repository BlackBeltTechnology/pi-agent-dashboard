# lifecycle.ts — index

Shared E2E lifecycle module. Port dynamic: probes free port in managed mode; `PW_E2E_PORT` (default 18000) + `PW_GATEWAY_PORT` when attaching (USE_RUNNING). Exports `DASHBOARD_PORT`, `PI_GATEWAY_PORT`, `BASE_URL`, `HEALTH_URL`. Paths `REPO_ROOT`/`DOCKER_DIR`/`TEST_UP`/`TEST_DOWN`, `MARKER_PATH` `test-results/.e2e-managed`, `USE_RUNNING` flag, `waitForHealth(timeout)` poll helper.

Harness failure diagnostics (change: stabilize-browser-e2e): `resolveHarnessProject(workspace)` reads the state file's `project` (undefined on absent/malformed — failure path never throws); `harnessRestartCount(workspace, probe?)` = docker `RestartCount`, undefined before the container exists; `captureHarnessFailure(workspace, logPath, probe?)` writes `test-results/harness-failure.log` (project, container names, `status=`/`restarts=`/`exit=`, log tail 200) and returns its path, or undefined with nothing written when docker shows no container. `harnessFailureLogPath(logPath)` names the bundle. `throwIfCrashLooping(workspace, logPath, probe?)` throws once `RestartCount >= CRASH_LOOP_RESTARTS` (2), naming the count + bundle path (a failed entrypoint restarts in seconds, so this reports in ~2min vs a 20-min poll that cannot win). `LIFECYCLE_CHANGE` is the triage bracket. `DockerProbe`/`defaultDockerProbe` make the builders unit-testable without a daemon.
