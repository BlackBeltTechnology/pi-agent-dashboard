Ownership (change: add-missing-ci-legs, #861): this directory — like `tests/e2e/team/` — is CONFIG-OWNED. The three non-`pi` specs (`browser-login`, `security`, `setup-matrix`) read `test-results/identity-matrix/state.json` written only by this config's `globalSetup`, so they could not pass in the default shards.
