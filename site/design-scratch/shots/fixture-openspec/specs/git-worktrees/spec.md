# git-worktrees

## Purpose

The dashboard SHALL allow spawning a session in a new git worktree from the folder card.

## Requirements

### Requirement: Worktrees are first-class

The dashboard SHALL allow spawning a session in a new git worktree from the folder card.

#### Scenario: worktrees are first-class

- **WHEN** a user picks New Worktree
- **THEN** a branch is created and a session starts in it
