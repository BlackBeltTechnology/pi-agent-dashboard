    Decisions

    • Dwell 300 ms + speed cutoff 0.4 px/ms + 300 ms grace — the session-actions menu hover-strip constants (session-hover-intent.ts), reused.
    • Explicit Hide + Pin buttons. Default state expanded; no auto-collapse. Hide (top-edge handle) collapses; Pin (on a peek) or a click on the bar keeps it open.
    • Per session persistence of the collapsed state.
    • Out-of-cwd files: Open always offered. A granted folder opens directly; an ungranted one raises the standard access-grant dialog from the viewer's own read (no client pre-check). No Diff outside the session folder (unchanged).
    • Variant A: file name click = Open, plus explicit Open and Diff buttons.
