Levels:
- `L1`: vitest, `packages/*/src/**/__tests__` (plus the `scripts/__tests__` project).
- `L2`: `qa/tests/*.sh|*.ps1`. Process/HTTP checks only, never rendered-UI assertions.
- `L3`: Playwright, `tests/e2e/*.spec.ts`, against the docker harness. Read the base URL from `.pi-test-harness.json#dashboardPort`; never hardcode `:18000`.
- `L3` rows marked *dist-only project* run in a Playwright project whose base URL is a clean-prefix npm-global server (New infra #1), not the docker harness.
- `ci`: workflow or ship-gate wiring.
- `electron`: the packaged app.
- `—`: manual-only.

Ids:
- `E` edge / decision table.
- `F` frontend-quirk / convergence, also used for manual-only rows.
- `X` error-handling / fault injection.
- `P` performance.

A row may be **table-driven**: it lists several input→observable pairs that one parametrised test covers.
