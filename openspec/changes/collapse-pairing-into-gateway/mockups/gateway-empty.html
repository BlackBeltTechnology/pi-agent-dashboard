Proposed — ported and restructured

Connect a device

No secure road to pair over yet

Pairing proves this server's identity to the device, so it needs a TLS endpoint — a public Gateway tunnel or an https:// URL you own. A plain-http LAN address cannot run the handshake.

On this machine — http://localhost is already a secure context and can pair without any of the above. This is a same-machine path only, not a route for a phone on your LAN.

NN/g empty states — name the outcome (“no secure road to pair over”), not the missing feature; exactly one primary CTA plus at most one escape hatch, which is precisely the shape the spec asks for. Shape of success — the dashed placeholder shows a QR is what appears here, so the region is not an unexplained blank.
