Every exemplar was verified with `ls`.

Harness note (L3): the docker harness port is read from `.pi-test-harness.json` (`dashboardPort`), never `:18000`. Inside the container the dashboard listens on `config.port` (8000) while the browser reaches the **published, derived** port; a browser `Origin` on the derived port is admitted by same-origin-by-Host, not by the listener-port rule. Rows that need `Origin: http://localhost:<config.port>` literally are therefore L1 (or a `docker exec` curl in L2), not browser rows — see "New infra".

## Hard gate satisfied

Operator accepted every recommended answer (2026-10-26; gaps in `/tmp/secmap/batch2/gaps-harden-http-auth-boundaries.md`); no slot is open.

- **AG1** — Capped principal on vault/services: route-tier gate refuses first, 403 `insufficient_scope`, `scope="operate"`; `operate_required` bodies stay for gate-exempt callers (E86, E88).
- **AG2** — Present-but-unrecognised `trustModeOrigin` fails closed: reads `upgrade`, capped, one warning per distinct value; absent origin still reads `operator` (E31).
- **AG3** — Listener set is captured at bind; runtime config edits change nothing until restart (E27, E4).
- **AG4** — Loopback rule pins scheme and port (`http` HTTP port, `https` TLS port); bind family is an accepted residual (E26).
- **AG5** — Logout with no usable token: 302 `/auth/login` + cleared cookie, no store write, no audit, no `onSessionEnd` (E102).
- **AG6** — Fail closed: in-memory revocation always applies; write failure 500 `revocation_not_persisted` with cookie cleared; boot persist failure continues; sweep throw returns 200 and the lazy 4401 gate closes the rest (X6–X8).
- **AG7** — Any file not matching `{notBefore:number>=0, revoked:{d,exp}[]}`, including zero bytes, is corrupt: mass logout (E108).
- **AG8** — `notBefore` is monotonic, `max(previous, now)` (E111).
- **AG9** — Ticket from a revoked session: upgrade refused `HTTP/1.1 401`, ticket consumed (E100 d, F7 b).
- **AG10** — Refused-only peers count in `distinctPeers`; separate hourly throttle per kind; one shared 256-entry peer map (E46, P4).
- **AG11** — Credential-less listed peer: only browser `/ws` admitted; `/ws/bridge`, plugin WS scopes, `/editor/*` refused (E49).
- **AG12** — `revoke-sessions` exits 0 / 1 / 1 / 1 / 2 (success / down / no token / HTTP error / usage), success prints `notBefore` and sockets closed (E113).
- **AG13** — `defaultPrincipalTier` frozen at boot; runtime edit applies after restart; tickets keep their tier (E85, X9).
- **AG14** — Relative budget only, ≤ 5 % regression vs the `auth.test.ts` / `browser-gateway-load.test.ts` baselines; no absolute latency numbers (P1–P3, P5).
