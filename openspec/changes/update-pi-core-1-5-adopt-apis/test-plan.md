Stage: apply (tasks.md present → soft gate)   Generated: 2026-11-03

## Decisions

The six scenario-design gaps (full options in `/tmp/pi15/gaps.md`) were resolved by the user, each with the recommended option:

- **G1** (where the win32-only proofs run): the digest case takes an injected `pathApi` (`trustResourceManifest` `opts.pathApi` → `collectAgentSkills`) and runs on ubuntu CI (E33); the bridge case stays a dev-only `runIf(win32)` row (E28), CI proof via E19, E22, E23, E29, gap recorded in `evidence.md`.
- **G2** (form display of a stored `"soon"`): the number input is empty, the Changed marker shows, no extra text (E46; spec scenario "Non-numeric stored timeout string shows an empty input").
- **G3** (minimatch 11 parity corpus): explicit cases in `filter-enabled-models.test.ts` for `provider//model`, `**/**/model`, `anthropic/**`, `*/claude-*`, expected sets taken from minimatch 11.0.3 (E61).
- **G4** (`accessSync(F_OK)` default): `vi.mock("node:fs")` on posix CI; assert the call and the throw → missing mapping (E57).
- **G5** (trust lock held, no-resources path): fault outcome `{ trusted: false, source: undefined }` and wall time ≤ 250 ms per decide; no uncontended perf budget (P2, X2; spec scenario "Held trust lock fails closed within a bound").
- **G6** (`exitCode` for a `BASH_TIMEOUT` kill): pi's `code` forwarded verbatim (`143` → `143`; `0` + `killed:true` → `0`) (E65; spec scenario "Timeout-killed run forwards pi's code verbatim").

Harness exemplar = the nearest **existing** test of the same category, verified on disk. A new test file is authored beside it. `pi-1-3-floor-smoke.spec.ts` is the pre-rename name (task 1.5).
