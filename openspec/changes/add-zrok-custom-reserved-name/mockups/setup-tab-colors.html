Setup tab — colour repair

Light mode is where it breaks. Toggle to compare. BEFORE reproduces the shipped class strings verbatim.

Root cause

--accent and --accent-soft are never defined in index.css — not in :root, not in [data-theme="light"]. All 14 usages fall back to the hardcoded literal baked into the class string (var(--accent-soft,#1d3a63)), so a dark-navy fill is painted in both themes while the text on top stays theme-aware. In light mode that is near-black on dark navy.
