## 4. Electron: Google view

- [ ] 4.1 Pure fence helper `decideGoogleViewNavigation(target, phase, ssoHosts)` → `allow | external | blocked-redirect | drop` per D5:
  - phases `will-navigate`, `will-redirect`, `will-frame-navigate`, `window-open`, plus a `recentInput` input (≤ 1 s) that decides `external` vs `blocked-redirect` for off-list top-level targets;
  - exact subframe hosts, no suffix rules;
  - normalization: punycode, lower-case, userinfo and non-default port rejected;
  - `about:` / `blob:` / `data:` subframe rules; `mailto:` external.

  External opens go through `openExternalIfAllowed`.
- [ ] 4.2 View manager in main (D4):
  - partition `persist:google-docs`, no preload, sandbox, default UA;
  - main re-validates `{kind,id,resourceKey?,fragment?}` (enum, id pattern, the three anchor patterns, no extra keys) and constructs the URL; `already-open` for a `(kind,id)` already bound in that window;
  - per-view `before-input-event` timestamps (input guard and user-initiated rule);
  - owner `did-start-navigation` (main-frame, cross-document), `render-process-gone` and `destroyed` → release that owner's views (unload check, one 5 s retry);
  - per-window budget 3 with serialized releases, a 10 s input guard (`before-input-event`), and an unload check that never calls `preventDefault`;
  - detach when hidden; destroy on tab close (blocked → keep), plugin disable and window close (one 5 s retry);
  - `setWindowOpenHandler` → deny + external;
  - default-deny request and check permission handlers (clipboard write and fullscreen only);
  - `will-download` → save dialog defaulting to Downloads;
  - availability false under any remote-debugging switch.
- [ ] 4.3 Preload: `googleView.availability()` on every main-window origin; `attach`, `setBounds`, `setVisible`, `destroy`, `signOut`, `onEvent` on the local origin only, per the D4 IPC table, through the trusted-sender wrappers. Views are owned by the sender. `setBounds` is clamped. `signOut` is unload-checked. The client derives `remote-window` vs `browser` when the surface is absent (UA `Electron/`, card text only).
- [ ] 4.4 Client overlay watcher (one per window, `MutationObserver` + rect check): hide the view and show the opaque placeholder while any element overlapping the pane rect has role `dialog`/`alertdialog`/`menu`/`listbox`, is `:popover-open` or `aria-modal`, or sits in the shared portal root; restore on close. Covers plugin overlays. No page capture. Tooltips and toasts excluded.
- [ ] 4.5 Settings sign-out (`signOut`: destroy views, then `clearStorageData` with all storage types); plugin disable destroys live views.
- [ ] 4.6 `security-hardening` pass on isolation, IPC ownership, fence, popups, permissions and the debug-CDP exclusion. Spawn `Audit` on the diff.
