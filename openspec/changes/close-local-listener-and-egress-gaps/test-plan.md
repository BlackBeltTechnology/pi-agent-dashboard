All 13 gaps in `/tmp/secmap/batch2/gaps-close-local-listener-and-egress-gaps.md` were answered; the operator accepted every "Recommended" option:

- CG1 hardlink inside an anchor to an outside file: served, accepted named residual; E30 pins 200.

- CG6 refusal precedence: invalid URL, secret binding, env-unset, then egress vet (E96).
- CG7 metadata set = exactly the webhook set; Alibaba/Oracle/AWS-DNS addresses are a named residual (E101 narrowed).
- CG8 `HostIp` loopback = literals `127.0.0.1`/`::1` only; any other value or any non-loopback entry → recreate (E116, E117).
- CG9 failed `docker rm -f`: raise (fail closed) except "No such container", which continues to create (X20, X21; new X23).
- CG10 ELOOP/dangling keep today's 404 mapping; EACCES/EIO in the post-open check or `realpath(target)` is a refusal (site 403, handle closed) (E34, E35, E36, E58).
- CG11 no latency threshold; structural realpath/git counts only: P2 dropped, P3 re-cast as a per-match structural bound.
- CG12 provider-target vet shares the single 8 000 ms probe budget (X30).
- CG13 serve_mockup check-then-open race: accepted named residual; X12 dropped.
