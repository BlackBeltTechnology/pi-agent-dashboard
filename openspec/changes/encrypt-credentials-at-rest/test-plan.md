# Test Plan — encrypt-credentials-at-rest

Stage: design   Generated: 2026-10-25   Status: **FINAL — all 11 gap decisions applied (decisions.md G1–G11, accepted)**

Gap decisions G1–G11 are folded into the rows below and into the specs and design. `tasks.md` carries one task per automated row and one per manual-only row.

Routing honesty: tests never touch a real OS keychain (design D9). Every L1 row injects an `entryFactory`/provider stub, a test codec, or a stub worker entry. Real keychains (macOS ACL and prompts, notarized bundle, Secret Service, Windows Credential Manager) are covered by L2 VM rows, ci build legs, or `manual-only` rows.
