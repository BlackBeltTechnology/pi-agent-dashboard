A · Group pill (common region), borderless items

Each group is one filled pill and the items inside have no border. Spacing is 2px inside a group and 10px between groups. P/D/S/T becomes one stepper. Close sits behind an inner divider. Quota is read-only, so it gets a dashed, unfilled region with no hover. An empty STATUS group is not rendered.

  • Gestalt common region (NN/g, Common Region): one container per group, never boxes inside boxes.

B · Segmented groups (shared outline, label as the first segment)

Buttons are joined with a shared outline. The label is a tinted leading segment, and inner dividers separate the items. This reads more like a traditional toolbar and has stronger edges, but it is denser. It suits Git well and suits the quota readouts less well.

H · Hybrid: B-style segmented Git with a PR segment, A-style OpenSpec pill, dashed quota

The PR is a status segment in the Git group, not just an "Open PR" button. It shows the number, state and CI result, and links to GitHub. The actions after it depend on the PR state. The OpenSpec pill reuses the 5-segment lifecycle bar from PR #745 in its letters mode (the bar is 150px, under the 250px cutoff), with one primary action and a ⋯ menu, the same model as the session card.
