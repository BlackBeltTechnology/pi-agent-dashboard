## 2. Scanner layers (pure, exact tests)

- [ ] 2.1 Implement the Unicode layer (zero-width, tags, variation-selector runs, BIDI with the RTL rule; no entity decoding for non-HTML) with the preservation rules (emoji/Brahmic/Arabic joiners, ZWSP next to Thai/Lao/Khmer/Myanmar/CJK, LRM/RLM, RTL text). Verify: equality tests per rule, including the preservation cases.
- [ ] 2.2 Implement the ANSI layer. Verify: equality tests.
- [ ] 2.3 Implement the hidden-HTML layer on `htmlparser2`, using source-range removal (no re-serialisation), the narrow HTML-detection rule (contentType or doctype/`<html>` prefix), embedded `<style>` rules with simple selectors (type/.class/#id, comma lists), low `unresolved_css` for complex selectors, script counting as hidden, and per-text-node decoded scanning with source-range rewrite. Verify: a test per hiding technique (inline and class-based), a byte-identity test outside removed spans and rewritten nodes, an entity-encoded payload detected in HTML, and plain-text code mentioning `</div>` left untouched.
- [ ] 2.4 Implement the URL layer (`data:` placeholder in strip/block only; markdown and HTML `<img>` query-string images to non-allowlisted hosts reported low and never removed; confusables at low) and the low-severity phrase rules. Verify: unit tests.
- [ ] 2.5 Compose `scan()` in the fixed order with the 2 MB truncate + `oversize_truncated`, and visible-escaped samples ≤ 80 characters. Verify: determinism (scan twice, deep-equal), 3 MB HTML with early hidden text detected, and a linear-complexity perf test (500 KB vs 1 MB, ≤ 25 ms per 100 KB).
