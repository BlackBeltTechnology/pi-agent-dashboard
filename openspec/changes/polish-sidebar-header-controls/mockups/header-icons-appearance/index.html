4 · Decisions

D1 · Icon size: B (28 / 18), chosen

Big enough to read; one line at 280 px only with the left-group gap cut to gap-0.5 (the 28 px box already adds 10 px of air per glyph, so glyphs end up further apart than today). About 5 px of slack, measured here.

C meets tap-target but breaks the 280 px floor. Taking it means relaxing the spec floor to ~290 px. The Playwright fit spec (sidebar-header-fit.spec.ts #E3) is the real gate either way.

D2 · Scope of "other icons"

  • In: row-1 tools + filter funnel (same recipe, one helper).
  • Out: the session-card and folder-header icons (0.4–0.5). Separate change; they're governed by the compact card spec.
  • Chip and pills keep their sizes: they already carry text.

D3 · Popover = mockup layout

268 px two-column grid, labelled segmented mode, Mode + Palette headings, active = --bg-tertiary fill + bold + check (shape, not colour alone).

Swatch: split tile instead of two dots (one target-like shape, still the real colours).

D5 · Appearance glyph: mdiBrightness6

A half-filled circle is the common light/dark symbol. This one is a solid shape that stays crisp at 18 px, unlike the five-dot palette, and it can't be mistaken for Focus (target) or Settings (cog). Runner-up: mdiThemeLightDark, the right meaning but noisy at 18 px.

Rejected: mdiCircleHalfFull (the plain half circle), already the "group by status" glyph in GroupByChip. A glyph that follows the current mode drops out because System's monitor reads as "display". The swatch tile is the most informative, but no other row-1 control is an image of its value.

D6 · Collapsed chip: C (glyph by server kind, no chevron)

Below 400 px the chip turns into a row-1 icon button: a 28 px glyph with the status dot as a badge. mdiLaptop = this machine (isLocal), mdiServerNetwork = a remote server. With the name hidden, the glyph still says which kind of server you're on. Dropping the chevron keeps it narrower than today's dot + chevron; aria-haspopup="menu" and the accessible name don't change.

At ≥ 400 px the same glyph replaces the bare dot in front of the name, and the chevron comes back.

Touches ServerSelector.tsx, which group-servers-by-identity also edits (menu rows). Different region of the file, but sequence the two changes.

D4 · Icon contrast

Row-1 glyphs move from --text-tertiary/--text-muted to --text-secondary. The badge on each frame reports the lowest glyph contrast measured vs. the sidebar background.
