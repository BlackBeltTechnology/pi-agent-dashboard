Tone vocabulary (UiTone)

gopositive / proceed: Resume, New session, Verify, Merge
createmake something new: Fork, New change, Propose, Open PR, Add to workspace, New goal
cautionpending / side effects: Commit, New worktree session, Clean up broken, Project setup (update), KB reindex
dangerdestructive: Stop, Exit, Close worktree, Remove from workspace, Disable team
neutraleverything else (no tone)
Colour is icon-only; labels keep the neutral colour (WCAG 1.4.1). NEXT uses the blue tint triple. Lifecycle bars reuse the card stepper's statusPresentation colours (done --status-idle, current --status-working). The badge moves from raw text-amber-400 to --tint-orange-fg. Plugins set tone on FolderMenuContribution / UiActionListItem; an unknown tone renders neutral.
