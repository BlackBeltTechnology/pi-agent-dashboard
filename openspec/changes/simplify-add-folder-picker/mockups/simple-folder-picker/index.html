What changes vs today

  • Same component. It's still PathPicker inside AddFoldersDialog: the path input, the list, New folder, workspace and trust options.
  • Removed: row checkboxes, the chevron buttons, the "current folder" self-row with its "Contents" label, and the "Selected" basket.
  • Clicks work like a file manager (table below).
  • With nothing selected, the button adds the folder you're in. The status line names the exact path.
