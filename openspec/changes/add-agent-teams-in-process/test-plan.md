## Scenarios

Levels: **L1** vitest (`packages/agent-teams-plugin/src/**/__tests__/*.test.ts`; the plugin is created by `add-agent-teams-core`, exemplars are the nearest existing tests of the same category) · **L2** `qa/tests/*.sh` (no rendered-UI asserts) · **L3** Playwright `tests/e2e/*.spec.ts` against the docker harness (port from `.pi-test-harness.json`, never :18000). `⟦double⟧` = recorded contract double (task 2.2) plus an in-memory server↔bridge lane with fault injection (drop, delay, duplicate, reorder) and a fake clock, no pi process. `⟦faux⟧` = pi-ai `fauxProvider` scripted models driving real `createAgentSession` children (as the spike). `⟦upstream⟧` = the real `pi-dashboard-subagents` release, `describe.skipIf` it is absent, runs only after gate task 1.11. `⟦fixture⟧` = the test-only fake subagents extension fixture in the docker harness / qa (implements the recorded contract with scripted children). Performance rows: workload = input + trigger, metric = threshold (+ window); ratchet rows are report-only until the first recorded run (owner decision A12). Spike-derived rows: busy-wait `sleep` (S51), stray teammate cap race (S71), shutdown-notice wake storm (S91), batched mails read as one (S74), steer behind a long tool (S81, S28), ~50k-token base context (S99), spawn latency (S97), claim lock/duplicate work (S13, S76).
