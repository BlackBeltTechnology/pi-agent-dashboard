# Tasks

Conventions for every group (TDD per AGENTS.md): task X.1 writes the failing tests for the group's spec requirements (scenario-level detail is folded in later by `scenario-design`; keep test tasks at requirement granularity), then implementation, then a DOX closeout task. DOX closeout = update the nearest directory `AGENTS.md` row (path-alphabetical, caveman style) for every changed file; docs under `docs/` are written by a **DocScribe** subagent in caveman style (main agent never edits `docs/` directly). Verify tests with the recorded-log procedure: `set -o pipefail; npm test 2>&1 | tee /tmp/pi-test.log; grep -nE 'FAIL|Error|✗|✘|Tests +[0-9]+ (failed|passed)' /tmp/pi-test.log` (scope with `npx vitest run <file>` while iterating).
