# Test Plan — stabilize-blocking-test-lanes

Stage: design   Generated: 2026-11-22

## Owner decisions applied (2026-11-22)

- C1 — the deferral deadline is 04:05 UTC on the UTC date of the run's `created_at`; a reporter after that instant, the next day included, does not defer (E74).
- C2 — a `budget` timeout above 50 min moves `DEFER_DEADLINE_UTC_MINUTE` and the watchdog cron later together, keeping both inequalities (E106).
- C3 — a budget file is a code file only; `.snap` and other non-code `*.budget.test.*` names are ignored by the lane check and the selector (E13b).
- C4 — no file check on a liveness allow-list entry in this change (E54).
- C5 — the CodeQL 60 s and 300 s bounds are observed scaled, with no real waits: static default checks plus short bounds through the fake CodeQL binary (E113, X2).

> Group-6 rows (E64–E99, E102–E106, X5 (reporter half), X6–X8, X11–X18) apply only when spike task 1.1 passes; design.md D7 "If the spike fails" sets what happens otherwise.
