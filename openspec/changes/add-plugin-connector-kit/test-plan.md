| H7 (G7) | Op names validated up front (regex + unique); throw; register nothing | E46 |
| H8 (G8) | Unknown server failure code → `internal`, message kept | E30 |
| H9 (G9) | Client drops invalid entries individually (first 32, first duplicate kept), warn per entry; `required` on boolean invalid (server throws, client drops) | F6, E8 |
| H10 (G10) | Host already hides disabled plugin's settings page; assert, no kit work | F19 |
| H11 (G11) | Iterative seen-set walk; cycle → `"[Circular]"`; deep data no throw; no perf budget (P2 dropped) | E57 |
| H12 (G12) | Non-object `values` / non-object body → 400 `invalid_input`, nothing stored | E43 |
| H13 (G13) | `writesToggle:false` → no switch; PUT omits `writesEnabled` | F13 |
