What looks off today (numbers match the grey markers)

  1. Workspace is three different controls. Round radio chips, a detached grey "None — no workspaces yet" line and a "+ New workspace…" text link, for one optional choice.
  2. Workspace has the most visual weight. Coloured bordered chips outshine the primary Add button.
  3. Weak label with a glued-on hint. "Add to workspace" is small medium-weight secondary text; " — optional; a folder lives in exactly one" is muted and wraps badly.
  4. Faint text. The selected chip and "+ New workspace…" use raw --accent-blue as text; the hint and empty line use --text-muted. Both fall below the contract's contrast floor.
  5. Four stacked rules. Status, workspace, trust and footer each sit in their own band; the dialog reads as boxes.
  6. Status line has no verb. A bare path; it is not clear that's what Add adds. The hint is muted and shares the line.
  7. Selection is colour only, no shape.
  8. Hard-coded palette on the Add button and the git/pi badges; the "added" badge is 10 px and barely visible.
  9. Empty home is a dead end: "No subdirectories", no next step.
  10. Phone: the 8-row list is 352 px, so Add/Cancel scroll off-screen; buttons are 36 px, under the 44 px touch floor.

Proposed fixes (numbers match the blue markers)

  1. P1One Workspace dropdown, default "None", "+ New workspace…" as its last option (opens the existing NewWorkspaceDialog). Matches the original mockup.
  2. P1Options share one quiet block (Workspace + Trust) with field-label typography; no own divider.
  3. P2Proper field label (text-[12px] font-semibold text-primary); "optional" moves into the "None" option.
  4. P2Readable tokens: --accent-blue-text for link text, --text-secondary for hints.
  5. P2Two rules total: one above the options block, one above the sticky footer.
  6. P2"Adds:" prefix on the target, truncating path, hint on its own line.
  7. P2Selected rows get a left accent bar and a check mark.
  8. P1Add uses --accent-solid, truncates long names; badges use tokens; "added" is 11 px with a border.
  9. P2Empty state says what to do next: open a folder above, or use New folder.
  10. P1Phone: 6 rows, sticky footer, 44 px buttons and select. Add/Cancel are always visible.
