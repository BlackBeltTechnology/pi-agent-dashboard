# add-grammar-compact-view

New default **inline redline** presentation for composer grammar corrections — whole draft on one line, each change shown in place, per-change apply plus Apply-all — with a remembered `Redline / Compact / Original / Corrected` mode toggle, kind-colour semantics, a redesigned `list` view (aligned before→after columns + kind + message), and a `plugins.grammar.correctionView` setting to pick redline vs list. Interactive mockups in `mockups/` (`final.html`).
