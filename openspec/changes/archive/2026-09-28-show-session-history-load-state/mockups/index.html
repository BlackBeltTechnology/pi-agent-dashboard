UX rationale (each decision → public rule)

  • Never say “No messages yet” unless we know it. Pending, waiting, and timeout currently all fall through to the empty state — a false statement of system status. Nielsen H1 Visibility of system status, H9 help users recognize/recover from errors.
  • 300 ms show-delay before any indicator (reuse REPLAY_PILL_DELAY_MS). Warm replays resolve under it; flashing a spinner for 100 ms reads as flicker. NN/g response-time limits (0.1 s / 1 s / 10 s), Doherty threshold (400 ms).
  • Skeleton in chat, spinner on card. Chat is a content-layout load → skeleton predicts shape; card is a small status → compact spinner. NN/g skeleton screens.
  • >10 s → elapsed time + Retry. No percent-done exists (server heartbeats carry none), so elapsed seconds + an escape hatch is the honest substitute. NN/g 10 s limit; H3 user control & freedom.
  • Waiting = static, not spinning. A spinner implies progress; while disconnected nothing progresses. Static icon + text. H1 (accurate status).
  • Ring (A) chosen — compact, zero layout shift, co-located with the status chip (Gestalt proximity). Its colour+motion-only risk (WCAG 1.4.1) is mitigated three ways: (1) three distinct shapes — spinning arc / dashed / solid — not just hues; (2) chip title + sr-only text name the state in words; (3) the chat pane states it in text for the selected session. Static ring uses --text-tertiary for ≥3:1 non-text contrast (WCAG 1.4.11). Ring sits at inset:-3px so it never overlaps the status-shape badge dot.
  • Announce without stealing focus. role="status" for loading, role="alert" only for the chat failure. WCAG 4.1.3 Status Messages. Card: only the SELECTED/subscribing card carries an sr-only role=status; others stay silent (avoids announcement spam from 20 cards).
  • Reduced motion stops the spin/shimmer; the ring still differs by shape (partial arc vs dashed vs solid), and tooltip/sr-only text still name it. WCAG 2.3.3; existing fx-idle/app-hidden pause rules already exempt animate-spin.
  • No layout shift. Ring is position:absolute; inset:-3px around the existing 16px chip — card never reflows; timestamp stays. web.dev CLS.
  • Default state shows nothing. Most cards are idle (lazy load); marking “not loaded” on every card would be noise. Progressive disclosure / signal-to-noise, NN/g.
