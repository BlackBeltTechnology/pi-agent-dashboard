## Decisions

Each answer below was accepted as recommended and is written into the change specs and `design.md` (D11).

- **G1** — the 50 ms window is inclusive: `https − http ≤ 50` (E4).
- **G2** — at most 6 concurrent route checks; N requests settle within 2 s × ⌈N ÷ 6⌉ (P1).
- **G3** — malformed `routes` on load: drop invalid routes; none left → one legacy route from the `host`/`port` mirror; routes win over a disagreeing mirror (E10).
- **G4** — delivered routes: keep the first 8 valid; accept the bare trailing-slash origin (E6).
- **G5** — no fingerprint and no on-link route: no pair action, state text only (E7).
- **G6** — browser "Pair with code…": the payload's https origin must pass delivered-route validation, else refuse (F8).
- **G7** — host normalised before classifying and grouping: lower-case, one trailing dot, IPv4-mapped IPv6 as IPv4, zone id stripped (E14).
- **G8** — packaged Electron is verified manually (tasks 10.3); main-process logic stays at L1 (F14 manual-only).
