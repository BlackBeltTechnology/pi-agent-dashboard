Try these

  1. Open ⋯ on pi-agent-dashboard → Group by → Status, then Location.
  2. Sidebar ⚙ → Default grouping → Status. Documents follows the default; a folder you set explicitly doesn't. Use default (…) re-attaches it.
  3. Drag a card inside a lane (reorders). Drag it into another lane — it snaps back with an explanation.
  4. Collapse the Idle lane, select a card, then trigger “Turn ends” on the selected card — header shows the selection marker instead of auto-expanding.
  5. Type in search — lanes flatten. Clear it — lanes return.
  6. Theme toggle ◐, and resize to ~375 px.
