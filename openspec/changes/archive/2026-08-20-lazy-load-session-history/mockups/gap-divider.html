Memory Limits

Controls for bounding server memory usage. Set to 0 to disable a limit. Requires server restart.

Max Events Per Session
Ring-buffer size per session. Older events are trimmed from the middle so the chat head survives. 0 = unlimited (grows without bound).
Max Replay Events
Cap events sent to the browser when reopening a session. Keeps the start and the most recent messages; earlier ones load on demand. 0 = unlimited.
