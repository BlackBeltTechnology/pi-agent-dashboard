3 · Which tunnel is primary

Concurrency forces one question the UI must answer out loud: several URLs reach the dashboard, but only one may mint OAuth redirect URIs and pin the session-cookie origin. Naming it explicitly is what keeps the existing auth invariant intact.

Primary provider
zrok
Primary robson-home-mac.shares.zrok.io
tailscale
✓ Connected macbook.tail9f2a.ts.net
The primary decides your sign-in origin. OAuth redirect URIs and the session cookie derive from https://robson-home-mac.shares.zrok.io. The tailscale URL still reaches the dashboard and is allowed by CORS — it just never mints a redirect URI.
Switching primary re-mints your redirect URI. Any OAuth provider with the old URI registered byte-for-byte will reject sign-in until you register the new one. Confirmed, not one-click.

4 · Registering a live tunnel as a gateway URL

A gateway URL is not the same object as a tunnel. A tunnel is a live process; a gateway record is a persisted address the dashboard answers on, and it carries how people get in. That is why this cannot be silently automatic — gateway-action.ts rejects a record with no auth mode outright: “a gateway with none is either unreachable or unprotected.”

TLS URL — all three modes legal
tailscale · https://macbook.tail9f2a.ts.net
Adding this publishes an address. The dashboard will answer on it and it becomes a CORS-allowed origin. Choose at least one way in.

Publicly-trusted TLS — pairing and OAuth are both eligible. This does not change your sign-in origin; publicBaseUrls is never an OAuth redirect source.

http mesh URL — one mode legal
zerotier · http://10.147.20.4:8000
No TLS on this address. Two of the three ways in are unavailable, so the choice is made for you — but it is still shown, not hidden.

A http gateway is only reachable through a trusted network, so the CIDR is required rather than optional.

Why not just add it automatically on connect? Because the auth mode cannot be inferred. Defaulting to trusted-network would silently publish an address protected by a CIDR the user never chose; defaulting to pairing or OAuth is illegal on a http mesh URL. The button is offered the moment a live URL is unregistered — the decision stays with the operator.
