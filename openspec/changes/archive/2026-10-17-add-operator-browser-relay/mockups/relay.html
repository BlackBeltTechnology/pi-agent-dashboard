How it works (one screen)

The agent drives your real, logged-in Chrome through the Playwright extension; the dashboard relays CDP on loopback and screencasts each tab into the editor pane.

  1. Connect — Settings, or the agent: POST /api/browser/connect {profileDirectory}. Server mints a 128-bit guid, opens Chrome on connect.html?mcpRelayUrl=ws://127.0.0.1:<port>/ws/browser-ext/<guid>.
  2. Extension attaches — WS /ws/browser-ext/<guid>, origin pinned to the Playwright extension id, loopback only. Returns {cdpUrl, instanceId}.
  3. Agent attaches — agent-browser connect ws://127.0.0.1:<port>/ws/browser-cdp/<guid> (any Origin header refused). Deny-listed verbs answered -32000; allowedDomains guards navigate/createTarget.
  4. You watch — browser_show_in_pane or the session-card badge opens browser:<instanceId>:<tabId> as a pane tab; it sends browser_relay_subscribe, gets JPEG browser_relay_frames, and forwards allowlisted input.
  5. Your turn — browser_await_human opens the tab and blocks on a confirm; the pane's Done ✓ (or the chat card) answers it.
  6. Teardown — CDP or extension socket closes, 30 s with no agent, 60 s unclaimed guid, or the kill switch.
