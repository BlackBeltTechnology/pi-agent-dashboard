2Overview grid + focus viewM
Goal
Open a mock and read it in 10 seconds, like the invoice-bot portfolio: thumbnails plus reasons first, detail on click.
Kit API
Frame.why?: string: one line, at most 120 characters, shown in the caption and the focus view. Lint like TIP > 40: show WHY > 120 on the card.
Frame.group?: string: groups cards under a heading ("1 Session list"). Defaults to the frame title.
Site
#<id> becomes the overview: a CSS grid of minmax(250px,1fr) cards, one card per frame side (Current, Proposed, or each step). A card is a scaled live render of the pane (transform: scale() inside a fixed-height clip, pointer-events:none) plus a caption: chip (Current / Proposed / Step n), ref id (1a, 1b, 2a…), title, why.
#<id>/<n> becomes the focus view: today's full-size Current | Proposed pair, plus prev/next buttons (←/→ keys) and the why block under it.
Deep links #id/n/side/ring keep working and land in the focus view. Search hits open the focus view.
Style
Current / Proposed labels become small chips: neutral for Current, a quiet green tint for Proposed. Red/green stays reserved for rings. All colours stay --mk-* tokens.
Done when
A mock with 2 frames shows 4 cards. Clicking a card opens #id/n, and ←/→ walk the frames. The existing ref-link and ring-flash tests still pass.
3States: separate (default) or animate (opt-in)M
Goal
A reviewer sees what happens after a click without clicking. Mocks stay prop-driven: no fake handlers, no hidden state.
Kit API
interface Step { label: string; current?: ReactNode; proposed: ReactNode; tap?: string }
interface Frame { …; steps?: Step[]; play?: boolean }   // steps XOR current/proposed
export const Tap = ({ id, children }) => …             // wraps the click target
tap: "relink" on step k pulses the <Tap id="relink"> element inside step k: the click that leads to step k+1.
Separate
Default. Steps render as a horizontal strip: step card → arrow → step card. Each card is labelled 2a label and is linkable as #id/n/step/k. The Tap marker is drawn statically (ring dot).
Animate
play: true. A single pane stacks every step and crossfades between them (opacity 450 ms, 2.5 s per step, loops), with a tap pulse 500 ms after a step enters. Controls: Pause/Play, one dot per step (click = jump + pause), and the current label. prefers-reduced-motion renders the separate strip instead. The overview thumbnail always shows step 1.
Lint
A frame with both steps and current/proposed raises a problems entry. A tap with no matching <Tap> shows TAP? on the step.
Done when
The example's re-link flow is 3 steps and readable without interaction. Under reduced motion the player shows a static strip. Vitest covers the steps XOR rule and ref parsing for step/k.
