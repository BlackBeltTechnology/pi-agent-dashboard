This address is not allowed

Pi Dashboard received Host: rebind.example:8000, which is not one of the hostnames it answers on. The request was refused before anything was served.

Three ways in

  1. Use an address the dashboard already answers on: http://localhost:8000 on the machine that runs it.
  2. Add this name as an allowed hostname: Settings ▸ Security ▸ Allowed hostnames, or allowedHosts in config.json. Only do this if you put the name there yourself.
  3. Or add it as a gateway URL: Gateway ▸ Add a gateway URL, or publicBaseUrls in config.json.
