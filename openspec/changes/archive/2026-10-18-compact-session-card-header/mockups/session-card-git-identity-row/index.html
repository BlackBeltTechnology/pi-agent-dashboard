UX rationale

Why it is better

  • One text column. Title, git row and meta all start at 30 px; the status chip owns the left column. One alignment edge instead of two.
  • Identity next to identity. Worktree + branch sit directly under the title; the worktree pill leads, so worktree cards share a left edge (Law of Similarity).
  • Live state is easy to find. Status keeps its colour carrier (dot / glyph on the shape, word in --text-secondary, per align-ui-with-theme-tokens D2b) and in B leads the meta line, so scanning down the sidebar reads “working / needs you / idle” at a fixed x-position.
  • No layout jitter (B). A plain flex row would re-ellipsize the model on every tool call (motion in peripheral vision). The grid split keeps the model column still.
  • Missing folder moves to the title row, gated on cwdMissing alone, so non-git sessions and non-worktree group members finally show it.
  • Shorter cards. See the measured heights; B removes one text row on every card, and the GIT subcard disappears.

Rules the proposal keeps

  • Git row renders only when GitInfo renders today (showGitInfo || gitWorktree, gitBranch present).
  • Status content unchanged: ActivityIndicator (Resuming, ended reason, Needs you, Retry N, current tool, Thinking…, Idle) and HostPressureIndicator; context bar honours prefs.contextUsageBar; cost hidden when 0.
  • data-testids kept: worktree-pill, git-dirty-pill, cwd-gone-pill, session-card-meta, session-ended-reason-*.
  • MovedBadge / OriginDeviceChip / DriverChip (today on line 2) move to the title row next to the missing-folder pill. They're rare and describe the session, not the model.
  • Mobile card unchanged.
