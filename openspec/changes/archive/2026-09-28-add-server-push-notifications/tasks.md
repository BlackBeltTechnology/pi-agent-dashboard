  - `validateWebhookUrl(raw)`: `http:`/`https:` only, absolute, no userinfo; returns the WHATWG-canonical URL.

  - `resolveAndVet(hostname, port, selfPort)`: all A/AAAA records (`dns.lookup(..., {all: true})`); refuse if any is blocked, or if `port === selfPort` on a loopback/local-interface address (`os.networkInterfaces()`); return the vetted list.
  - `redactWebhookUrl(raw, label?)`: `label (origin)` or `origin`.
- [x] 4.6 Create `push-transports/webhook.ts`: `createWebhookTransport({timeoutMs = 5000})`. Per delivery, `resolveAndVet`, then `undici.request` POST JSON through an `Agent` whose `connect.lookup` returns only the vetted addresses. No redirect following, `headersTimeout`/`bodyTimeout` plus an `AbortSignal.timeout(timeoutMs)`, and `body.dump()` on every response. `2xx` → ok; `410` → gone; everything else (including `404`) → `{ok:false}`. Log only `{transport, target: redacted, status|errorCode, ms}`, never the raw error.
