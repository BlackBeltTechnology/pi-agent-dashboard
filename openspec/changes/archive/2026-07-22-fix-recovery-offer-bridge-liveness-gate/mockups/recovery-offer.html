Recovery offer — process-liveness grace window

Cold-start reopen offer, gated by process liveness. Class-1 keeper-alive candidates never appear. Class-2 bridge liveness resolves asynchronously over a 2.5 s grace window, so during that window Reopen is shown but not actionable — preventing a double-spawn if a surviving bridge is about to reattach.

1 · Verifying (grace window)

Offer visible immediately; Reopen disabled while bridge liveness is unresolved. No click can double-spawn a still-alive session.

Reopen 2 sessions? Checking if still running…

Reopen carries aria-disabled; Dismiss stays available.

2 · Resolved · genuinely lost

Grace window closed with no reattach → sessions are truly gone. Reopen enables for a single clean spawn.

Reopen 2 sessions?

Identical to today's offer once liveness is finalized.

3 · Retracted · bridge reattached

One candidate's bridge reattached within the window → it is dropped from the offer (marker consumed); count decrements live. When the last one retracts the toast disappears.

Reopen 1 session?

Was "2 sessions" → the reattached one silently left.
