The one idea to get right

Three things look similar and are not: serving now is derived and changes by itself; primary is your preference and holds one value per provider; shared is a lending decision that affects other people. Rendering all three as checkboxes would be the single biggest failure available here — so each gets a different control shape.

Architecture note: sign-ins live on the keysync server and never reach a member's machine, so these screens manage a remote pool. Nothing here writes a credential locally.
