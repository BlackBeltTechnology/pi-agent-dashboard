## Fixtures (used by every row)

- Servers: `G1=111`, `G2=222`, `G3=333`. Channels: `c11`, `c12` (in G1), `c21` (in G2), `c31` (in G3). Threads: `t11` (parent `c11`).
- Users: `U1=9001` (allowlisted, admin of G1 only), `U2=9002` (allowlisted, no admin), `U3=9003` (NOT allowlisted), `U4=9004` (admin of G2 only).
- Harness: `FakeAdapter` (`src/adapters/fake.ts`) driven in-process (callbacks, not files), plus the additions under "New infra needed". "outbound" = what the fake recorded as sent. "counter" = a drop counter in the surface. "audit" = `command-log.json` entries. Rows at the adapter chokepoint run the Discord adapter against a stub discord.js client (existing pattern: `adapters/__tests__/discord-provisioning.test.ts`).
- Time-based rows use fake timers or an injected `now`; no real sleeps. Windows are half-open `(now − W, now]`.
- Default `limits` = `LIMIT_DEFAULTS` unless the row names one.
- Platform fault vocabulary (injected by the fake): `429` (rate limited, `retryAfter`), `50013` (Missing Permissions), `50001` (Missing Access), `10003` (Unknown Channel), `10004` (Unknown Guild).
