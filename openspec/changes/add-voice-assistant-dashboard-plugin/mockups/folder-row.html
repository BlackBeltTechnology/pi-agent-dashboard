Why the pill never carries buttons

SlotPill is a single role=button (change move-slot-actions-to-menu): nesting buttons inside it is an ARIA anti-pattern. So every meeting verb is a folder-menu item, and the pill shows state only. One exception: while a meeting is live, a compact Stop renders as a sibling of the pill, outside its button root. This follows the KB card-placement reindex precedent (FolderKbSection), because stopping capture is the one action that must not be two clicks deep (Nielsen #3 user control / emergency exit, Fitts's law).
