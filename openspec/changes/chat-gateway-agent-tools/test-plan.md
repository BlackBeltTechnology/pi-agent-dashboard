Stage: design   Generated: 2026-11-27

Source: proposal, design and specs of this change, A's contract, and the owner's scenario-gap decisions (all recommended options applied; no open clarifications).

Levels: `L1` = vitest `packages/chat-gateway/src/**/__tests__/*.test.ts` against `FakeAdapter` (`adapters/fake.ts`, extended by task 2.3 with fault injection) plus a fake pi API and fake host seam; `L3` = Playwright `tests/e2e/chat-gateway-*.spec.ts` (settings UI only). `Δclock` = vitest fake timers. Fixture baseline F0: guilds X (#gen, #staff not viewable by @everyone, public thread t1 and private thread p1 under #gen), Y (#dev), Z disabled (#z); the bot can view all; `agentTools = {enabled:true, read:{guilds:[X], channels:[Y#dev]}, send:{channels:[X#gen, Y#dev], users:[U1]}}`; session S_u unbound, S_a attached in X, S_s spawned in X (`chatSpawnToken`); limits absent (code defaults).
