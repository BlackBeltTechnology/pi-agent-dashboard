# Test Plan — rich-chat-links

Stage: design   Generated: 2026-11-21

Abbrevs: SRV = `packages/server/src`, CLI = `packages/client/src`, SHR = `packages/shared/src`, E2E = `tests/e2e`. Exemplars marked `new` do not exist yet; every other exemplar exists.
Owner decisions applied (not re-asked):
- HTML chevron + tab toggle;
- pane-first web links with modifier escape;
- server probe (HEAD origin root, opaque sandbox);
- CSP `frame-src 'self' https:`;
- read-only HTML source tab;
- perf budget: batch of 200 on this repo, p95 < 150 ms warm, < 3.5 s cold, ≤ 1 flush/s while scrolling (design.md "Scenario-design decisions").
