# CONTRIBUTING.md — index

Pull-only condensed map. Source: `CONTRIBUTING.md`. The phases are the pipeline; read the phase you are in.

- The shape of it — four phases (explore → plan → build → ship), agent-executed with human gates.
- Phase 0 Explore — decide whether the thing is worth building; interview for intent before specs.
- Phase 1 Plan — write the OpenSpec spec, review it adversarially, design the test scenarios.
- Phase 2 Build — the agent writes code in the worktree and gates itself (red tests, enforcers, review).
- Phase 3 Ship — PR, CI, CodeRabbit review loop, squash-merge, worktree cleanup.
- Phase 4 CI — what the machine checks on every push.
- The inner loops — what stops each loop (tests, lint, review) and why.
- Bugfixes — the same pipeline, compressed.
- Things that will annoy you — deliberate friction, with reasons.
- Quick reference — commands and file locations.
