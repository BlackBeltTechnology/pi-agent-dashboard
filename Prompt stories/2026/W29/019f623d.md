## 1. Goal (the ask)

The session opened in **explore mode** (`openspec-explore` — think, don't implement),
and the operator's real question was: *is the way we install Playwright's Chromium

## 2. TL;DR playbook

1. Reproduce first, don't theorize: actually run `npx playwright install chromium 2>&1 | tail -15`.
2. Read the error at the network layer — `Download failure, code=1` + a TLS socket timeout means the **command is fine, the CDN is blocked** (proxy/firewall/offline/flaky). The invocation shape (`2>&1 | tail`) is a red herring.
3. Grep the repo for the canonical install docs: `grep -rn "playwright install" --include="*.md" .` (skip `node_modules`).
4. Find the escape hatches already in the repo: `npm run test:e2e:chrome` (system Chrome, no bundled download) and `PLAYWRIGHT_DOWNLOAD_HOST=<mirror>`.
5. Ask "where does this belong?" — for setup/how-to, the Investigation Protocol says grep `README.md` + `docs/` first. Answer here: `tests/e2e/README.md` Prerequisites (NOT under `docs/`, so edit directly, no DocScribe subagent).
6. Add a **Troubleshooting** subsection: symptom → "command is fine" → Fix 1 (`test:e2e:chrome`) → Fix 2 (`PLAYWRIGHT_DOWNLOAD_HOST`).
7. Also try to save a durable memory (`failure`/`tool-quirk` + `project`) so cross-session recall works.
8. Commit only that one file: `git diff` it, `git add` just that path, leave unrelated untracked files alone.

## 7. Pitfalls & dead ends

- **If `npx playwright install chromium` fails with `Download failure, code=1` / TLS
  timeout → don't blame the command.** It's the CDN being unreachable. Use
  `npm run test:e2e:chrome` (system Chrome) or set `PLAYWRIGHT_DOWNLOAD_HOST=<mirror>`.
- **`2>&1 | tail` hid the top of the error** — when debugging, widen the tail (or drop
  the pipe) so you see the real root cause line.
- **Memory stores full → writes silently useless.** `failure` and `project` were at
  capacity, so the intended memory never landed. If durable recall matters, run
  `consolidate-pi-memory-store` first, or rely on the canonical doc.
- **Don't `git commit -a`** with unrelated untracked files present — add explicit paths.
