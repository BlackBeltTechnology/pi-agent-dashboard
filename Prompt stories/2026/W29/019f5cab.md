## 2. TL;DR playbook

1. Ask the source question naming the exact package (`@blackbelt-technology/pi-dashboard-subagents`), not a fuzzy alias.
2. Run the repo's own tool: `npx tsx .pi/skills/switch-extension-source/scripts/switch-source.ts status` to see per-package local-vs-npm sources.
3. Realize the subagents package is a **separate repo** — the monorepo's `switch-source.ts` does not manage it. Its wiring lives in global `~/.pi/agent/settings.json` `packages[]`.
4. Grep the global settings for the package: `grep -iE 'subagent' ~/.pi/agent/settings.json` → confirm it reads `npm:@blackbelt-technology/pi-dashboard-subagents`.
5. Validate the local target: the dir exists, its `package.json` name matches, and it declares `pi.extensions` (so pi resolves a bare dir path).
6. Back up settings first: `cp ~/.pi/agent/settings.json ~/.pi/agent/settings.json.bak-subagents-$(date +%Y%m%d%H%M%S)`.
7. Edit `packages[]`: replace `npm:@blackbelt-technology/pi-dashboard-subagents` with the absolute local path `/Users/robson/Project/pi-dashboard-subagents`.
8. Re-validate JSON with a one-liner (`python3 -c "import json; ..."`) and confirm the package count is unchanged.
9. Tell the user to **respawn** — `packages[]` is read at session init; a reload of a running session won't re-resolve.

## 7. Pitfalls & dead ends

- **Fuzzy package name.** The literal string `pi-dashboard-agents` matches nothing; the real names are `-extension` and `-subagents`. If a source probe returns "no exact match," list the near-neighbors before concluding.
- **Wrong tool reflex.** The monorepo `switch-source.ts` won't switch a separate repo. If the package isn't in the monorepo's status output, it's wired in global settings — edit there.
- **Typo'd path.** The steering turn said `pu-dashboard-subagents`; the real dir is `pi-dashboard-subagents`. Confirm with `ls -d` before trusting a hand-typed path in a config write.
- **Reload ≠ re-resolve.** `packages[]` is read only at session init. Editing settings while a session runs does nothing until you respawn/restart the TUI.
