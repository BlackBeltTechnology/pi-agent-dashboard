# How we did it: Directory card redesign — an AI collaboration guideline

> A reusable playbook reconstructed from a real pi session. It explains **what was
> asked, how it was built with the AI, what had to be steered, and how to reproduce
> the result faster next time.** Write for a future operator who has the same goal.

---

## 1. Goal (the ask)

The session opened in **OpenSpec explore mode** — a *thinking* stance, not an implementing
one. The literal first prompt was the boilerplate skill preamble ("Enter explore mode.
Think deeply. Visualize freely…"), so the real goal only crystallized through the second
prompt onward: **redesign the pi-dashboard directory card** — the folder-group header in
`SessionList.renderGroup` that crams four plugin slots (Automations, OpenSpec, KB, spawn
buttons) into dense one-line text rows. The objective was to make it **scannable**: break
the slots into self-contained pills, add a distinctive **3D half-open folder watermark**,
and detach the spawn buttons from the card body — then extend the same design discipline to
the four inline message/log surfaces, and finally **formalize both into one OpenSpec change**
with proposal → design → specs → tasks. No production code was touched; the whole session
lived in mockups + OpenSpec artifacts.

## 2. TL;DR playbook

1. **Ground in the real component + tokens first.** `kb_search` + targeted `grep` to find
   `SessionList.renderGroup`, `FolderSpawnButtons`, the `Folder*Section` slots; then read the
   theme CSS so the mockup uses **real design tokens**, not invented colors.
2. **Build a self-contained HTML mockup** (`directory-card.html`) showing *before vs after*,
   faithful to the real tokens, and `serve_mockup` it onto the canvas.
3. **Verify visually with the browser skill** (agent-browser), not Playwright — screenshot
   light + dark themes; force dark via a `#dark` URL param + cache-bust when a stale tab drifts.
4. **Iterate the folder icon in tight loops.** CSS-tilted SVG → too flat → `mdiFolderOpenOutline`
   (the app's own glyph) → still flat → **nano-banana renders a 3D folder** → knock out the white
   background → **posterize to ~6 flat tones, THEN vtracer** into a clean low-color icon SVG.
5. **Save the non-obvious trick as a global skill** (`raster-3d-icon-to-flat-svg`): posterize
   *before* tracing is the key that keeps the 3D planes from collapsing to one blob.
6. **Widen scope on request** — review all four inline message/log surfaces, mock a unified
   `InlineMessage` + `LogBlock` pair (`inline-logs.html`) exposing the two-token-system problem.
7. **Formalize one combined OpenSpec change** via the CLI: `proposal.md` (2 new / 2 modified
   capabilities), then **fast-forward** design → 4 spec deltas → tasks.
8. **Validate the change parses, then scope the commit** to only the `redesign-directory-card/`
   files — leave unrelated dirty tree untouched.

## 3. How the collaboration unfolded

**Phase 1 — Discovery & grounding.** The AI resisted the temptation to mock from imagination:
it grepped out the actual `SessionList.renderGroup`, the slot components, and the spawn buttons,
then extracted the **theme tokens** (`--bg-*`, `--text-*`, `--accent-*`, `--severity-*`) from
`index.css` so the mockup would be theme-faithful. *Why it worked:* a token-grounded mockup is
directly translatable to real components later — no color guesswork to redo.

**Phase 2 — Mockup + visual verification.** Built `directory-card.html` (before/after), served
it, and screenshotted via **agent-browser** after Playwright's browser turned out uninstalled.
First render exposed a real defect — a muddy watermark "box" bleeding through translucent pills —
fixed by centering/enlarging the watermark and making pills opaque. *Decision point:* the human
approved the pill-grid + detached-tray direction, so the shape was locked early.

**Phase 3 — The folder-icon odyssey (5 steering turns).** This is where most of the session went.
The human rejected each attempt in short succession: "be a half-open folder rotated 3d" → "don't
look as folder" → "glyph not correct" → "maybe nano banana can help?" → "convert SVG… icon style
not much color". The AI walked the full ladder: CSS `perspective/rotateX` tilt (blob) → real
`mdiFolderOpenOutline` glyph → **nano-banana AI render** of a 3D folder → background knockout →
**posterize-then-vectorize** into a 5-path/5-color SVG. *Why the final approach won:* posterizing
to flat tones *before* `vtracer` preserves the folder's planes; tracing the photoreal gradient
directly collapses to one flat blob.

**Phase 4 — Scope expansion to inline surfaces.** "There are functions which inline messages, logs
in card — check that too" → "all of them". The AI located four surfaces (`SpawnErrorBanner`,
`SessionBanner`, `MissingToolInlineError`, `FlowAgentCard` log preview), read each, and built
`inline-logs.html` surfacing the core finding: **each was designed in isolation → four visual
languages + two token systems** (proper `--severity-*` vs hardcoded `red-500/amber-500`). It
proposed unified `InlineMessage` + `LogBlock` primitives.

**Phase 5 — Formalize + commit.** On "propose", the AI scaffolded **one combined** OpenSpec change
via the CLI, wrote `proposal.md`, then on the `openspec-ff-change` skill **fast-forwarded**
design → 4 spec deltas (2 ADDED, 2 MODIFIED — copying exact existing requirement blocks) → tasks.
It validated the change parses clean, then **scoped the commit** to only the 15 change files,
deliberately leaving the unrelated dirty tree (CHANGELOG, docker, pnpm) untouched.

## 4. Prompts that worked

- **The goal prompt (explore-mode preamble).** Effective because it set a *stance* — "think, don't
  implement" — that kept the whole session in mockups + artifacts, so nothing risky landed. A
  stronger kickoff would name the target up front: *"Explore-mode: redesign the directory card in
  `SessionList.renderGroup` — fragment the four slots into pills, add a 3D folder watermark, detach
  the spawn buttons. Mock it with real theme tokens first."*
- **High-leverage follow-ups.** `"all of them"` (one prompt → review all four inline surfaces),
  `"propose"` (one word → formalize the whole approved design), `"commit"` (scope + land). These
  worked because the AI had already surfaced concrete options, so a terse confirm carried a lot.
- **Rewrite weak prompts:** the icon-steering chain ("don't look as folder", "glyph not correct")
  was slow because it never said *what good looked like*. Better: *"Use the app's own
  `mdiFolderOpenOutline` glyph, or an AI-rendered 3D folder posterized+vectorized into a low-color
  icon SVG — subtle watermark, ~10% opacity, centered over the pill grid."* — collapses 5 turns to 1.

## 5. Steering & corrections (what to watch for)

| The AI tended to… | The human had to steer by… | Bake this in next time by… |

## 6. Skills, tools & memory created — and why they're effective

- **`raster-3d-icon-to-flat-svg` (global skill, created).** Captures the reusable pipeline:
  *AI render (nano-banana) → background knockout → **posterize to ~6 flat tones** → vtracer →
  low-color scalable SVG.* **Why effective:** it encodes the single non-obvious insight — posterize
  *before* tracing — that took several failed iterations to discover; direct tracing of a photoreal
  gradient collapses to one blob. **Invoke when:** you need a scalable flat-icon SVG that resembles
  a 3D render (watermarks, UI glyphs) and a direct trace produces a flat blob.
- **`nano-banana-imagegen`** (used) — text-to-image render of the 3D folder; note the default model
  wasn't accessible, so `--list-models` was needed to pick a working image model.
- **`serve_mockup` + agent-browser + `score_mockup`** (used) — the verify loop: serve HTML, screenshot
  light/dark, catch visual defects (the muddy watermark box) before formalizing.

## 7. Pitfalls & dead ends

- **Playwright browser not installed** → `score_mockup`/Playwright screenshots failed. *Fix:* use the
  **browser skill (agent-browser)** for screenshots instead.
- **Stale browser tab drift + cached HTML** → dark theme "didn't apply." *Fix:* force theme via a
  `#dark` URL param with a tiny init script, and **cache-bust** the URL on reload.
- **nano-banana default model inaccessible** → `--list-models | grep image` to find a working one.
- **Direct vtracer on the photoreal render → one flat blob.** *Fix:* `magick -kmeans 6` posterize
  first, then trace — preserves the front/edge/inside/paper/tab planes.
- **`openspec validate` "error" right after writing proposal.md** was expected — it just flags that
  `specs/` deltas + `tasks.md` aren't written yet. Don't chase it; fast-forward the remaining artifacts.
- **Dirty working tree at commit time** (CHANGELOG, docker, pnpm, unrelated untracked) → scope the
  commit explicitly to the change dir, never `git add -A`.
