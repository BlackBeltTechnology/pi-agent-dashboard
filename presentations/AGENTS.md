# DOX — presentations

Author-side deck sources. Each subdir = one deck3d presentation. Build with
`packages/deck3d/bin/deck3d build <dir>/deck.md -o <dir>/deck.html`. Tune via
inline `<!-- deck3d: {...} -->` overrides, never by editing `deck.html`.

| File | Purpose |
|---|---|
| `business-next-5-years/deck.md` | Source outline. 23 slides, 25 min. Business change 2026-2031 for software/IT-services sales. 4 mermaid diagrams (3 flowchart, 1 sequence). Front-matter: dark/blackbelt/glass/high; `overrides.deck.palette` restyles it to `midnight`. See change: deck3d-cinematic-worlds. |
| `business-next-5-years/deck.json` | Derived IR. Regenerated by `parse`/`build`. Do not hand-edit below `slides[]`. |
| `business-next-5-years/deck.html` | Rendered offline deck. Generated artifact. `check: clean` + `style: 23/23 slides styled`. See change: deck3d-cinematic-worlds. |
| `business-next-5-years/` (no `fx/`) | Deck carries NO local effects. All eight promoted into the corpus (`deck3d/src/fx/`) via `fx promote`; deck references them as plain corpus presets `{id:"<name>"}`, no `sha256` pin. Renamed on promote: `horizon-2031`→`horizon-gates`, `workforce-100`→`cohort-grid`. Deck-specific `0.59` cohort split now passed as `params.share`, not baked in. See change: deck3d-cinematic-worlds. |
| `business-next-5-years/speaker-notes.md` | Per-slide timing table (25 min), Q&A prep, source list. |
| `business-next-5-years/s*.png` | Snapshot previews of styled slides (1, 6, 9, 15, 16, 20) after the Style pass. Regenerate with `deck3d snapshot deck.html --slide n -o sn.png`. See change: deck3d-cinematic-worlds. |
