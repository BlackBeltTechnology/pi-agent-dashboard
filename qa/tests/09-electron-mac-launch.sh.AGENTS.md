# 09-electron-mac-launch.sh — index

macOS in-CI Electron launch smoke. Resolves `.app` from `packages/electron/out/PI-Dashboard-darwin-*/` (forge package output), falls back to copying out of mounted DMG (`xattr -dr com.apple.quarantine` on copy). Direct-execs inner Mach-O `Contents/MacOS/pi-dashboard` (NOT `open`); no `--no-sandbox`. Wipes `~/.pi/dashboard/server.log` pre-launch. Seeds `~/.pi/dashboard/first-run-done` pre-launch to skip blocking welcome-wizard window (else server spawn waits on wizard close, no CI user). Launches `--disable-gpu` (no usable runner GPU; macOS analog of xvfb). Polls `/api/health` ≤120s; asserts HTTP 200, `launchSource==electron`, server.log size>0, no `FATAL` in Electron stdout. `SKIP:`+exit 0 when `.app` absent. Boot-proof not floor-proof (runner macOS 14/15 above the 12.0 floor; static `otool minos` check in `_electron-build.yml` is label-only floor guard). Floor raised 10.15 → 12.0 by change: upgrade-electron-runtime. Invoked from macOS legs of `.github/workflows/_electron-build.yml` after floor check. Pre-launch seeds a `.bin/openspec`→`bin/openspec.js` shebang symlink + `~/.config/openspec/config.json` (profile core); post-health asserts `GET /api/openspec/config` returns 200 + profile core (pre-fix stripped-PATH shebang dies 127→502), SKIP if seed uncreatable. See change: add-macos-electron-launch-smoke, fix-openspec-config-read-bundled-node.
