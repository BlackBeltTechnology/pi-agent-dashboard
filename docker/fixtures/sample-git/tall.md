# Tall preview fixture

Deliberately longer than any dialog height cap (>= 92vh + 500px at every
viewport in the E2E matrix). `tests/e2e/overlay-layout.spec.ts` opens this
through `/folder/:cwd/view?path=tall.md` to exercise the tall-content half of
the flush-dialog layout gate: the panel must clamp at its cap and a descendant
must become a working scroller.
