# lib-ports.sh — index

Sourced pure-helper lib. Exports `derive_hash(cwd)` (cksum), `derive_project(cwd)` -> `pi-dash-test-<hash>`, `is_free(port)` (bash /dev/tcp check), `find_free_in_window(start,lo,hi)` (wrap scan, cap=window size). Windows: dashboard 18000-18999, gateway 19000-19999. See change: parallelize-test-harness. Exports `list_running_harness_projects(self)` — other running `pi-dash-test-*` compose projects, one per line, excluding `self`; always exits 0 (empty = no information, never an error). Exports `parse_memory_bytes(limit)` — `4g`/`512m`/`1gb`/bytes -> bytes, exit 1 on unparseable. Exports `human_bytes(n)` — exact GiB/MiB else raw bytes, for guard messages. See change: stabilize-browser-e2e.
