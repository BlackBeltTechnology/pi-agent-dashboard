# DOX — packages/untrusted-content-guard/src/scanner

Deterministic scanner layers (design D1). Pure; same input → same output + findings. See change: add-untrusted-content-guard.

| File | Purpose |
|------|---------|
| `ansi.ts` | `ansiLayer(text, findings)` — strips OSC/CSI/8-bit CSI/2-char ESC; one HIGH `ansi` finding, count = sequences. Fast path without ESC/0x9B. |
| `css.ts` | Minimal CSS model for the HTML layer. `buildCssIndex(stylesheets, findings)` indexes simple type/.class/#id rules, collapsing each key to ONE winner per property (linear; no per-element rule replay); complex hiding selector → LOW `unresolved_css`. `resolveDecls(name, attribs, index)` cascades `!important` → specificity (type<class<id<inline) → source order. Comments stripped by linear `indexOf` scan (`display:/**/none` hides); CSS escapes decoded in names/values (`n\6fne` = `none`). `hidingReason(decls)` → `html-display-none`/`-visibility-hidden`/`-font-size-0`/`-opacity-0`/`-color-match`/`-offscreen` or null. |
| `findings.ts` | `Finding {layer,severity,count,sample}`, `FindingSet` (aggregate by layer id, first sample, insertion order), `visibleEscape` (invisibles → `U+XXXX`), `truncateSample` (≤ `SAMPLE_MAX`=80). |
| `html.ts` | `isHtml(text, contentType?)` (`text/html` or `^\s*<(!doctype html\|html)`). `htmlLayer(src, findings, {apply, allowHosts})`: parser PREPASS `collectStylesheets` (real `<style>` text only) → `css.ts` index; main htmlparser2 pass on source ranges removes hidden elements holding text or comments (`hidden` attr, `<script>`, cascaded hiding CSS) and top-level comments; rewrites only changed decoded text nodes (Unicode → ANSI → URL, re-escape `&<>`); URL checks on DECODED `URL_ATTRIBUTES` (also inside hidden markup; `data:` → HIGH + value-only edit via quote-aware `attributeValueRange`, first occurrence wins; `<img src>` tracking; host confusable) and on decoded `<a>` descendant text (design D1 amendment). Never re-serialises; `applyEdits` copies everything between edits byte-for-byte. Implied close → range ends at trigger `startIndex`; EOF-unclosed → end of document. |
| `phrase.ts` | `phraseLayer` — versioned (v1, in header comment) instruction-phrase regexes; LOW `phrase` only, never removes. |
| `scan.ts` | `scan(input, {mode,contentType,allowHosts,maxChars})` → `{cleaned,findings,html}`. Order: `MAX_SCAN_CHARS` (2 MiB) cap + HIGH `oversize_truncated` → HTML layer (runs Unicode/ANSI/URL itself on decoded data; parser throw → HIGH `html_parse_failed` + plain-text fallback) OR plain text Unicode → ANSI → URL → phrase (always). Document-level URL pass never runs on HTML. `warn` returns capped input unchanged. |
| `unicode.ts` | `unicodeLayer(text, findings, rtlContext?)` — HIGH `unicode-zero-width`/`unicode-tags`/`unicode-variation-selectors`/`unicode-bidi`; LOW `unicode-bidi-rtl` (kept). Preserves emoji ZWJ, Brahmic/Arabic ZWJ/ZWNJ only with a cluster script on BOTH sides, ZWSP beside Thai/Lao/Khmer/Myanmar/CJK, LRM/RLM. Never entity-decodes. `hasRtl`. |
| `url.ts` | `urlLayer(text, findings, {replaceData, allowHosts})` for plain text / decoded HTML text nodes — HIGH `data-url` (case-insensitive; strip/block → `[data-url removed: <mime>, <n> bytes]`); LOW `tracking-image` (markdown / literal `<img>` query-string URL, host not allowed); LOW `confusable` (Latin + Cyrillic/Greek word in domain, markdown or literal `<a>` text). Exports helpers for the HTML layer: `checkImage`, `checkConfusable`, `hostOf` (as written, never punycoded), `dataUrlPlaceholder` (canonicalises like the URL parser: strips tab/LF/CR, leading C0/space). Tag scans bounded `{0,2000}`. |
