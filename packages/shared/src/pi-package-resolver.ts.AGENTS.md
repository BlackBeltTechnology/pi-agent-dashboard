# pi-package-resolver.ts — index

Walks `~/.pi/agent/settings.json#packages[]` + per-workspace `<cwd>/.pi/settings.json`. Resolves `npm:` / `git:` / `https:` / abs / rel sources to absolute install dir. Returns entry path via `exports["."]` → `main` → `pi.extensions[0]` → `index.{js,ts}` chain. Read-on-call (no cache). Exports `resolvePiPackage` + `resolvePiPackageEntry`. Consumers import from `@blackbelt-technology/pi-dashboard-shared/pi-package-resolver.js`. Exports `listPiPackages(opts)` returning `ResolvedPiPackage[]` across user (`~/.pi/agent/settings.json`) + project (`<cwd>/.pi/settings.json`) scopes, deduped by `packageDir`, no name filter; consumed by Electron `probePiExtension` in `launch-source.ts`.
