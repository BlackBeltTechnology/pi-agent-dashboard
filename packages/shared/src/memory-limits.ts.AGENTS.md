# memory-limits.ts — index

BROWSER-SAFE memory-limit types + defaults: `MemoryLimitsConfig`, `MIN_REPLAY_WINDOW` (100), `DEFAULT_MEMORY_LIMITS`. Split out of `config.ts` because that module imports `node:fs`/`node:os`/`node:path` at module scope, so a VALUE import of it from `packages/client` puts node built-ins in the browser bundle and the SPA dies at boot with `uv.homedir is not a function` — a blank page, with tsc, vitest and the build all green (`import type` stays safe). `config.ts` re-exports all three, so existing importers are unaffected. Guarded by `packages/client/src/__tests__/no-node-only-shared-imports.test.ts`. `maxReplayEvents` default `2000` (was `0`); explicit `0` = unlimited = rollback lever. See change: fix-lazy-history-backfill-ux (D7). Adds `ReplayWindowMode` (`head-tail` \| `tail-only`) and `MemoryLimitsConfig.replayWindowMode`, default `head-tail`. SERVER-scoped — consulted before any per-client preference, so it reshapes the transcript for every client of that server. `MIN_REPLAY_WINDOW` clamping stays MODE-INDEPENDENT now that head-free windows are reachable. See change: add-tail-only-replay-window (D1). Adds `MemoryLimitsConfig.maxBytesPerSession` (default 33554432 / 32 MiB), `maxTotalEventBytes` (default 805306368 / 768 MiB) and `maxCachedSessions` (default 32); the two byte budgets share the `maxReplayEvents` presence rule (absent/negative/non-numeric → default, explicit `0` preserved, positive loaded AS-IS — the STORE applies the floor clamp). `DEFAULT_MEMORY_LIMITS.maxCachedSessions` MUST equal the store's `DEFAULT_MAX_CACHED_SESSIONS` (different packages; asserted by a test). See change: bound-event-store-by-bytes (D5-D8).
