# e2e-browser-workflow-contract.test.ts

Repo-lint contract for `.github/workflows/ci-e2e-browser.yml` (change: stabilize-browser-e2e, #433 part 2). Triggers: `workflow_dispatch` + `shards` input; `pull_request` gated on the `e2e-browser` label; NO `push`; `schedule` in exactly ONE of active (cron) / land-dark (commented, must cite the enabling condition) form — never both. Shard matrix: more than one entry, and EVERY `--shard=${{matrix.shard}}/N` denominator equals the matrix length (the vacuity that would silently run zero specs); `timeout-minutes` >= number of `runs-on` (every job bounded — the only whole-run budget once `globalTimeout` is gone, #450); `PI_E2E_SEED` seeded; `if: always()` teardown naming `docker/test-down.sh` on the step header; per-shard blob upload; per-shard `harness-failure.log` upload (globalSetup's container state+log snapshot when the boot never goes healthy — the bundle that makes an otherwise causeless "never became healthy" diagnosable); `merge-report` uploads `playwright-report`; `merge-report` guarded by `always() && needs.e2e.result != 'skipped'` (a bare `always()` reds every unlabeled PR); the merge toolchain comes from the lockfile (`pnpm exec playwright merge-reports`), no hardcoded `playwright@x.y.z`; PR path advisory via `continue-on-error: ${{ github.event_name == 'pull_request' }}`; and the `e2e-browser-relay` VARIANT leg exists (its own job: `PI_BROWSER_RELAY_FAKE=1` + `PI_E2E_SEED=1`, runs only `tests/e2e/browser-relay.spec.ts`, uploads `blob-report-relay`, bounded/label-gated/PR-advisory/always-teardown) — without it the relay spec's file-level `test.skip` would drop that whole file from CI silently; `merge-report` `needs` both legs. Pattern: `nightly-workflow-contract.test.ts`.
