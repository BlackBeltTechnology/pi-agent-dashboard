# url-policy.ts — index

`classifyUrl(raw, origin | null)` → `internal | loopback | external | mailto | blocked` for navigation targets (`<a href>`, `window.open`, `location.*`, `openExternal`); media sources and the markdown protocol set stay with `safeUrlTransform` / `is-external-href.ts`. Pure (WHATWG `URL` only), never throws. Raw pre-scan: edge C0 / whitespace trimmed; any remaining C0 control, DEL or backslash → `blocked`. Loopback (`127/8`, `::1`, `localhost`, `localhost.`, `*.localhost`) decided on the parser-normalized hostname. Same origin wins over loopback; scheme-relative input is never `internal`; `origin = null` (Electron main) → relative / scheme-relative `blocked`. Used by client chokepoints, plugin runtime SDK, Electron `isAllowedExternalUrl`, OIDC endpoint check, nav-intent mint. See change: harden-client-sinks.
