# dashboard-paths.ts — index

Single-source path helpers for dashboard runtime dirs. `getDashboardConfigDir` → `~/.pi/dashboard/`. `getDashboardServerLogPath` → `~/.pi/dashboard/server.log` (live server log). `getManagedDir` re-export → `~/.pi-dashboard/`. `getInstallerLogPath` → `~/.pi-dashboard/server.log` (legacy installer log, distinct from server log). All accept `DashboardPathsEnv = { homedir? }` override for test isolation. See change: harvest-bootstrap-survivor-fixes. Adds `resolvePiSessionsDir(env?)`: resolves pi sessions root dashboard scans. Precedence: `config.json#piSessionsDir` → `PI_CODING_AGENT_SESSION_DIR` → `PI_CODING_AGENT_DIR`+`/sessions` → literal `~/.pi/agent/sessions`. Trims each layer; blank falls through; leading `~/` expands against `homedir`. `DashboardPathsEnv` gains `piSessionsDir?`, `sessionDirEnv?`, `agentDirEnv?` (latter two test seams). Reads `PI_CODING_AGENT_DIR` directly, not pi-core import (pi-core `.d.ts` barrel unresolvable under `moduleResolution: bundler`). See change: configurable-pi-sessions-dir.
