# config.ts — index

Dashboard config loader. `loadConfig()` reads `~/.pi/dashboard/config.json` via `CONFIG_FILE`; `ensureConfig()` seeds defaults. Exports `DashboardConfig`, `AuthConfig`, `OpenSpecPollConfig`, `ModelProxyConfig`, `SpawnStrategy`, `ReattachPlacement`, `parseReattachPlacement`, `parseModelProxyConfig`, `getPluginConfig`, `clampSpawnRegisterTimeoutMs`. v2 (support-zrok-v2): `tunnel.zrok` gains `reservedName?`/`persistent?` (default false, in DEFAULTS + `normalizeTunnelConfig`); legacy `reservedToken` preserved on read but NOT promoted to `reservedName`. External-editor `EditorConfig`/`parseEditorConfigForTest` removed (change: remove-external-editor-integration). `AuthConfig` gains optional `redirectBaseUrl?` (OAuth redirect-URI base; trimmed, blank omitted, parsed in `parseAuthConfig`). Top-level `publicBaseUrls?: string[]` promotes the legacy `pairing.publicBaseUrls`; read via `resolvePublicBaseUrls(config)` (top-level first, legacy fallback, else `[]`). Deliberately NOT in `DEFAULTS` and never seeded by `ensureConfig()` — absence is what selects the legacy fallback, and it is not an OAuth source (D7). Adds `GatewayAuthMode`/`GatewayWroteRecord`/`GatewayRecord` + optional top-level `gateways?: GatewayRecord[]` (provenance of what the add-gateway action wrote; malformed entries and unknown modes filtered, never defaulted). See change: config-override-oauth-redirect-base. `ModelProxyConfig` + `parseModelProxyConfig` gain optional `preferredModels?: string[]` (ordered, drop non-string/empty, omit empty) + `modelAliases?: Record<string,string>` (drop non-string/empty key or value, omit empty). See change: fix-and-prefer-model-proxy-resolution. Adds `EmbedLifecycleConfig` + `DEFAULT_EMBED_LIFECYCLE` (`config.embedLifecycle`, default-inert `enabled:false` + idle/hardCeiling/grace/sweep/register seconds + per-visitor & global caps), parsed clamped via `parseEmbedLifecycleConfig`. See change: add-embed-session-lifecycle.

`MemoryLimitsConfig.maxReplayEvents: number` (default `0` = unlimited) caps events replayed to a browser on a FULL-stream subscribe. `parseMemoryLimits`: absent / non-numeric / negative / `NaN` / `Infinity` → `0`; positive below exported `MIN_REPLAY_WINDOW` (100) clamps UP to 100; `0` never clamped; fractional floored. Requires server restart. See change: lazy-load-session-history (D3, D13).
