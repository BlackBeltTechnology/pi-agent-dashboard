| `git-fixtures.ts` | Builds the nine git states as REAL repos in a temp dir: normal (+ deep subdir), linked worktree, superproject, submodule, worktree-of-submodule, `clone --bare` hub, worktree-of-bare, `--separate-git-dir`, a checkout named `app.git`, plus a non-repo. See change: add-git-checkout-root-resolver. |
