| `git-fixtures.ts` | Builds the nine git states as REAL repos in a temp dir: normal (+ deep subdir), linked worktree, superproject, submodule, worktree-of-submodule, `clone --bare` hub, worktree-of-bare, `--separate-git-dir`, a checkout named `app.git`, plus a non-repo. Exports `buildGitFixtures()` → `GitFixtures` (paths + `cleanup()`), `fixtureGit(cwd,args)`, `probeTriple(cwd)`, `FIXTURE_GIT_ENV`. Every git call sets `GIT_CONFIG_GLOBAL=/dev/null` + `GIT_CONFIG_SYSTEM=/dev/null` (else a developer's own `core.worktree` leaks into assertions) and `submodule add` passes `-c protocol.file.allow=always` (CVE-2022-39253). Lives in `test-support/` not `__tests__/` so extension + kb-plugin suites can import it across packages. `execFileSync` from `platform/exec.js` (the `no-direct-child-process` rule). See change: add-git-checkout-root-resolver. |

See change: add-pi-gateway-transport-identity. |
