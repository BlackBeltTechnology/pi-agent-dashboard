# server-identity.ts — index

Identity-verified dashboard detection over GET /api/health. Exports `DashboardStatus`, `DashboardCheckOpts`, `isDashboardRunning(port, host?, opts?)`. Replaces bare TCP port probe; flags `portConflict` for foreign JSON on HTTP 200. Bounded retry loop via `opts.retries` / `timeoutMs` / `retryDelayMs`; defaults preserve legacy single-attempt 2 s behaviour. Retry semantics: retries on AbortError (timeout) / 5xx only — ECONNREFUSED is definitive and never retried; `portConflict` short-circuits. `_sleep` opts seam for retry-delay tests. The bridge auto-start consumes this signature (widened seam) to probe candidates at their advertised host + bootstrap-aware opts — see `server-auto-start.ts.AGENTS.md` and change fix-autostart-discovery-precedence (task 1.1).
