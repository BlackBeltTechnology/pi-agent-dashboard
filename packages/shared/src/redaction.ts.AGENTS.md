# redaction.ts — index

`REDACTION_VERSION`=1; `REDACTION_PATTERNS_V1` (linear-time, `(?<!…)` run-start lookbehinds not `\b`; callers cap input first): PEM/PGP private key (unclosed → end of input), `Authorization: Bearer|Basic`, `Bearer`, `sk-`, quoted/unquoted `key=value` (api/access/secret key, client_secret, aws secret, password), env-style `*_TOKEN|SECRET|PASSWORD|API_KEY=`, AWS `AKIA`, JWT, GitHub, Slack, Google, Stripe, npm, URL `user:pw@` (keeps scheme/user/host), `?token=|key=|sig=`. `redactSecrets(text)` replaces matches with `[REDACTED]`; a pattern whose first capture group is defined keeps that group (URL prefix, query name). Best-effort, not a security boundary. Bump version + add `_V<N>` when patterns change. Test: `__tests__/redaction.test.ts`. See change: add-pending-question-stack.
