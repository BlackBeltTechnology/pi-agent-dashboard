# tunnel-core.ts — index

Provider-neutral child-tunnel lifecycle. Exports `ChildTunnelRuntime` (PID helpers, spawn→timeout→retry→URL-match state machine (`SPAWN_TIMEOUT_MS` = 90s: hosted zrok.io POST /share can land ~35s; a 30s kill orphaned the share + 409-locked the reserved name), `cleanupStale`, `scavengeOrphans`, `createTunnel`/`deleteTunnel`/`getTunnelUrl`) + `ChildProviderSpec` interface (binary, buildArgs, urlRegex, optional `normalizeUrl` post-match hook — e.g. prepend scheme to a bare host, reserve/release, markers, toEndpoints). Daemon providers skip this entirely (`kind==='daemon'`). See change: add-tunnel-providers.
