# DOX — packages/server/src/model-proxy

Files in this directory. One row per source file.

| File | Purpose |
|------|---------|
| `api-key-store.ts` | Pure proxy API-key helpers: `hashKey` (sha256 hex), `verifyKey` (constant-time), `generateKey` (`pi-proxy-<48 base64url>`), `findApiKey` (discriminated `FindResult`: valid/revoked/expired/miss), `recordKeyUsage` (60s-debounced lastUsedAt), `keyHasScope` (`"all"` matches any). Types `FindResult`, `ProxyScope`. |
| `auth-gate.ts` | Fastify `onRequest` hook factory `createModelProxyAuthGate` for `/v1/*` proxy routes. Extracts bearer token, enforces `pi-proxy-` prefix, applies `FailedAuthBackoff` delay, calls `findApiKey`/`keyHasScope`/`recordKeyUsage`, attaches `proxyApiKeyId`/`proxyApiKeyLabel` to request. Returns 401/403 codes `AUTH_REQUIRED`, `AUTH_MALFORMED`, `PROXY_KEY_REQUIRED`, `AUTH_REVOKED`, `AUTH_EXPIRED`, `SCOPE_INSUFFICIENT`. On success ALSO sets `request.isAuthenticated = true`, which is how the universal network guard (registered AFTER this gate) admits proxy traffic — there is deliberately no public `/v1` allowlist entry, so a proxy-disabled `/v1` is not silently open. See change: add-universal-network-guard. |
| `concurrency.ts` | Nested concurrency limiter `ConcurrencyTracker.acquire({apiKeyId, provider}, config)` returns release() callback; throws `ConcurrencyError` with codes `SERVER_FULL`/`KEY_FULL`/`PROVIDER_FULL` + `retryAfterMs`. Tracks server-wide, per-key, per-provider counts; reads caps from `ModelProxyConfig` at acquire time for live config updates. |
| `failed-auth-backoff.ts` | Per-source-IP exponential backoff for failed proxy auth. Class `FailedAuthBackoff`: `record(ip)` doubles delay from 10ms cap 10s, `reset(ip)` on success, `getDelayMs(ip)` peeks. In-memory only. |
| `custom-provider-discovery.ts` | Server-side custom-provider discovery (Approach C). Exports `discoverProviderModels(name, entry)` + `discoverAllCustomProviders(providers)`: for each `providers.json#providers` entry resolves apiKey (`resolveProbeApiKey`) + lists `/v1/models` (`listProviderModelIds`), returns `CustomModelEntry[]` carrying provider `baseUrl`/`api` + api-typed fallback capability floors. Never throws (unreachable provider → []). NO models.json. See change: add-agent-role-model-tools. |
| `internal-auth-storage.ts` | Server-resident auth storage `InternalAuthStorage`. Reads `~/.pi/agent/auth.json` via `provider-auth-storage.ts`, returns API key + headers per model. Constructor takes optional `customProviderCreds` resolver — custom-provider api_key creds (from providers.json, not auth.json) fall back here so custom-provider models route (change: add-agent-role-model-tools). For OAuth credentials, `ensureFreshOAuth` refreshes tokens 30s before expiry (provider-specific `getOAuthProvider` then generic `refreshOAuthToken` fallback), serializes concurrent refreshes per provider in `refreshLocks`, persists via `writeCredential`. `OAUTH_PROVIDER_MAP` maps anthropic/openai-codex/github-copilot. `PiAiOAuthModule` is now a per-provider CAPABILITY FACADE: the refresh path gates on `isAvailable(oauthId)`, not truthiness. The old `if (!this.oauthModule)` guard passed for >=0.85's `export {}` type-only stub and then threw `TypeError` on the first refresh; the gate now raises a diagnosable error naming the provider AND why its OAuth path is unreachable, while api-key models keep routing. A credential inside the 30s buffer is returned without consulting the gate at all. See change: adopt-piai-factory-api-registry (D7). |
| `internal-registry.ts` | Server-resident model registry `InternalRegistry`. Composes pi-ai built-in providers with custom-provider models discovered from `providers.json` (`discover()` — fills the former no-op loop via `deps.discoverCustomProviders`, cached) + any user-authored `models.json`, filters to authed models via `canRouteModel` (api_key routes all; oauth routes only `oauthCompatible !== false`). `refresh()` re-runs discovery. Exports `getAvailable`, `find`, `firstAvailable(preferred[])` (walk ordered fqids, first available in registry; skips bare labels; null on empty/none), `getApiKeyAndHeaders`, `refresh`, `discover`, `getAll`, `getAllAnnotated` (excludedReason: no-credential/oauth-incompatible). `getAllModels()` field-level OUTER JOINs custom models per `provider/id`: routing (`baseUrl`/`api`/`oauthCompatible`) from discovery, capabilities (`contextWindow`/`maxTokens`/`reasoning`/`thinkingLevelMap`/`compat`/`input`/`cost`) from native `models.json` and WIN on overlap; native-only surfaces (routing from `providers.json`); discovered-only keeps floors; `oauthCompatible` NEVER from native. Then dedups by fqid keeping first (built-in → merged-custom) so a custom entry under a built-in name never overrides the built-in. `compat` carried on the model for `streamSimple` routing, never emitted by `toRow`. `PiAiModule` is now DECLARED in the shared seam (`packages/shared/src/piai-compat/types.ts`) and re-exported here for existing importers — on a factory runtime it is SYNTHESIZED by `adaptPiAi`, not the raw module. Types `CustomProviderEntry`, `CustomModelEntry` (gains `thinkingLevelMap?`/`compat?`), `InternalRegistryDeps` (+ optional `discoverCustomProviders`). See change: add-agent-role-model-tools, fix-and-prefer-model-proxy-resolution, honor-native-models-json-metadata. |
| `oauth-compat.ts` | OAuth-incompatible model override table. Exports `OAUTH_INCOMPATIBLE: Record<provider, ReadonlySet<modelId>>` + `isOauthIncompatible(provider, id)` (unknown provider/id → false; case-sensitive). Flags legacy Anthropic snapshots (`claude-3.x` dated ids) unreachable over OAuth. `internal-registry.ts` sets `oauthCompatible = !isOauthIncompatible(...)` on built-in models. Hand-maintained; review when provider ships new model. Table is UNCHANGED by the 0.85.1 bump: `claude-fable-5-1` is NOT added — its fable 5.1 HTTP 400 was a client-version (UA) header gate, not a catalog gate. NO provider-key remap for GPT-6 Astra: the Codex channel is a first-class `provider: "openai-codex"` catalog entry, matched by credential-key equality. See changes: filter-oauth-incompatible-models, update-pi-core-0-85-adopt-apis. |
| `recursion-guard.ts` | Recursion guard preventing custom providers pointing back at dashboard. `collectDashboardOrigins(port, opts)` enumerates localhost + LAN IPs + optional tunnel/mDNS hostnames. `isSelfPointing(baseUrl, origins)` normalizes URL host:port and checks against origin list. |
| `registry-singleton.ts` | Singleton accessor for `InternalRegistry`. `getModelRegistry()` lazily resolves pi-ai via `getDefaultRegistry().resolveModule`, loads oauth subpath, constructs `InternalAuthStorage` + `InternalRegistry` with disk readers for `~/.pi/agent/providers.json` and `~/.pi/agent/models.json` (exported `readModels()` routes through shared `flattenModelsJson` — native nested + legacy shapes; `console.warn` on parse failure), wires `discoverCustomProviders: discoverAllCustomProviders` + fires initial `discover()`. `readAugmentedAuth` merges auth.json with synthetic custom-provider api_key creds (`readCustomProviderCreds`) so discovered custom models pass `getAvailable`'s auth filter. Also exports `refreshModelRegistry`, `disposeModelRegistry`, `getStreamSimpleFn`, `getModelProxyStatus`. Routes the resolved pi-ai module AND its oauth subpath through the shared seam `adaptPiAi(module, resolution.path)` — the seam now owns the subpath load this file used to do inline with a POSIX-only regex. Caches the ADAPTED surface, NOT the raw module: caching the raw module leaves `getStreamSimpleFn()` undefined on a factory runtime and the proxy 503s with a healthy registry. `getModelProxyStatus()` gains `piAiGeneration` and per-provider `oauthProviders: {<providerId>: boolean}` (clarification C2) — OAuth unavailability does NOT flip `status` to `degraded`, which stays reserved for a dead registry, because api-key models keep routing. See changes: add-agent-role-model-tools, adopt-piai-factory-api-registry (D1/D5/D7). |
| `request-log.ts` | Optional JSONL request logger `logRequest(entry)` to `~/.pi/dashboard/model-proxy.jsonl`. Logs metadata only (no bodies, no keys): `RequestLogEntry` carries ts, requestId, apiKeyId, model, format, status, durationMs, tokens, error. Rotates at 50MB to dated suffix. Best-effort, never throws. |
