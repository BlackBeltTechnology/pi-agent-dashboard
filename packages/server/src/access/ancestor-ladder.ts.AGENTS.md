# ancestor-ladder.ts — index

`offeredAncestorLadder(subject)` — the nearest-first rungs a denial remedy may also offer (task 7b.1a). Stops BELOW `$HOME` when there is no repository, and AT the checkout root inside one; never offers a symlink, never the filesystem root, and never a rung that SUBSUMES a forbidden subject (`/private` would admit `/private/etc` on macOS) or sits inside a secret store. Degrades to the no-repo boundary when `git` is unavailable. A ladder failure must never turn a denial into a 500 — `containment-gate` catches and falls back to no offer. See change: add-access-grants-and-review. Unresolvable subject (dangling symlink, missing dir) -> `[]`, never lexical tail (#X8). Checkout-root probe cached per real dir: `CHECKOUT_ROOT_CACHE_TTL_MS`=5000, `CHECKOUT_ROOT_CACHE_MAX`=256 (oldest evicted), throws not cached, `__resetCheckoutRootCache`; forbidden sets derived once per ladder. p95 ~1.3 ms 12-deep (#P3, was ~26 ms git spawn per denial). See change: add-access-grant-dialog.
