# grant-coordinator.ts — index

Joins a denial to the registry, the planes and the operator's browsers (design D3/D6/D7/D8, tasks 6.1-6.3). `GrantCoordinator` (`onDenial(ctx, holdable)` -> `Hold`, `onResponse(msg)`, `registry`) + `DenialContext`, `Resolution`, `Hold`. Records via `PendingGrantRegistry`, broadcasts `grant_request` when prompted, arms ONE unref'd expiry timer per entry, and suspends only a held plane whose precondition passed AND whose entry is actually prompted (never on a flooded/degraded entry). First well-formed `grant_response` settles; `persistVerdict` writes only on allow-always; an allow-always whose store write FAILS resolves as a deny (D11: the admitted set never widens on failure). Coalesced held requests share one verdict; the last waiter aborting releases the entry. Waiters are resolved BEFORE the `grant_dismiss` is sent, and every broadcast goes through `send()`, which reports failure instead of throwing: an undeliverable prompt resolves `broadcast-failed` and is not held (#X5), so a gateway failure can neither turn a 403 into a 500 nor hang a held request. Remembers each entry's denying session so allow-always grants are attributed to it. See change: add-access-grant-dialog. Consults `yolo.decide` at the prompt point, BEFORE the registry: an auto-allow returns an `allow-once` resolution with no dialog and no entry (still re-evaluated by the caller), and prompt suppression (disabled / kill switch) does not stop it, since YOLO is itself the explicit opt-in (8b.6); a prior refusal resolves `refused-by-prior-refusal` without prompting. An operator's explicit `deny` on a held, YOLO-eligible plane calls `recordRefusal` (8b.4a). Review fixes (2b.7): `onResponse` (WS) settles only PROMPTED entries under live `enforce`, else ignored; `settle(msg)` = any-surface settle (Access page), never throws, deny `settle-failed` on store/ledger throw, always `finish`. Allow-once releases ONLY first waiter (raiser); coalesced waiters get deny `allow-once-not-shared`. `GRANT_MAX_WAITERS_PER_ENTRY`=8, overflow -> immediate `waiters-full`. Persisted allow-always logs `[access-grant] persisted plane= subject= store= origin=`. `settle`/`onResponse` return `SettleResult` (`{ok,record}` | reason incl. `ignored`). `recentVerdicts()` = bounded ring (`GRANT_VERDICT_HISTORY`=200) of `GrantVerdictRecord {promptId,plane,subject,outcome allow-once|allow-always|deny|expired|aborted|failed,store?,widenedFrom?,at}`; store only on a persisted allow-always (8.1/8.2). See change: surface-denial-remedy-in-previews — Null `subjectOf` → log `[access-grant] not-promptable plane= subject=<json>`. Non-held deny reason = own precondition → join flood reason → `not-held` (never entry `suppressedBy`). Promoting joiner re-points audit origin.
