# access-grants.ts — index

The path-grant store (design D2/D10/D11/D16/D17). `recordGrant` / `listGrants` / `revokeGrant` / `grantedSubjects` / `normalizeGrantSubject` / `__resetAccessGrants`. Subject = **realpath at grant time** (a retargeted symlink does not move the grant); non-directory subjects normalize onto their containing directory. Per-scope cap 200 with oldest-by-`grantedAt` eviction, never crossing scope. Atomic write (tmp+rename) → an interrupted write leaves old-or-new, never truncated. Load-once cache; `revokeGrant` invalidates it so revocation takes effect without a restart. A write failure returns `{ok:false}` and leaves the cache untouched, so the admitted set never widens on a failure (D11). **Forbidden backstop:** `isUngrantableSubject` is re-applied to the NORMALIZED subject, because normalizing a FILE subject onto its parent could otherwise store `$HOME` for a denial that named `$HOME/<file>` (design D15). Store path overridable via `PI_ACCESS_GRANTS_STORE`.
