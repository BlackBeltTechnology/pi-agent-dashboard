# git-worktree-compose.ts — index

Pure helper composing live `gitWorktree` payload. Exports `composeWorktreePayload(wire, cachedBase, prior)` → `null` (bridge cleared AND no prior parentage), the unchanged `prior` object (bridge cleared AFTER parentage was resolved — the worktree was removed underneath a live session, never a cwd switch), merged `GitWorktreeInfo` with `base` filled from cached server value when bridge omitted it, or `undefined` (bridge omitted field → caller leaves existing value untouched). No state/IO deps; unit-testable. Tests: `__tests__/git-worktree-compose.test.ts` (E1–E4). See changes: add-worktree-spawn-dialog, fix-worktree-grouping-lost-on-remove.
