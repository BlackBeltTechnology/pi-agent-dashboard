# git-worktree-lifecycle.ts — index

Pure stderr→code mappers `mapRemoveStderr` / `mapMergeStderr` / `mapPushStderr` / `mapPrStderr` + `parsePrUrl` + `parseShortstat`. Drives stable error codes (`dirty_worktree`, `branch_not_merged`, `merge_conflict`, `non_fast_forward`, `auth_failed`, `gh_not_authed`, `pr_exists`, ...) emitted by `/api/git/worktree/*`. See change: add-worktree-lifecycle-actions. Adds `BRANCH_DELETE_CODES` + `REMOVE_CODES` const arrays as the RUNTIME source of truth (the unions are derived from them so a disjointness test evaluates a real set intersection, not an erased type assertion), `BranchDeleteCode`, and `mapBranchDeleteStderr`. `BranchDeleteCode` is disjoint from `RemoveCode`: generic failure is `delete_failed` not `git_failed`, and it never reuses `branch_not_merged` (that RemoveCode makes the client auto-tick `--force`). See change: manage-worktrees-filter-cleanup.
