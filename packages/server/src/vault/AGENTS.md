# DOX — packages/server/src/vault

Credential vault (hub): store, bindings, grants, import, plugin reads, delivery, routes. Spec: `openspec/changes/add-credential-vault/` (archived after ship).

| File | Purpose |
|------|---------|
| `vault-bindings.ts` | Env bindings: `createBinding`/`setBindingDefault`/`deleteBinding`, `listBindings`, `wellFormedBindings`; re-exports shared `isDeliverableEnvName`/`isReservedEnvName` (regex + case-insensitive deny list, checked at creation, snapshot, bridge). Tests: `__tests__/vault-bindings.test.ts` (E6, E7). See change: add-credential-vault. |
| `vault-delivery-hub.ts` | Hub half of env delivery. `createVaultDeliveryHub({store,getOrigin,send,isDeliveryEnabled,getGraceHours,isTls?})`: `handleSyncRequest`/`handleReport`/`schedulePush` (debounced, on `store.onChange`)/`pushNow`/`getSessionState`/`forget`. `decideVaultTrust`: hub-local, or remote paired device over TLS (`isTls` defaults false → remote gets `transport-insecure`). Refusal order: config switch, trust, corrupt vault (`unavailable`), project. Tests: `__tests__/vault-delivery-trust.test.ts`, `vault-delivery-wiring.test.ts` (X1, X2, X9, X10). See change: add-credential-vault. |
| `vault-grants.ts` | Grants + resolution. `repoSubject`/`dirSubject`, `createGrant`/`deleteGrant`, `confirmCheckout`/`revokeConfirmation` (bound to device+dir+repoKey), `revokeAccount` (default dropped, override grants kept `no-account`, never fallback), `resolveBindings`, `buildDeliverySnapshot`, `listGrantStates`. Session with repoKey → repo grants (need confirmation); without → exact directory grants. Tests: `__tests__/vault-grants.test.ts` (E10, E11, E13–E15). See change: add-credential-vault. |
| `vault-import.ts` | Non-destructive import. `createVaultImport({store,candidates})`: `listCandidates` (existence only, opaque ids), `proposeFromCandidate`, `proposeFromUpload` (≤64 KiB), `confirm` (single-use proposal, names only, values <8 skipped). Local `.env` parser (mirror of nano-banana `parseEnvFile`). `defaultKnownLocations()`. Never reads a client path. Tests: `__tests__/vault-import.test.ts` (E16–E18). See change: add-credential-vault. |
| `vault-permissions.ts` | `checkOwnerOnly(file, env)`: POSIX mode bits; Windows inherited profile ACL (file must sit under the profile home). Manual access-denied check is task 7.1. Tests: `__tests__/vault-store.test.ts`. See change: add-credential-vault. |
| `vault-plugin-read.ts` | Plugin read seam. `createPluginVaultReader(store, pluginId, declared)` → `read(name)` only when declared AND approved; returns the default account value. `approvePluginBinding`/`revokePluginBinding`/`listPluginApprovals`. Tests: `__tests__/vault-plugin-read.test.ts` (E19). See change: add-credential-vault. |
| `vault-routes.ts` | `registerVaultRoutes`: `/api/vault*` management (operate bearer, operator session, or local trust; reads too) + `GET /api/session/:id/vault-bindings` (session-read authority). No response carries a value. Import propose accepts only `{candidateId}` xor `{content}`. Tests: `__tests__/vault-routes.test.ts`, `vault-import.test.ts` (X12). See change: add-credential-vault. |
| `vault-store.ts` | `createVaultStore(path?)` over `~/.pi/dashboard/vault.json` (locked-json-file, `createIfMissing:false`, 0600, unknown fields/kinds preserved, corrupt → backup + refuse every write with content-free `VaultError`). `addAccount`/`listAccounts` (no values)/`getKeyValue` (delivery only)/`rotateAccount`/`readDocument`/`update`/`onChange`. Min value length 8. Tests: `__tests__/vault-store.test.ts` (E1–E5). See change: add-credential-vault. |
