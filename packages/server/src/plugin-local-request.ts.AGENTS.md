# plugin-local-request.ts — index

Plugin host service `host.localRequest` (`HOST_LOCAL_REQUEST_KEY`). `createHostLocalRequest({getToken,host,getPort})` → `({method,url,body?,timeoutMs?}) → {ok:true,statusCode,body}\|{ok:false,code}`. Real loopback HTTP request with per-request CLI-style local proof (`httpProofHeaders`); token never exposed; no caller headers; no redirect follow. FIXED allowlist `LOCAL_REQUEST_ALLOWLIST` (POST `/api/git/worktree[/init\|/orphan-cleanup]`, GET `/api/openspec/tasks`, POST `/api/openspec/tasks/toggle`); caps 256 KiB body / 4 MiB response; default 60 s timeout (max 300 s). Codes: `invalid_request path_not_allowed body_too_large response_too_large timeout unavailable unreachable`. Registered in `server.ts` beside `host.resolveCwdPolicy`. See change: add-agent-teams-openspec.
