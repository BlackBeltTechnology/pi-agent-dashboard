# browser-gateway.ts — index

WebSocket gateway for browser clients. Exports `BrowserGateway` interface, `createBrowserGateway`, `buildOpenSpecConnectSnapshot`. Routes `BrowserToServerMessage` switch to `browser-handlers/*`. Manages subscriptions, replay suppression, headless `headlessPidRegistry`, `pendingResumeRegistry`, `viewedSessionTracker`, pending UI/prompt request replay, `broadcastEvent`/`broadcastSession*`/`broadcastOpenSpecUpdate` (pre-serialized payload fanout), plugin `registerHandler`/`registerDisconnectHandler`. Back-pressure guard via `MAX_WS_BUFFER`. First over-cap send calls `handleBackpressure`: count the dropped frame, terminate only that socket, and force reconnect/replay. A `WeakSet` bounds termination to once per socket. `getDroppedFrameStats()` returns `total`, `bySession`, and `forcedReconnects` for `/api/health#droppedFrames`. See changes: fix-stuck-tool-card-on-dropped-event, fix-reliable-live-control-events. Routes `role_remove` → `piGateway.sendToSession` (mirrors `role_set`/`role_preset_*` cases; without it custom-role removal was dropped server-side). See change: add-custom-roles-ui. Routes `subagent_resync_request` → `handleSubagentResyncRequest` → `piGateway.sendToSession`. See change: fix-subagent-live-detail-reliability (D2). Routes `set_session_tags` → `handleSetSessionTags`. See change: add-session-tags. Routes `remove_tag_globally` → `handleRemoveTagGlobally` (load-bearing switch case — unwired it falls through `default:`→`handlePiGatewayForward` and is misrouted to a bridge). See change: sidebar-tag-collapse-and-delete. `plugin_action` now fans out by pluginId: separate `pluginActionHandlers` Map<pluginId,Handler> + `registerPluginActionHandler(pluginId,handler)` gateway method (distinct from single-owner `customHandlers`); dispatch routes `plugin_action` to the owning plugin's handler, unknown pluginId → `plugin_action_error` sent to sender (never silent-drop), duplicate pluginId warns. See change: fix-plugin-action-fanout-and-handlers. Adds `hasPendingUiRequest(sessionId)` (unanswered `ask_user` tracked) - read by the embed-lifecycle reaper quiescence gate. See change: add-embed-session-lifecycle. Adds `hasPendingPromptRequests(sessionId)` (>=1 unanswered PromptBus request; read by the `currentTool` derivation and the reaper pending-ask union), `reconcilePromptRequests(sessionId, promptIds)` (snapshot setter - drops tracked prompts absent from the bridge's re-sent burst, recovering a `prompt_dismiss` lost across a socket drop), and `clearPendingRequestsForSession(sessionId)` (drops BOTH `pendingUiRequests` and `pendingPromptRequests` on session death; the pre-existing `pendingUiRequests` leak already made a dead session permanently unreapable). Accessors return ids/booleans, never prompt payloads. See change: restore-ask-user-tool-state-on-reconnect.
 Owns the bounded per-session notify log (`createNotifyLog`, cap 50, oldest-first). Adds `appendNotify(sessionId, entry)` (append + mirror onto `DashboardSession.notifyLog` so the debounced `.meta.json` save carries it across a restart) and `replayNotifyLog(ws, sessionId)` (sibling of `replayPendingUiRequests`, passed through `BrowserHandlerContext`; cold-hydrates from the restored session record when the in-memory log is empty). The log is deliberately NOT cleared in `clearPendingRequestsForSession` — an ended session keeps the rows it displayed while alive; reapability is protected by exclusion (no reaper signal reads it), not deletion. Exposes `getNotifyLogStats()` (cap evictions, `/api/health#notifyLog`). `hydrateNotifyLog(sessionId)` seeds the in-memory log from the restored record for BOTH `replayNotifyLog` and `appendNotify` — appending onto an empty in-memory list would mirror back a one-row array and wipe the persisted history. See change: split-notify-from-prompt-request.
