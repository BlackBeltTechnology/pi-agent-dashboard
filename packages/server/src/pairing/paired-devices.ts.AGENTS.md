Opaque bearer: only SHA-256 hash stored; plaintext returned once at `add(label, source = "pairing")`. `verify(token)` constant-time, updates last-seen; `revoke(id)` = row delete; `list()`. `PairedDevice`/`PairedDeviceView` carry `source: "pairing" | "manual"`; loader defaults a missing field to `"pairing"` (no migration; next write normalises). Exports `PairedDevice`, `PairedDeviceView`, `defaultRegistryPath`. See change: add-server-keypair-pairing, mcp-legacy-clients-and-token-issuance.

## harden-auth-credentials (B4r)

Optional row fields (epoch ms): `expiresAt` (absent/null = non-expiring; present non-finite/≤0 = malformed → expired), `pairedAt` (30 d ceiling anchor), `previousHash`/`previousExpiresAt` (one grace bearer). `add(label,source,tier,holder?)`: exact `"browser"` → `expiresAt=now+7d`, `pairedAt=now`; else row byte-identical to legacy. `verifyDetailed(token)` → `ok{superseded}|expired|invalid` on in-memory state only (no file IO); expired at `now >= min(expiresAt, pairedAt+30d)`; previous hash ok until `previousExpiresAt=min(rot+60s, own expiresAt)`, then plain `invalid`; grace match skips last-seen. `verify` = ok-only wrapper (expired → null). `rotate(token, declaredBrowser)` sync: bearer rotates its own row; `expiresAt=min(now+7d, pairedAt+30d)`; legacy row converts only with declaration (`pairedAt=now`); reasons `invalid|expired|superseded|holder_declaration_required|rate_limited(retryAfterS)|persist_failed` (in-memory state restored); limiter 10/60s sliding per device, only successes count. `browserExpiryFor(id, declared)` serves pairing poll. Last-seen persist is best-effort (never rejects a valid bearer). Constants `BROWSER_BEARER_TTL_MS`, `BROWSER_BEARER_CEILING_MS`, `ROTATION_GRACE_MS`, `ROTATE_LIMIT`, `ROTATE_WINDOW_MS`. Tests: `__tests__/paired-devices.test.ts`, `__tests__/bearer-auth.test.ts`. See change: harden-auth-credentials.

## device-key-mutual-check (D3, D5, D6)

Rows gain optional `keys?: {pub, createdAt}` (ONE primary key; field name is plural per design) and `companions?: {id, pub, origin, createdAt}[]` (max `MAX_COMPANIONS`=4; `id` = `keyIdOf(pub)` = `dk:`+12; origin via `storedCompanionOrigin`). Rotation mutates the same row so both survive. `PairedDeviceView` adds `keyId?`, `companions?[{id,origin,createdAt}]` (no pub). `keyIdOf(pub)` sync short id.

Key API: `bindKey(id,pub)` → `bound|replaced|held|no-device` (same key = idempotent `bound`; `held` = owned by other row or own companion, active OR revoked); `addCompanion(id,{pub,origin})` → `added|cap|held|no-device`; `removeCompanion(id,companionId)` → bool; `lookupKey(pub)`/`isKeyHeld(pub)` (active before revoked; `KeyLookup{device,kind,state,companion?}`); `deviceKeyStatus(pub)` → `DeviceStatusReply` for a VERIFIED key (revoked wins; `expired` = `currentVerdict`!=ok AND NOT `previousGraceLive` — same judgement as `verifyDetailed`; companion → `status-only`, no tier). `add(..., {key, companions})` drops held/invalid silently; result adds `keyBound?`, `companionsAdded?`. Persist failure on bind/add/remove rolls the row back + throws.

Revoked = held state: `revoke(id, by="local")` → bool (false = unknown/already revoked → route 404); writes `revoked-devices.json` (0600, sibling of registry file) FIRST, then active; first-write failure throws, device stays active; second-write failure logged only. Record = whole row + `revokedAt` (epoch ms) + `revokedBy`. `restore(id)` → `restored|not-found|active` (active file first; keeps every field incl. unknown, expiry never extended; held `lastSeen` kept); `deleteRevoked(id)` → `deleted|not-found|active`; `listRevoked()` → `{devices: RevokedDeviceView[], warning?: "unreadable"}`; `purgeExpired()` (age >= `REVOKED_RETENTION_MS` 90 d) runs at load, on list/restore/delete/lookupKey/`deviceKeyStatus`; emits `[pairing] purged id=<8>` (no actor/ip). Load: id in both files → revoked wins; unparseable or wrong-shape revoked file → renamed `revoked-devices.corrupt-<ms>.json`, error logged, empty list, `warning:"unreadable"`. `onRevoked(listener(id))` fires after a successful revoke. `verify()` scans active rows only. Tests: `__tests__/paired-devices-keys.test.ts`, `paired-devices-revoked.test.ts`, `pairing-audit.test.ts` (E23). See change: device-key-mutual-check.
