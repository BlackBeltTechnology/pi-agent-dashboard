# paired-devices.ts — index

Paired-devices registry (D5). `PairedDeviceRegistry(path?)` persists `~/.pi/dashboard/paired-devices.json` (0600). Opaque bearer: only SHA-256 hash stored; plaintext returned once at `add(label, source = "pairing")`. `verify(token)` constant-time, updates last-seen; `revoke(id)` = row delete; `list()`. `PairedDevice`/`PairedDeviceView` carry `source: "pairing" | "manual"`; loader defaults a missing field to `"pairing"` (no migration; next write normalises). Exports `PairedDevice`, `PairedDeviceView`, `defaultRegistryPath`. See change: add-server-keypair-pairing, mcp-legacy-clients-and-token-issuance.

Row gains `exposure {trackedSince, plaintextSeenAt?}`. `verify`/`verifyDetailed`/`rotate` take the channel. `deviceTrust(id)` → `eligible|inactive|exposed|history-unknown`. Adds `onChange`, `markDelivered`, `exposurePending`, `activeIds`, `isKnownBearer`. `add(..., {channel, purpose:"bridge"})` mints `pi_tls_`; first-exposure write fails closed. See change: prove-vault-bridge-tls.

## harden-auth-credentials (B4r)

Optional row fields (epoch ms): `expiresAt` (absent/null = non-expiring; present non-finite/≤0 = malformed → expired), `pairedAt` (30 d ceiling anchor), `previousHash`/`previousExpiresAt` (one grace bearer). `add(label,source,tier,holder?)`: exact `"browser"` → `expiresAt=now+7d`, `pairedAt=now`; else row byte-identical to legacy. `verifyDetailed(token)` → `ok{superseded}|expired|invalid` on in-memory state only (no file IO); expired at `now >= min(expiresAt, pairedAt+30d)`; previous hash ok until `previousExpiresAt=min(rot+60s, own expiresAt)`, then plain `invalid`; grace match skips last-seen. `verify` = ok-only wrapper (expired → null). `rotate(token, declaredBrowser)` sync: bearer rotates its own row; `expiresAt=min(now+7d, pairedAt+30d)`; legacy row converts only with declaration (`pairedAt=now`); reasons `invalid|expired|superseded|holder_declaration_required|rate_limited(retryAfterS)|persist_failed` (in-memory state restored); limiter 10/60s sliding per device, only successes count. `browserExpiryFor(id, declared)` serves pairing poll. Last-seen persist is best-effort (never rejects a valid bearer). Constants `BROWSER_BEARER_TTL_MS`, `BROWSER_BEARER_CEILING_MS`, `ROTATION_GRACE_MS`, `ROTATE_LIMIT`, `ROTATE_WINDOW_MS`. Tests: `__tests__/paired-devices.test.ts`, `__tests__/bearer-auth.test.ts`. See change: harden-auth-credentials.
