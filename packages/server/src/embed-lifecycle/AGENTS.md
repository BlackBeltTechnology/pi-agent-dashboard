# DOX — packages/server/src/embed-lifecycle

Files in this directory. One row per source file. Server-side lifecycle control plane for machine-fronted (`ephemeral`) sessions: idempotent acquire, idle reaper, active-session caps, observability — all off by default (`config.embedLifecycle.enabled`). See change: add-embed-session-lifecycle.

| File | Purpose |
|------|---------|
| `caps.ts` | Active-session caps admission gate. `createCapsAdmission(deps)` → `{ admit(key) }`; counts only ephemeral, reclaims oldest quiescent, else throws `CapacityError` (exported). Global cap = hard bound; shared `reclaimGuard` avoids double-select. `reclaim` dep returns `TerminateResult`; unconfirmed ⇒ `CapacityError` ("could not be confirmed"), exactly one victim per call, failure recorded in shared `giveUp` tracker; given-up sessions excluded from victims but still counted. See change: fix-session-reclaim-tmux. `CapSessionInfo.declared` (plugin close policy) ⇒ counted, never reclaimed. See change: add-session-close-plugin-hook. |
| `cwd-allowlist.ts` | `isCwdAllowed(cwd, allowedRoots, {realpath?})` — realpath + `within` containment; empty allowlist denies (D11). |
| `embed-lifecycle-controller.ts` | Server-integration facade. `createEmbedLifecycleController(deps)` → `{ metrics, reaper, giveUp, start, stop, snapshot }` (deps: `terminate` + `sendStopAfterTurn=>boolean`; `giveUp` = tracker shared with caps; `onReclaimFailed`→`metrics.recordReclaimFailure`); wires the live reaper + metrics to sessionManager/browserGateway/terminalManager/pidRegistry/piGateway. Dormant when disabled. `hasPendingAsk` is now the UNION of `hasPendingUiRequest(id)` and `hasPendingPromptRequests(id)` (new optional dep, defaults false). Explicit, not an accident of `currentTool:"ask_user"`: that field vetoes only the idle gear, while `streamingGearVerdict` reads `hasPendingAsk` and never `currentTool`, so a PromptBus-blocked session could be phantom-reaped. See change: restore-ask-user-tool-state-on-reconnect. Optional deps `closers` (`SessionCloserRegistry`), `isPluginEnabled` (disabled owner ⇒ closer skipped), `markArchiveOnEnd`, `log`; wires `closerFor`/close requests/verdict log+metrics; declared reaps logged with owner. See change: add-session-close-plugin-hook. |
| `idle-reaper.ts` | Three-gear reaper loop. `createIdleReaper(deps)` → `{ sweepOnce, start, stop }`; assembles signals, calls `decideReap`, applies (idle/phantom → shared `terminate`, counted only on confirmed termination; stop-after-turn → latch, counted on delivery). Failed reclaim: warn + `onReclaimFailed` + shared give-up (3 attempts, immediate for no/refused identity, one `error` line); throw ⇒ unconfirmed. `CPU_IDLE_THRESHOLD`. See change: fix-session-reclaim-tmux. Scope per session: `(enabled && ephemeral) || isPluginGoverned(closePolicy.idleAfterMs) || closeRequested`; feature off + nothing declared ⇒ no-work pass. Governed, non-requested reaps ask the owner's closer (`CLOSER_TIMEOUT_MS` 1 s/call, `CLOSER_SWEEP_BUDGET_MS` 5 s/sweep, overflow deferred; throw/timeout/unknown ⇒ keep). Archive mode ⇒ `markArchiveOnEnd` before close. `onReap(id, reason, declared?)`; close request cleared on confirmed termination. See change: add-session-close-plugin-hook. Archive-mode mark rolled back (`markArchiveOnEnd(id,false)`) unless close confirmed (terminated / stop latch delivered); session already `archiveOnEnd` → not touched. See change: add-session-close-plugin-hook. |
| `identity-key.ts` | Canonical identity key. `canonicalizeCwd` (realpath + case-normalize via `caseInsensitiveFilesystem`), `buildIdentityKey`, `composeIdentityKey`, `visitorIdOf`. NUL-joined `visitor + cwd + agent` (D10). |
| `lifecycle-event-capture.ts` | `captureLifecycleTimestamp(eventType, now)` → `{lastRunStartedAt}` / `{lastSettledAt}` / null. Version-agnostic settle capture (keys on event name, no piVersion branch). Wired in `event-wiring.ts`. |
| `lifecycle-metrics.ts` | Observability counters. `createLifecycleMetrics(deps)` → `{ recordReap, recordCapacityReject, recordReclaimFailure, recordReuse, snapshot }`; `failedReclaims` = single scalar (no per-reason split). Live active/idle from injected accessors; cumulative reap/reuse/reject. Exposed via `/api/health` `embedLifecycle`. Adds `declaredReaps`, `closerKeeps`, `closerFailures`, `pluginCloseRequests` (`recordDeclaredReap`, `recordCloserOutcome`, `recordPluginCloseRequest`). See change: add-session-close-plugin-hook. |
| `liveness-probe.ts` | Bounded pid-tree + CPU probe. `createLivenessProbe({timeoutMs?,runPs?})` → `(rootPid)⇒LivenessSnapshot`; pure `summarizeProcessTree` + `parsePsOutput`. `{ok:false}` on ps failure ⇒ safe direction. |
| `plugin-session-close.ts` | Plugin session-close hook. `createSessionCloserRegistry()` (one closer per plugin id + in-memory close-request set), `createPluginSessionCloseApi(deps, pluginId, trusted)` → `{ registerSessionCloser, requestSessionClose }`. Request only for sessions whose `closePolicy.owner` is the caller; `now` ⇒ `deps.closeNow` (server binds the graceful `abortSpawnedRun` path: shutdown hint + shared terminator; archive mode marks first), `idle` ⇒ close request; refusals return false + one warning; untrusted ⇒ no-ops. See change: add-session-close-plugin-hook. `when:'now'` rolls archive mark back when `closeNow` returns false. See change: add-session-close-plugin-hook. |
| `quiescence.ts` | Pure reap-decision core. `decideReap(signals, thresholds, now)` → `{action,reason}`; `isAtRest`, `isWithinGraceWindow`. Encodes 3 gears + every veto (X4 matrix, X5 phantom guard). `LifecycleSignals`, `LifecycleThresholds`, `ReapReason`. Signals gain `governed`, `idleTimeoutMs` (declared threshold), `closeRequested` (skips only idle-age; never mid-run); `isReapable` = ephemeral ∨ governed ∨ closeRequested. See change: add-session-close-plugin-hook. |
| `reclaim-give-up.ts` | Bounded retry for failed unattended reclaims, shared by reaper + caps. `createReclaimGiveUpTracker()` → `{ recordFailure(id,outcome)⇒crossed, isGivenUp, clear, prune }`; `RECLAIM_GIVE_UP_AFTER=3`; immediate for `no-identity`/`refused-identity`; count resets only via `clear` (confirmed) or `prune` (unlisted). See change: fix-session-reclaim-tmux. |
| `session-lifecycle-policy.ts` | Provenance accessor. `isEphemeral(session)`, `effectiveLifecyclePolicy(session)` — absent `lifecyclePolicy` ⇒ `"durable"` (D1). Every downstream gate reads through here. |
| `visitor-session-registry.ts` | Idempotent acquire. `createVisitorSessionRegistry(deps)` → `{ acquire, resolveByCwd, mappedSessionId }`; coalescing `key→Promise`, reuse→resume→spawn ladder, bounded register timeout (X2), key re-point across resume renumber (E10). |
