# preferences-store.ts — index

Global UI preferences store — JSON-backed with debounced writes. Stores `sessionOrder`, `pinnedDirectories`, `workspaces`, `favoriteModels`, `displayPrefs`, `openspecUpdateSignatures`, `autoInitWorktreeOnSpawn`, `pinSeeded`, `liveServers`. Exports `createPreferencesStore`, `PreferencesStore`, `PREFERENCES_FILE`. Adds `getLiveServers`/`setLiveServers` (live-server allowlist persistence). Replaces `state-store.ts`. `backfillDisplayPrefs` backfills `reasoningAutoCollapseMs` (30000) + `keepReasoningOpenUntilTurnEnds` (false) + `toolGroupDefaultCollapsed` (false) + `changeSummaryTable` (true) + `showOutOfCwdSessionDiffs` (false) for legacy files; `setDisplayPrefs` base + merge include `showOutOfCwdSessionDiffs`. See changes: folder-workspaces, configurable-chat-display, docker-packaging, improve-content-editor, keep-reasoning-open-until-turn-ends, enhance-tool-call-grouping, add-change-summary-table, opt-in-out-of-cwd-session-diffs.
 Adds `moveFolderToWorkspace(dirPath, toWorkspaceId, index?)`: validate-before-mutate — resolves the target BEFORE any detach so a stale id leaves the folder where it was (returns false, no mutation) instead of detaching it from EVERY workspace. Rejects same-workspace moves (`reorder_workspace_folders` owns repositioning; a post-detach splice would be off by one). `index` clamped to `[0, folders.length]` — a negative index would make `splice` count from the END. Omitted `index` = append. `toWorkspaceId: null` ejects from every workspace (false when a member of none). Canonicalizes internally, like `addFolderToWorkspace`. See change: drag-folders-across-workspaces.
