# preferences-store.ts — index

Global UI preferences store — JSON-backed with debounced writes. Stores `sessionOrder`, `pinnedDirectories`, `workspaces`, `favoriteModels`, `displayPrefs`, `openspecUpdateSignatures`, `autoInitWorktreeOnSpawn`, `pinSeeded`, `liveServers`. Exports `createPreferencesStore`, `PreferencesStore`, `PREFERENCES_FILE`. Adds `getLiveServers`/`setLiveServers` (live-server allowlist persistence). Replaces `state-store.ts`. `backfillDisplayPrefs` backfills `reasoningAutoCollapseMs` (30000) + `keepReasoningOpenUntilTurnEnds` (false) + `toolGroupDefaultCollapsed` (false) + `changeSummaryTable` (true) + `showOutOfCwdSessionDiffs` (false) + `notifyMinLevel` (`"all"` — today's behavior, so an upgrade hides nothing) for legacy files; `setDisplayPrefs` base + merge include `showOutOfCwdSessionDiffs` and `notifyMinLevel` (both write paths, so a partial PATCH of an unrelated field cannot drop the floor). NB neither write path VALIDATES `notifyMinLevel` — fail-open lives in the shared predicate. See changes: folder-workspaces, configurable-chat-display, docker-packaging, improve-content-editor, keep-reasoning-open-until-turn-ends, enhance-tool-call-grouping, add-change-summary-table, opt-in-out-of-cwd-session-diffs, gate-notify-rows-by-level.
 Adds `moveFolderToWorkspace(dirPath, toWorkspaceId, index?)`: validate-before-mutate — resolves the target BEFORE any detach so a stale id leaves the folder where it was (returns false, no mutation) instead of detaching it from EVERY workspace. Rejects same-workspace moves (`reorder_workspace_folders` owns repositioning; a post-detach splice would be off by one). `index` clamped to `[0, folders.length]` — a negative index would make `splice` count from the END. Omitted `index` = append. `toWorkspaceId: null` ejects from every workspace (false when a member of none). Canonicalizes internally, like `addFolderToWorkspace`. See change: drag-folders-across-workspaces.

Workspace seam (add-chat-gateway-team-controls): `onWorkspacesChanged(handler): () => void` — subscribe to workspace mutations, fired from all nine workspace mutators after a successful change (per-subscriber try/catch so one throwing handler neither blocks others nor fails the mutation; never driven by the browser broadcast). Exports `WORKSPACE_MUTATOR_NAMES` (the wiring contract) + `discoverWorkspaceMutators(methodNames)` for the completeness guard test. See change: add-chat-gateway-team-controls.

## session-list-group-by

- New optional fields `defaultGroupBy` (absent → none), `folderGroupBy: Record<pathKey, GroupByMode>`, `collapsedLanes: string[]` (`<pathKey>::<lane>`). Included in both `writeJsonFile` payloads.
- Load: invalid modes / lane ids dropped; corrupt containers → defaults; keys `pathKey`-folded (platform from `inferPlatform` over collapsedFolders + group keys); never realpath'd; never pruned.
- API: `getGroupByPrefs()` (copies), `setFolderGroupBy(path, mode|null)`, `setDefaultGroupBy(mode)`, `setLaneCollapsed(path, lane, collapsed)` — each validates, canonicalizes via `groupFolderKey`, returns true only on real change. See change: session-list-group-by.
Card sections: `cardSections` field — Map-backed (no prototype keys), load-time sanitized (invalid ids / non-boolean / non-absolute folder keys / empty maps dropped, keys re-folded + merged, caps applied; corrupt → `{}`; rewritten when sanitization changed it). `getCardSections()` deep snapshot. `setCardSectionVisibility(path|undefined, id, boolean|null)` → true only on mutation; null deletes key + empties folder; over-cap new folder/key rejected. `resetFolderCardSections(path)`. Omitted from disk when empty. See change: configurable-session-card-sections.
Focus mode + accordion: `cardSections.focus` loaded through `sanitizeFocusProfile`, snapshotted by `getCardSections()`, persisted only when non-empty. `setFocusEnabled(enabled)` / `setFocusProfile(profile|null)` return true only on mutation; `null` resets to the built-in profile; an invalid or over-cap profile returns false and mutates nothing. Top-level `expandedFolders` (`pathKey`-folded, dedupe-preserving) with `getExpandedFolders()`/`setExpandedFolder(path, expanded)`; never pruned — an unseen folder keeps its state across restarts. Pin and collapse stay mutually exclusive: pinning a folder clears its collapsed entry, collapsing clears the pin. See change: add-focus-mode-and-card-block-toggles.
