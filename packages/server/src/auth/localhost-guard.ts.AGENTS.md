Universal network guard (change: add-universal-network-guard). `createNetworkGuardHook({trustedNetworks, localToken?, getBypassUrls?, getPairingPrefixes?, logDenial?})` — ONE root `onRequest` hook, registered LAST and unconditionally in `server.ts`, so enforcement is structural instead of a per-route `preHandler` a registrar can forget. Jurisdiction = `GUARD_JURISDICTION_PREFIXES` (`/api/`, `/v1/`, `/editor/`, `/live/`, trailing-slash anchored); OUTSIDE it the hook is a no-op (static assets, SPA shell, `/manifest.json`, `/auth/*`, `/mcp`). INSIDE it: deny-by-default, admitted only by an in-namespace public exception (`/api/health` exact pathname, GET+HEAD; injected pairing prefixes; injected `bypassUrls` via the shared leaf `bypass-urls.ts`) or a pass condition IDENTICAL to `createNetworkGuard` (genuine-local → local-token → live-thunk trusted CIDR → `isAuthenticated`). `guardPathname(url)` parses origin-form only and returns `null` on a malformed percent-escape or authority/absolute form → the hook FAILS CLOSED (denies), because an unparseable target cannot be proven out of jurisdiction. `isGuardJurisdiction(pathname)`. `GUARD_DENY_REASON` = `unparseable-url` | `not-local-not-trusted-not-authenticated`. `sendNetworkDenied(request, reply)` is the single denial path (blockEvents record + the `network_not_allowed` body) shared with `createNetworkGuard`, so the hook (which denies BEFORE any route `preHandler` runs) cannot change the 403 shape of already-guarded routes. Default `logDenial` emits `[network-guard] denied reason=… path=… ip=…` — path + socket-peer IP + reason only, never a body/token. Pairing prefixes are INJECTED (`getPairingPrefixes`) rather than imported so this module stays free of a `routes/pairing-routes.ts` edge, which imports this module back.

`setNetworkDenialObserver(fn | null)`: an observer told about every network-policy denial from the ONE shared `sendNetworkDenied` path, after `blockEvents.record` and before the unchanged 403. Best-effort: a throwing observer never blocks or alters the denial. The access-grant coordinator hangs off it (deferred network plane). See change: add-access-grant-dialog (task 6.1).
