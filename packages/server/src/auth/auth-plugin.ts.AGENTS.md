# auth-plugin.ts — index

Fastify plugin registers OAuth routes + `onRequest` JWT gate. Exports `registerAuthPlugin`, `validateWsUpgrade`, `isBypassed`, `escapeHtml`. Mutates auth state via `_reloadAuth` for runtime config updates. Skips auth on loopback, `/auth/`, `/api/health`, `/v1/`, bypass prefixes, trusted hosts. Cookie `pi_dash_token`, 7-day expiry, httpOnly/`sameSite:lax`. `Secure` derives from `resolveRedirectBase().base` starting `https:` — NOT from `request.protocol`, which is always `http` behind a proxy because Fastify runs without `trustProxy` on purpose: `trustProxy` would rewrite `request.ip` from `X-Forwarded-For`, and `request.ip` is what BOTH bypasses read (`:288` here, `localhost-guard.ts:116`). Pinned by `__tests__/forwarded-ip-trust.test.ts` (S1/S2) — enabling `trustProxy` turns those red. Redirect URIs built with `authState.redirectBaseUrl` (config `auth.redirectBaseUrl`) threaded as `buildRedirectUri` override. See change: config-override-oauth-redirect-base (D14).
