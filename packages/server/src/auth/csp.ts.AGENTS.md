# csp.ts — index

Baseline Content-Security-Policy (defense in depth). `buildCsp()` (default-src/object-src none/frame-ancestors self/base-uri self/worker-src blob:/connect-src ws:wss:), `resolveCspMode(env)` (`report` default / `enforce` / `off`), `registerCsp(fastify, mode)` onSend hook. Report-only header by default; skips `/live/` proxied prefixes. Env `PI_DASHBOARD_CSP`. See change: improve-content-editor.
`registerCsp` only adds an ABSENT header, so a `serveApp` response's own enforced `Content-Security-Policy` survives in `report` + `enforce` (report also gets baseline `-Report-Only`); `off` registers no hook and the mount sets its own. Doc-comment + tests only, no logic change. See change: add-plugin-capability-routes (D7).

`resolveTrustedTypesMode({env,config,cspMode})` re-exported from `packages/shared/src/trusted-types-mode.ts` (env `PI_DASHBOARD_TRUSTED_TYPES` → config `security.trustedTypes` → default off iff CSP off, else report; unrecognized set value → report + warning; `server.ts` resolves once). See change: enforce-trusted-types-default; `registerCsp(fastify, mode, ttMode)` appends `require-trusted-types-for 'script'` to the baseline when modes match, else sets the other header kind with the directive alone; add-only-if-absent per kind; off+off → no hook. See change: harden-client-sinks.

Strict policy: `buildStrictCsp(nonce?)` = baseline directives with `script-src 'self' 'nonce-<n>'`. `cspNonceFor(reply)` memoized 16-byte nonce per reply (HTML only). `markViteProxied(reply)` = dev response (baseline only, no destinations). `report` mode = baseline RO + strict RO; `enforce` = strict enforcing; TT appended to same-mode header else TT-only header (label `trusted-types`). Every header carries `report-uri` only via `csp-report-paths.ts` — never `report-to` / `Reporting-Endpoints` (undeliverable on plain http in Chromium/Firefox). Default mode stays `report`. See change: harden-cors-and-csp-reporting, fix-csp-report-delivery.

`frame-src 'self' https:` in baseline AND strict (was `'self'`): operator-gated `WebPagePreview` (opaque sandbox) + fixed-host `YouTubePreview` (unsandboxed; now unblocked under `enforce`). `http:`/`data:`/`blob:`/`*` stay blocked; `frame-ancestors 'self'` unchanged. Untrusted HTML cannot create frames (markdown schema + DOMPurify drop `<iframe>`). See change: rich-chat-links (D13).
