# local-credential.ts — index

Local credential verifier + edge stamp. `createLocalCredentialVerifier({token,now,acceptLegacyToken,log,maxNonces})` → `stamp(req,{kind:'bridge'\|'http',boundAt,port?})` runs once per request: bounds → ±30 s window → `boundAt` floor → binding vs the connection's OWN `localAddress:port` → constant-time MAC → replay cache (TTL 61 s, cap 10 000, fail closed, insert after MAC). Verdict `proof\|legacy\|absent\|invalid(cause)` stamped under a private Symbol on `req.headers`; `hasLocalCredential(headers)` / `credentialVerdict` read it (unstamped ⇒ absent). `counterProof(verdict)` for the gateway. Deprecation + invalid-cause logs rate-limited 1/60 s per key with `suppressed=N`. See change: loopback-credential-proof (D3, D4, D9). Stamp is non-configurable + non-writable (immutable verdict). `listenWithProofFloor(app,setFloor,{port,host},now?)` takes the proof floor AFTER `ready()`, right before `listen`. See change: harden-credential-proof-binding.
