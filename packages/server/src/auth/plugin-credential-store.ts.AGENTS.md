# plugin-credential-store.ts — index

`createPluginCredentialStore(pluginId, {codec, path?})` over `~/.pi/agent/plugin-credentials.json` `{pluginId:{key:record}}`. `codec` REQUIRED (`getCredentialCodec("plugin-credentials")` in prod, fixed-key codec in tests); missing ⇒ `TypeError` before any file access. Own namespace only. `get`/`list`(keys)/`snapshot`/`set`/`remove`/`update(key,fn)` (sync fn inside lock; `undefined` deletes). Keys 1–200, `__proto__`/`constructor`/`prototype` rejected; record ≤64 KiB; ≤256 keys, ≤2 MiB per namespace; `PluginCredentialError{code,reason?}`. Unlocked reads never create the file; `structuredClone` copies.
Encrypted at rest: file = envelope (`credential-envelope.ts`); API + results unchanged. First write creates it 0600 already encoded (no `{}` placeholder with a codec). Plaintext file readable without a key; next write encrypts it.
`store_locked` (`PluginCredentialError.reason` = lock reason; message = shared remedy; never content): locked envelope (`key_mismatch|unsupported_format|envelope_damaged|key_missing…`) rejects ALL ops; no key available rejects writes. Locked file never quarantined, never overwritten. Corrupt plaintext keeps byte-exact `.corrupt-*` backup (refuse write if backup fails).
Write prologue `ensureWritable(codec)` runs BEFORE the store lock (D4): codec has key ⇒ no-op; else `await ensureCredentialKey()` (creates deferred key on first write), re-check codec; still none ⇒ `store_locked` (transient creation-lock refusal reports `keychain_unavailable`, not cached). In-lock `CredentialLockedError` ⇒ `store_locked`.
