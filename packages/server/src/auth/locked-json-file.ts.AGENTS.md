# locked-json-file.ts — index

Path-parameterised lock primitives shared by `auth.json` + `plugin-credentials.json`: `LOCK_OPTIONS` (`{stale:30_000,realpath:false}`, pi-coupled), `withLockedJsonFile(path,fn,{budgetMs,createIfMissing,logTag,signal})` (sync-only `fn` via `NotPromise<T>`, `ELOCKED`-only retry default 2 s, `signal` checked before every attempt, contained `onCompromised` → `ECOMPROMISED` before `fn`, 0600 `wx` placeholder), `readJsonChecked(path,logTag)` (never creates; corrupt → byte-exact `*.corrupt-<stamp>` quarantine, dedup `Map<path,Set<sha256>>`), `tryReadJson(path)` (unlocked, NEVER quarantines; `{ok:false}` on unparseable), `writeJsonAtomic(path,data,forceMode?)`, `corruptUnbackedRefusal(path)`, `_resetQuarantineDedupForTests`. Opt-in `codec?: JsonFileCodec` (type exported here; `CodecReadResult`): `readJsonChecked(path,tag,codec)` adds `locked?`/`encrypted?` to the result (locked ⇒ `data:{}`, NEVER quarantined; corrupt plaintext still quarantined); `writeJsonAtomic(path,data,forceMode?,codec?)` encodes via `codec.encode(data, existingBytes)` (throws `credential_locked` before any byte is written); `withLockedJsonFile(...,{codec})` skips the plaintext `{}` placeholder. Default (no codec) path byte-identical. `acquireLock` now exported (creation lock in `credential-key.ts`).
