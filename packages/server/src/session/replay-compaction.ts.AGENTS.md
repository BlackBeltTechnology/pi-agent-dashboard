# replay-compaction.ts — index

`compactEventsForReplay(stored: StoredEvent[]): StoredEvent[]` — pure REPLAY-ONLY pass dropping assistant `message_update` snapshots superseded by a later `message_end` (warm window ~20k → cold-path shape ~1k). Exempts thinking updates (`data.assistantMessageEvent.type` starting `thinking`; the client builds `role:"thinking"` rows with `startedAt`/`duration` that `message_end` reconstruction cannot reproduce) and the last text update before each `tool_execution_start` (seeds the reducer's `flush-<toolCallId>` row). Tail after the last `message_end` kept verbatim; seqs never rewritten. Store keeps the full stream. COUPLING: rule defined by `packages/client/src/lib/chat/event-reducer.ts`; guarded by `replay-compaction-equivalence.test.ts`. See change: compact-warm-replay-stream.
