# terminal-manager.ts — index

Server-side PTY terminal manager. Exports `RingBuffer`, `detectShell`, `TerminalManager` interface, `createTerminalManager(options)` — spawn node-pty with git-source augmented env, ring-buffer output replay, attach/detach WS clients, resize guards, `kill` (windows taskkill tree-kill, POSIX SIGHUP→SIGKILL), `getTranscript`. Exports `capTranscript(s, capBytes)` (byte-measured tail cap via store `measureBytes`; marker `…[N chars hidden]…\n` counted inside budget) + `deriveTranscriptCapBytes(maxEventDataSize, maxStringFieldSize?)` (75% of ceiling; unset string cap defaults to `DEFAULT_MAX_STRING_SIZE`, explicit `0` disables the string pass; fail-loud boot asserts derivedCap<ceiling and `maxStringFieldSize*6<ceiling`) + `DEFAULT_TRANSCRIPT_CAP_BYTES` (192 KiB, coupled to the 256 KiB event ceiling — D9). Ephemeral-only transcript retention: dead inline PTYs write a bounded (`TOMBSTONE_CAP=64`, insertion-ordered) `transcripts` tombstone (`{transcript,sawInput}`) in `pty.onExit` + kill-fallback BEFORE `entries.delete`, gated on `session.ephemeral && !released`. `releaseTranscript(id)`/`isReleased(id)`: sticky suppression `released` map (id→ts, `RELEASED_TTL_MS=60_000`, lazily swept) so a late exit path never re-tombstones a closed card. `sawInput` on `TerminalEntry` set at the sole user-input `pty.write` sites in `attach` (binary/non-JSON/unknown-JSON frames; resize/title do NOT). `getTerminalRecord(id)` returns capped `{transcript,sawInput}` from live entry else tombstone else undefined. See change: preserve-inline-terminal-transcript, fit-attachments-for-display.
