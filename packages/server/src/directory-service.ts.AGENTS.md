# directory-service.ts — index

Server-side directory-scoped ops. Exports `createDirectoryService`, `DirectoryService` interface, `isOpenSpecDataEmpty`, `hasOpenSpecDir`, `hasOpenSpecRoot`, `fnv1a32`, `phaseOffsetMs`, re-exports `effectiveMtimeOr`, `DiscoveredSession`. Session discovery + worker-pooled event hydration (`cancelLoad`), OpenSpec polling (mtime-gated cache, `fs.watch` change watcher, worker pool with pre-serialized payload, jitter, semaphore, TOCTOU gate), pi-resources scan (5× cadence), folder-HEAD poll+watcher, `reconfigurePolling`, `onDirectoryAdded`. Master `enabled:false` gate short-circuits to cleared state. Per-turn event-loop attribution: `scheduleOpenSpecTick` self-records `{at,ms,turn}` into `options.eventLoopSpikes` when a single synchronous turn's `performance.now()` run ≥ `eventLoopSpikeFloorMs` (default 100) — `tickOpen` (setInterval fire prefix), `dirPollPre` (setTimeout fire incl. `pollOne` sync prefix before the worker await), `dirPollPost` (broadcast continuation after the await); never summed across the await. Per-turn slow-tick alarm at `perTurnWarnMs` (default 250) names the turn, independent of the retained wall `durationMs > TICK_SLOW_WARN_MS` alarm. See change: attribute-openspec-poll-eventloop-stalls.

A `loadWorkerPoolDisposed` flag set in `stopPolling` (cleared in `startPolling`) makes it return `null` post-dispose; `loadSessionEvents` returns `{success:false,error:"disposed"}` rather than spawning a fresh pool during shutdown.

See change: offload-retained-transcript-replay — adds `loadRetainedEvents(sessionId, raw, knownContextWindow?)`, the RETAINED sibling of `loadSessionEvents`. Shares its plumbing: the `ensureLoadWorkerPool()` null → `{success:false,error:"disposed"}` guard, the `inFlightLoadJobs` registration (so `cancelLoad(sessionId)` reaches a retained job, which is why the retained read does not call the pool directly), and the `finally` that records the `hydrationMetrics` sample + emits the `HYDRATION_SLOW_WARN_MS` warning. Differs in three ways: dispatches `{raw}` instead of `{sessionFile}`, applies NO `customEventGroupResolver` (retained events do not carry that annotation), and takes NO `loadingSet` dedup (coalescing lives in the subscription handler). Records NOTHING for the short-circuited `absent` read and for the disposed pool — neither reaches parse-and-replay, and the ring holds 20 slots, so no-op reads must not evict real slow hydrations. `fileBytes = Buffer.byteLength(raw)`, comparable with the local path's `statSync().size`.
