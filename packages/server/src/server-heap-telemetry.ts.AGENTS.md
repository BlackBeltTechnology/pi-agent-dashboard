# server-heap-telemetry.ts — index

Heap + GC telemetry for the SERVER process. Exports `startServerHeapTelemetry`, `effectiveServerMaxOldSpaceMb`, `serverHeapTelemetry`. Three semantics differ DELIBERATELY from the session-side collector: the major-GC count is CUMULATIVE (a polled GET must be idempotent; read-and-reset would let two pollers erase each other), the effective ceiling is parsed from the RUNNING process's `execArgv` then `NODE_OPTIONS` and NEVER from the config file (`serverHeap` is cold-start-only, so divergence is the thing the field exists to show), and `heapSizeLimit` is not the request (carries V8's ~192 MB overhead). Classifies on `entry.detail.kind` vs `NODE_PERFORMANCE_GC_MAJOR`; `entry.kind` is `undefined` on the supported runtime. Started once at boot from `server.ts`. See change: bound-session-heap-and-gc-telemetry.
