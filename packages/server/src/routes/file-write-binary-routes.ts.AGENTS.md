# file-write-binary-routes.ts — index

`registerFileWriteBinaryRoute(fastify,{sessionManager,networkGuard,fileHandlers?})` — `POST /api/file/write-binary` in an encapsulated plugin (octet-stream Buffer parser only, 128 MiB `bodyLimit`). Query `cwd,path,mode=overwrite|copy,claim=<plugin>/<claim>,expectSha1` (required for overwrite). Order: query(400) → claim(403) → validator `enabled()`(403) → known cwd(403) → `isWritableHandlerTarget`(403) → fail-closed validator(503) → `maxBytes`(413) → worker validator before lock(422/503) → realpath lock: sha1 conflict(409) + tmp+rename mode-preserving \| copy `<stem>.<suffix>[-n].<ext>` via `wx`(≤99, 409). Exports `FileHandlerDeps`, `HandlerClaimInfo`. See change: add-editor-pane-file-handlers. Sibling copy: `siblingExt=<.ext>` (copy only; overwrite+siblingExt → 400; malformed → 400; not in claim `siblingExtensions` → 403); source must resolve inside cwd under a claimed ext (symlink escape → 403); target `<stem><ext>` then `<stem>-<n><ext>` (n ≤ 99 → 409) via `wx`; validator receives the sibling ext; log note `sibling=<ext>`. See change: extend-craft-web-to-all-apps (D6).
