# models-introspection-routes.ts — index

Ungated `GET /api/models` model-introspection surface for in-session agents. Exports `registerModelsIntrospectionRoute`, `ModelsIntrospectionRegistry`, `ModelsIntrospectionRouteDeps`. Subject only to dashboard auth gate (same posture as `/api/provider-auth/status`), registered unconditionally. Default = `getAvailable()` reachable rows `{id: provider/modelId, provider, reasoning?, input?, contextWindow?, maxTokens?, thinkingLevelMap?, cost?}`; `?annotated=1` = `getAllAnnotated()` adds `excludedReason`. `toRow` passes through the RAW native `thinkingLevelMap` (agent consumers interpret it; server derives NO `supportedThinkingLevels`), and NEVER emits `compat` or any credential. 503 `MODEL_PROXY_RUNTIME_MISSING` when pi-ai unresolved. See change: surface-model-introspection-to-agents, honor-native-models-json-metadata.
