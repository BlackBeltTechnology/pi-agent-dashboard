# session-routes.ts — index

Session REST routes. Exports `registerSessionRoutes`. Endpoints: `GET /api/sessions`, `GET /api/events/:sessionId/:seq`, `GET /api/sessions/:sessionId/tool-result/:toolCallId`, `GET /api/session-diff`, `GET /api/session-file` (path confined to session cwd). Uses `extractFileChanges` + `enrichWithVcsDiff`. `/api/session-diff` surfaces `totalAdditions`/`totalDeletions`; handler `await`s `buildSessionDiffCached(...)` over a per-registration `SessionDiffCache` (short-TTL + single-flight; no `spawnSync` git on the path). See changes: add-change-summary-table, fix-session-diff-eventloop-block. Adds `GET /api/session-change/:sessionId/:toolCallId` → `{ content?, edits? }`: resolves `sessionManager.get(sessionId).sessionFile` (NEVER built from `sessionId`), calls `findSessionToolCallPayload` for the FULL untruncated Write/Edit payload from the JSONL; session-addressed only (no path input, no traversal); miss/absent → 404. See change: opt-in-out-of-cwd-session-diffs.

See change: fix-session-diff-durable-source — `/api/session-diff` resolves `{sourceKey, load}` via `resolveDiffSource(session, eventStore, {pool: loadWorkerPool?.() ?? null, maxStringSize})` and calls `buildSessionDiffCached(sessionId, load, session.cwd, cache, {sourceKey, ended: session.status === "ended"})`. New optional deps: `loadWorkerPool?: () => SessionLoadWorkerPool | null` (transcript projection off-thread; absent/null → in-process) and `maxStringSize?: number` (the store's cap, so projected args match store-sourced ones). Existing route tests omit both.

See change: offload-retained-transcript-replay — the two retained reads are ASYNC now, so the `/api/sessions/:sessionId/retained-transcript` handler `await`s `readRetainedState`, and the archived-open stamp (`GET /api/sessions/archived/:id`) moves from `readRetainedState` onto `RemoteTranscriptStore.completenessOf(id)` — marker + `R_OK` content access, no body read, so the route stops reading up to 44 MB to answer a boolean. `completenessOf` never throws (a refused id reads `absent`).

See change: fix-session-diff-heap-retention — `sessionDiffCache = new SessionDiffCache<SessionDiffResult>(2000, 100, {maxBytes: 64 MiB, sizeOf: sessionDiffResultSize})` (byte-budgeted, estimated).
