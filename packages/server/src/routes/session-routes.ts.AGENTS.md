# session-routes.ts — index

Session REST routes. Exports `registerSessionRoutes`. Endpoints: `GET /api/sessions`, `GET /api/events/:sessionId/:seq`, `GET /api/sessions/:sessionId/tool-result/:toolCallId`, `GET /api/session-diff`, `GET /api/session-file` (path confined to session cwd). Uses `extractFileChanges` + `enrichWithVcsDiff`. `/api/session-diff` surfaces `totalAdditions`/`totalDeletions`; handler `await`s `buildSessionDiffCached(...)` over a per-registration `SessionDiffCache` (short-TTL + single-flight; no `spawnSync` git on the path). See changes: add-change-summary-table, fix-session-diff-eventloop-block. Adds `GET /api/session-change/:sessionId/:toolCallId` → `{ content?, edits? }`: resolves `sessionManager.get(sessionId).sessionFile` (NEVER built from `sessionId`), calls `findSessionToolCallPayload` for the FULL untruncated Write/Edit payload from the JSONL; session-addressed only (no path input, no traversal); miss/absent → 404. See change: opt-in-out-of-cwd-session-diffs.
