# session-routes.ts — index

Session REST routes. Exports `registerSessionRoutes`. Endpoints: `GET /api/sessions`, `GET /api/sessions/archived`, `GET /api/sessions/archived/:id`, `DELETE /api/sessions/archived/:id`, `GET… → see `session-routes.ts.AGENTS.md`. See change: archive-sessions-lazy-load. Adds `GET /api/sessions/:sessionId/retained-transcript` → `{entries,state}` for a REMOTE-origin session; `networkGuard`ed like every content-bearing sibling; the browser uses subscribe-time hydration, not this route. `decideRetainedRead` gates it — 400 on a path-bearing query field (shape, checked BEFORE the session lookup so 404-vs-400 cannot be differenced into an existence oracle), 404 unknown, 403 on a local-origin session (legitimate shape, wrong subject), 503 with no store. `GET /api/sessions/archived/:id` stamps `retainedTranscript` onto the single row for a REMOTE archived session (NOT the listing — that would cost a store read per row); the read-only open reseeds from it because `session_updated` is dropped client-side for non-resident sessions. Subject resolves `sessionManager.get(id) ?? sessionArchive.getById(id)` — an archived remote session is where the retained copy is the ONLY copy. Takes `deps.remoteTranscriptStore`. See change: serve-retained-remote-transcripts. `/api/session-diff` now sources events via `resolveDiffSource` + the loader form of `buildSessionDiffCached`; takes optional `deps.loadWorkerPool` + `deps.maxStringSize`. See change: fix-session-diff-durable-source. Adds `GET /api/sessions/:sessionId/entry/:entryId` — full custom-entry payload from the on-disk JSONL (never the 4 KB-capped event store), session-addressed, `networkGuard`ed; unknown/unflushed/off-branch/cross-session/traversal → 404. See change: add-custom-entry-renderer-slot.
`/api/session-file` branches on `containmentAllows(sessionDecision, absPath)`. See change: codeql-file-containment-barrier.

`/api/session-file`: `dashboardStateRefuses(absPath)` runs BEFORE the in-cwd shortcut (403 `path outside session directory`); non-grant read via `readFileStateChecked`. See change: close-security-map-high-findings (D1).
