# attachment-routes.ts — index

`GET /api/sessions/:sessionId/attachments/:attachmentId` — full-resolution original for click-to-zoom. Exports `registerAttachmentRoutes(fastify, {sessionManager, networkGuard})`. NOT load-bearing: the fitted derivative is already inline, so failure degrades only the zoom view. SECURITY CONTRACT — gates in order: `networkGuard` → session must exist with a `sessionFile` → id shape-check (400) before any lookup → transcript-scoped recovery → allow-listed mime only. Unknown session and unknown hash both return 404, so the route cannot be used to probe which session ids exist. Responses set `nosniff`, `default-src 'none'; sandbox`, and `Cache-Control: no-store, private` (private screenshots must not persist in shared caches — CWE-524). See change: fit-attachments-for-display.
