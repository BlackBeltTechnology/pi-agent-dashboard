# csp-violations-routes.ts — index

`registerCspViolationRoutes` — `POST /api/csp-violations` (network guard, 8 KiB, schema, per-principal burst 3 + 12/min → 429, unknown fields dropped, rejected bodies never logged) and `GET` counters (LRU 500; `trusted-types-shadow` detail entries in own LRU 500, never evicts violation keys). Optional `shadow:{outcome:n}` aggregate: non-object (array, string, number, `null`) or bad known count (not integer 1..1,000,000) → 400; unknown keys ignored. After schema + limiter, calls `deps.recordShadow(outcome,n)` per known key (persisted `ttShadow` in `CspReportStore`), never `record()`. `server.ts` builds `CspReportStore` before this route.
