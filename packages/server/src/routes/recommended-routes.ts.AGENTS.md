# recommended-routes.ts — index

Curated recommended-extensions list enriched with npm/GitHub meta, install scope, activeInPi, updateAvailable, skills, requirements probes. Exports `registerRecommendedRoutes`, `invalidateRecommendedCache`, `npmNameMatchesPath`, `createPkgReader`. `GET /api/packages/recommended`, 60s cache. Re-exports `parseSourceKey`, `sourcesMatch`, `SourceKey`. Install/active matching is an EITHER-match: pure-string `sourcesMatch` OR fs-aware `npmNameMatchesPath` (npm entries only) comparing the entry's npm name to `package.json#name` at a local candidate path — covers monorepo checkouts whose dir basename is decorated differently (`image-fit-extension` vs `@blackbelt-technology/pi-image-fit-extension`). Applied at ALL THREE sites: `inGlobal`/`inLocal`, the inner `installed.find` gating the version/skills read, and `activeInPi` over `activeSources` (the site driving the client Active/Remove button + missing-required count). `createPkgReader()` memoizes one `package.json` parse per path per request, shared by the name match and the version/`pi.skills` read; fails closed to string matching on any read/parse error. `sourcesMatch`/`source-matching.ts` stay fs-free. See change: match-local-installs-by-package-name.
