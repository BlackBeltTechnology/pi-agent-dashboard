# git-routes.ts — index

REST routes: git branches, checkout, init, stash-pop. Adds `GET /api/git/head`, `GET /api/git/worktrees`, `POST /api/git/worktree` (body `{cwd, branch, base?, path?}`) forwarding structured `{code, stderr}` errors from `addWorktree`. See change: add-worktree-spawn-dialog. Adds `POST /api/git/worktree/{remove,merge,push,pr}` + `GET /api/git/worktree/diff-stat`. Localhost-gated. Takes `sessionManager` + `browserGateway` deps. `/remove` pre-flight calls `activeSessionsUnder` → returns `{code:"active_sessions", sessionIds}` when non-empty; on success broadcasts `cwdMissing:true` per session under removed path. See change: add-worktree-lifecycle-actions. Adds `GET /api/git/worktree/bootstrap-status?cwd=<path>` (returns `{needsBootstrap, reason}` per decision tree: `not_required` / `ok` / `no_node_modules` / `stale_lockfile`) and `POST /api/git/worktree/bootstrap` (body `{cwd, requestId?}`; runs install in existing worktree). `POST /api/git/worktree` body extended with optional `requestId`; runs `detectBootstrapRequirement(repoRoot)` + `runBootstrap(...)` post-add; streams `worktree_bootstrap_progress` / `_done` / `_failed` to requesting browser via `worktreeBootstrapRegistry`. Response shape gains `bootstrap: {ran, durationMs?, skippedReason?}`. New error code `bootstrap_failed`. Takes `worktreeBootstrapRegistry` dep. See change: harden-worktree-spawn. worktree-init endpoints: `GET /api/git/worktree/init-status` (cached gate eval → {hasHook,needsInit,trusted}; `hasHook:false` responses also carry `configured:boolean` — `configRoot===null`→false, else `existsSync(<configRoot>/.pi/settings.json)` — distinguishing unconfigured dir ① from configured-no-hook ③; see change: distinguish-initialize-actions), `POST /api/git/worktree/init` (TOFU-gated; untrusted → init_untrusted carrying {hook,hash}; runs hook, streams progress). `POST /api/git/worktree` no longer auto-runs init. friendlier-worktree-init: `/init` registers a cwd-keyed run in `worktreeInitRegistry` (startRun/progressRun/finishRun) + fans progress/done/failed by cwd (not just requestId); after trust passes, re-evals gate → `needsInit:false`→`{ran:false,skippedReason:"already_initialized"}` (re-trust grants trust without running). New `GET /api/git/worktree/active-inits` → `{runs}` (running + terminal-within-TTL) for boot rehydration. `lastLineOf(tail)` = last non-empty line for the ghost preview. See change: friendlier-worktree-init. Replaced bootstrap + bootstrap-status endpoints. See change: generalize-worktree-init-hook. Adds `GET /api/git/pull-requests?cwd=` (lists open PRs via `listPullRequests`, `networkGuard` + gh resolution) + `POST /api/git/worktree/from-pr` (body `{cwd, prNumber, path?}`; runs `addWorktreeFromPr`). See change: add-worktree-from-pull-request. `POST /api/git/worktree` body `newBranch` now optional (string when present, else checkout mode); base still required. See change: worktree-checkout-existing-branch. Adds `GET /api/git/status?cwd=` (fresh `getGitStatus`), `GET /api/git/changed-files?cwd=` (picker list), `POST /api/git/commit` (body `{cwd,message,files}` → `commitFiles`; on success broadcasts fresh `gitStatus` to every same-cwd session; error codes → 400/409), `POST /api/git/commit-draft` (body `{cwd,files,sessionId}` → `commitDraftRelay.request` via `sendToSession`; stub when unwired). New deps `sendToSession`, `commitDraftRelay`. See change: add-session-uncommitted-indicator-and-commit. Adds `POST /api/git/worktree/remove-batch` (body `{items:[{cwd,force?,deleteBranch?}]}`; cap 50 enforced BEFORE any git → `batch_too_large` 400, non-array `items` → `items_invalid` 400; returns `{results}` in INPUT ORDER, one per item, never aborting on first failure; item `code` widens `RemoveCode` with `active_sessions | cwd_invalid | is_main_worktree`, `active_sessions` rows carry `sessionIds`) and `POST /api/git/worktree/prune` (repo-global `{pruned}`). Both behind `networkGuard` + `validateCwd`. `/remove` gains `deleteBranch?:boolean` (threaded to `removeWorktree`), an `is_main_worktree` 400 rejection (previously `git_failed` → 500), and returns `result.data` = `{removed,branchDeleted,branchDeleteCode?}`. Local `isMainWorktree(cwd)` + `stampCwdMissing(cwd)` helpers; the latter extracts the cwdMissing stamp+broadcast block shared by the single and batch endpoints. See change: manage-worktrees-filter-cleanup.
