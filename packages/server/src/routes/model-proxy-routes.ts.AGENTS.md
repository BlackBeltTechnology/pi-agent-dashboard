# model-proxy-routes.ts — index

OpenAI- + Anthropic-compatible proxy endpoints fronting model registry via pi-ai `streamSimple`. Exports `registerModelProxyRoutes`, `ModelProxyRouteDeps`, `ModelProxyRegistry` (now requires `firstAvailable`), `StreamSimpleFn`. Endpoints: `GET /v1/models`, `POST /v1/chat/completions`, `POST /v1/messages`. Shared `resolveRequestedModel` resolves both POST endpoints: label = request.model → firstAvailable(preferredModels) → defaultModel (else 400); alias-expand (`modelAliases`, exact key); first-slash `parseModelId`; `registry.find`; preferred fallback; else 404. Both split("/",2) resolution + concurrency-provider sites converged onto `parseModelId`. Concurrency + SSE/non-stream + request logging + abort on disconnect. Disconnect = `reply.raw` "close" with `!writableFinished` — NOT `request.raw` "close" (Node 24 fires it once the body is consumed, before the listener attaches → abort never fired). Mid-stream throw (headers already sent) → converter `error` event + `reply.raw.end()`, never `reply.code(500)` (was `ERR_HTTP_HEADERS_SENT` + hung client). Parallel isolation, abort, mid-stream failure covered by `__tests__/model-proxy-parallel-isolation.test.ts`. See change: fix-and-prefer-model-proxy-resolution.
