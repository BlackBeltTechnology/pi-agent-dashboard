# addons-routes.ts — index

Add-ons hub REST. `registerAddonsRoutes(fastify,{networkGuard,packageManagerWrapper,broadcast,knownDirectories,lookupNpm,setPluginsEnabled,…})`. `GET /api/addons/catalog` → `{success,features:AddonFeature[]}` (joiner `addons/addons-catalog.ts`; GCs stale restore records). `POST /api/addons/:featureId/toggle {enabled,dryRun?,confirmToken?}`: dry run = no locks/writes + `confirmToken`; real = hub queue → `runExclusive` (409 busy) → settings-file lock → plugin-config lock; 409 `stale-confirmation`/`duplicate-entries`/`blockers`/settings-unparseable; 400 core. Folder mode: `GET ?scope=local&cwd=` (folder catalog, read, not trust-gated) and `POST {scope:\"local\",cwd,enabled,removeUnowned?}` (project delta; hub lock → project settings lock; `cwd` absolute+normalised → 400, `admitCwd` 403/503). Feature ids can be long (`maxParamLength` 1024 in server.ts). See change: addons-hub-feature-catalog. See change: addons-hub-folder-view.
