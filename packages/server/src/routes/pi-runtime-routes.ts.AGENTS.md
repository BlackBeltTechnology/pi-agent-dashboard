# pi-runtime-routes.ts — index

Fastify plugin: `GET /api/pi/installs` (every discoverable pi install + per-consumer `usedBy`, sync/divergence, floor) and `POST /api/pi/runtime` (BOTH consumer selections in ONE `OverridesStore.setMany` transaction; `null` = Automatic, clearing that consumer's pin in the same write). Both carry the same `networkGuard` as `/api/tools`. Validates each path via `validatePiOverridePath` and 400s naming the failed check. Rescans `pi` + `pi-coding-agent` after a successful persist — `setOverrides` bypasses `setOverride`, so without this the registry would keep serving the OLD argv while the UI showed the new selection. Logs an audit line on every applied selection. Two sequential PUTs were rejected: a crash between them splits the runtime in half. See change: select-pi-runtime-install (design D7).
