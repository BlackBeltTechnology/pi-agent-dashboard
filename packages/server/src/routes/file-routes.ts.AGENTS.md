# file-routes.ts — index

REST routes for file read/browse. `/api/file` decodes leading `file://` on `path` via `decodeFileUri`. Absolute paths accepted but still gated by known-session-cwd + traversal check. See change: unify-file-link-openability. Adds GET /api/favorite-models → {labels}. See change: enrich-model-selector-capabilities-favorites. 4 guard sites (`/api/file`, `/api/file/exists`, `/api/file/raw`, `/api/file/render`) route through `isAllowed`. exists keeps pinned-dir anchor + `"unknown cwd"`/`"path outside cwd"` strings. See change: git-root-file-containment. /api/file/raw adds layer ③ artifact-root image anchor via isImageUnderArtifactRoot (image-only, realpath-contained); only raw route, not /api/file or /api/file/render. See change: serve-agent-artifact-previews. GET /api/file file branch sniffs first 1024 bytes, calls `fileKind(resolved, sniff)`, returns `{ type:"file", kind, mimeType, size, content? }`. content read only for monaco/markdown viewers. /api/file/raw (pre-existing) serves image/pdf bytes. See change: add-internal-monaco-editor-pane. Adds `POST /api/file/write` (body `{cwd?,path,content,mtime}`; isWritableMdTarget gate → 403; mtime mismatch → 409; atomic tmp+rename; returns new mtime), `GET /api/file/md-candidates` (scoped picker list), `GET /api/file/md-read` (scoped markdown read, same guard, serves global ~/.pi/agent that /api/file cannot). `/api/file` read now returns `mtime`. See change: directory-settings-page-and-scoped-md-editing. Adds `GET /api/file/tree?cwd=&path=` → `{entries:{name,isDir}[]}` via single `readdir(withFileTypes)`, hidden INCLUDED, same known-cwd+containment gate; single source of truth for editor-pane tree (fixes #1 hidden-dir mislabel). See change: improve-content-editor. `/api/file/render` gains a `.docx` branch (two-tier, design D8): `{mode:"pdf"}` (document-converter render, cached) or `{mode:"html",html,truncated,imageCount}` (mammoth+hyperlink-guard+DOMPurify+image-cap); ANY engine error falls through to html. Adds `GET /api/file/rendered-pdf?cwd=&path=` (streams cached docx→PDF, `application/pdf`) and `GET /api/file/sheet?cwd=&path=&limit=` (SheetJS structured JSON `{sheets[],activeSheet,encoding?}`; csv encoding-detected). Shared `gateOfficeFile` helper: ext allowlist (else 400) + `stat.size` cap (>cap → 413 before read) + traversal gate. Injectable `docxPdfEngine`/`officeCaps`/`docxRenderMode` deps (tests). Corrupt/password/oversize degrade to `{success:false}` (design D5). See change: render-office-previews. `/api/file/render` + `/api/file/rendered-pdf` also accept `.pptx` (per-ext size cap via `pptxSizeCap`): pptx → engine-only PDF render (`renderPptx`, `{mode:"pdf"}`); NO in-process fallback — engine absent → `{success:false}` → client FallbackPreview. See change: render-pptx-preview. Adds shared async `gateFilePath(cwd, relPath, sessionManager)` (known-session + `isAllowed`, factored so the EML routes CALL it not re-impl) + `GET /api/file/eml?cwd=&path=&allowRemote=` (mailparser parse + DOMPurify sanitize → metadata-only JSON; non-`.eml`→400; >25 MB→413 before read; malformed→400 no crash; parse cache) and `GET /api/file/eml-attachment?cwd=&path=&index=` (streams one decoded part, ALWAYS `Content-Disposition: attachment` + `nosniff`; bad index→400; out-of-range→404). See change: add-eml-preview. Adds `POST /api/file/resolve-mention` (body `{cwd,mention}` → `{resolved, kind}`\|`{resolved:null}`): gates `cwd` against known-session set FIRST (mirrors `/api/file`, NOT the wider exists-only pinned set — D2/F6/F7) then delegates to `resolveFileMention`; never stats an untrusted cwd (403). Module `homePiAnchor()` = `join(os.homedir(),".pi")` (call-time, fake-HOME safe); the open/preview routes `/api/file` + `/api/file/raw` + `/api/file/render` now anchor `isAllowed` on `[cwd, homePiAnchor()]` so a resolved `~/.pi/…` mention previews without a 403 (D7). See change: server-side-file-mention-resolution.
