| `brief-generator.ts` | Brief engine. `createBriefGenerator({resolveModel, complete, timeoutMs?, maxConcurrent?})` → `{generate(req) → BriefOutcome, stats()}`. Global cap 2 + FIFO queue; 20 s timeout (aborts signal, frees slot); never throws; logs `[questions] brief outcome=… latencyMs=…` (no content); counters ready/failed/unavailable/fallbacks. Label `generated` vs `generated-limited` (no assistant text). Consts `BRIEF_TIMEOUT_MS`, `BRIEF_MAX_CONCURRENT`. See change: add-pending-question-stack (D4, 4.6). |

Unbound/unknown/null registry/no stream fn/malformed JSON → unavailable, never throws; malformed/unreadable logs `console.warn`. See change: add-pending-question-stack. |
