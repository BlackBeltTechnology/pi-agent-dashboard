# DOX — packages/server/src/tls/sources/acme

ACME DNS-01 certificate source (cert-source type `acme`): publicly trusted certs for operator-owned domains on private/mesh IPs, no inbound exposure. Solver secrets live in the credential vault (`tls:<id>`, kind `tls-solver`). Guide: `docs/acme-dns01-certs.md`. See change: add-acme-dns01-certs.

| File | Purpose |
|------|---------|
| `accounts.ts` | ACME account keys: `loadOrCreateAccountKey(tlsRoot,dir,email,mayCreate)` → ECDSA P-256 at `<tlsRoot>/acme-account-<sha256[:32]>.key` (0600, tmp+rename, no write once source removed/aborted); in-memory CA account-URL cache; `listAccountKeyHashes`/`removeAccountKey` for GC. |
| `acme-source.ts` | `AcmeCertSource` + `acmeSourceType` (registered by `ensureBuiltinCertSourceTypes`). `names()`=normalized domains (never null); `configFingerprint`=sha256(canonical dir ∣ effective advertise ∣ name); `attemptTimeoutMs`=10.5 min (×names for acme-dns); staged `obtain` (order → dns-publish → propagation → validation → finalize) via injectable `AcmeClientFactory`; 10 min deadline after lock wait, abort ctx in `AsyncLocalStorage` + `acme.axios` request interceptor, late-publish cleanup; CA `invalid` → `RetryAfterError(1h)`; `readiness({force})` gates `credentials`/`dns-cname`/`dns-zone` + `details` (`directory`,`staging`,`solverType`,`fulldomain`,`propagationMode`,`checkedAt:<domain>`), 5 min per-domain cache; `invalidateReadiness()`; `onRemoved` aborts + GC. |
| `config-projection.ts` | `projectAcmeConfigured(data)`: fills `tls.sources[].solver.configured` for `GET /api/config` from the vault listing (names only). |
| `credentials.ts` | Vault adapter `createAcmeCredentials(store)`: `readSecret`, `isConfigured`, `vaultState` (`unavailable` for corrupt OR locked vault; consumers `acme-source` gate, `gc`, `config-projection` follow, no change), `save` (cloudflare `{token}` / acme-dns `{user,key}`, atomic), `redactorFor`, `deleteNamespace`, `listNamespaces`; pure `redactSecrets` (raw, percent-encoded incl. full/double, JSON-escaped, base64/base64url, auth headers, `token=`). |
| `dns.ts` | `createDnsApi`: DoH SOA/NS discovery, per-authoritative-server `dns.Resolver` (3 s, tries 1), 5 s rounds / 180 s bound naming the lagging server, DoH both-resolver fallback (`propagationMode`), CNAME at authoritative servers, `authoritativeOverride` for the E2E harness. |
| `e2e-overrides.ts` | `resolveAcmeE2eOverrides(env,log)`: `PI_E2E_CLOUDFLARE_API` / `PI_E2E_DNS_AUTHORITATIVE`, honoured only with `PI_E2E_SEED=1` and a `localhost`/`.test` host; else logged + ignored. |
| `entry.ts` | Pure: `normalizeAcmeEntry`, `validateAcmeEntry` (1–20 LDH/`xn--` names, single-label wildcard, no IP literals, email, `agreeTos`, `https` directory, solver allowlist so no secret reaches config), `canonicalDirectory`/`classifyDirectory`/`effectiveAdvertise`, `accountHash`. |
| `gc.ts` | `acmeGc()` (coalesced): delete `tls:<id>` namespaces + `acme-account-*.key` with no configured acme source; only when `config.json` state is `ok` and the vault is healthy. Called from `onReconciled`, `onRemoved`, entry routes, server start. `configuredAcmeEntries(raw)`. |
| `runtime.ts` | `configureAcmeRuntime`/`getAcmeRuntime`/`resetAcmeRuntime`: injected vault `credentials`, `tlsRoot`, `readConfigState`, `env`, `log` (server wires the vault at start; lazy default store uses `getCredentialCodec("vault")`). See change: encrypt-credentials-at-rest. |
| `types.ts` | Contracts: `Dns01Solver` (`publish`/`cleanup`/`check`/`checkCredentials`/`acquireOrderLock`), `SolverDeps`, `DnsApi`, `challengeOwner`, `SOLVER_LABELS`. |
| `solvers/` | → see `solvers/AGENTS.md` |
| `__tests__/` | Unit/integration suites: `acme-source-*.test.ts` (issuance E5–E11, timing E10/E32/E33/X3/X4, manager E16–E21/E29/E34/E36/X5/X6, security X7/X8), `cloudflare-solver`, `acme-dns-solver`, `dns`, `credentials`; shared `acme-source-helpers.ts`. |
