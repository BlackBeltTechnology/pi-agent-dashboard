# DOX — packages/server/src/tls

Optional native TLS listener: a second `https.Server` dispatching into the existing Fastify instance (one route table, one gate chain, one upgrade switch, two transports) with per-SNI hot-swapped certificates from pluggable sources. Off by default (`tls.enabled`). See change: add-tailscale-cert-tls.

| File | Purpose |
|------|---------|
| `cert-files.ts` | Disk store `~/.pi/dashboard/tls/<sourceId>/<name>/{cert.pem,key.pem,meta.json}`. `CertFiles`: `writePair` (tmp with attempt id → `chmod 0600` key → rename key → rename cert → `meta.json` last), `load` (parse + `checkPrivateKey`; mismatch/garbage → `{loaded:null,reason}`), `readMeta`/`writeMeta` (unique tmp names), `listNames`/`listSourceDirs`/`removeName`/`removeSource`/`removePair`. `CertMeta` (fingerprint, advertise, kind, details, notAfter, stage, lastError, failures, nextAttemptAt). `isSafeCertName`, `certValidity`, `pairMatches`. Every fs path goes through `within(base, …)` (resolve + prefix check) and ids/names are validated (`^[a-z0-9][a-z0-9-]{0,31}$` / `isSafeCertName`): an id or name can never escape the TLS dir. Only the manager writes. |
| `cert-manager.ts` | `refreshReadiness(sourceId)` forced readiness re-read without an attempt (credentials save). `CertManager` lifecycle per `(source,name)`: load from disk, obtain when missing / < 1/3 validity / `meta.fingerprint ≠ configFingerprint(name)`, single-flight (`trigger` joins), gate-before-obtain (unmet source-wide or name-scoped gate → no `obtain()`, no failure, re-check 15 min, forced), attempt deadline (`attemptTimeoutMs` default 10 min; late result discarded, slot freed), backoff 5 min doubling cap 6 h floored by `RetryAfterError`, persisted `failures`/`nextAttemptAt`, prune (only when `names()` is a list; `null` keeps held certs), name ownership (first source wins; exact+wildcard overlap OK), orphan-dir cleanup, 12 h `tick()`. `reconcile(sources, invalid)` (serialised), `trigger(sourceId, name?)`, `status()` (never calls out), `advertisable()`, `heldExactNames()`, `knownNames()`, `settle()`, `suspend()`. |
| `cert-store.ts` | `TlsCertStore`: name → `SecureContext`; `resolve` exact → single-label wildcard → null; `sniCallback` errors the handshake on no match (no default cert); `exactNames()`. |
| `source-registry.ts` | `registerCertSourceType`/`getCertSourceType`, `validateSourceEntry`/`validateTlsSources` (type registered, id `^[a-z0-9][a-z0-9-]{0,31}$`, unique, defaulted from `defaultId`, `tailscale` reserved, per-type `validate`). |
| `sources/tailscale-cert.ts` | `TailscaleCertSource` + `tailscaleSourceType`: `tailscale cert` into a private 0700 temp dir via own 120 s runner (+ promise race), cached `status --json` (30 s), gates `tailscale-running` / `https-certs` (shared `tailnetHttpsEnabled`), `names()` null when not running, `details.ipv4`. |
| `sources/acme/` | → see `sources/acme/AGENTS.md` (ACME DNS-01 source). See change: add-acme-dns01-certs. |
| `tls-bridge-route.ts` | `routeBridgeUpgrade`: bridge-scope upgrade → gateway only on a TLS socket + live `acceptBridges`, else 400 without consuming the ticket. `onTlsBridgeSwitchChanged`: push then close TLS bridges. See change: prove-vault-bridge-tls. |
| `tls-config-validation.ts` | `validateTlsConfigWrite(partial, stored, env)` for `PUT /api/config`: tls fields, sources, `tls.host` IP/localhost, port uniqueness vs effective `port`/`piPort`/`modelProxy.secondPort` of the MERGED config. `touchesTlsOrPorts`. `tls.acceptBridges` must be boolean (400). See change: prove-vault-bridge-tls. |
| `tls-listener.ts` | Registers `acme` next to `tailscale` (`ensureBuiltinCertSourceTypes`); `refreshReadiness(sourceId)`. `TlsListener`: `reconcile()` (awaits only the (re)bind; certs scheduled), `markReady()`, bind retry 1 min doubling cap 15 min on `EADDRNOTAVAIL`/`EADDRINUSE`, parity timeouts (`MAIN_KEEP_ALIVE_TIMEOUT_MS`, `MAIN_CONNECTION_TIMEOUT_MS`, `requestTimeout 0`), no session resumption (resumed sessions skip SNI), `tlsListenerNames()` (enabled AND bound), `tlsListenerUrls()` (non-loopback only), `status(detailed)`, `trigger()`, `stop()` (`closeAllConnections`). Fastify-independent (`dispatch` injected). |
| `types.ts` | `CertSource`, `CertSourceType`, `Gate`, `ObtainedCert`, `RetryAfterError`, `SourceReadiness`. |
