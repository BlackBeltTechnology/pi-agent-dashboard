| `subscription-handler.ts` | Browser→server subscription handlers: `handleSubscribe` (replay stored events in batches with backpressure, stale-lastSeq reset + full replay, on-disk load via `directoryService`, asset/UI-state replay) and exports `replayUiState`, `replaySessionAssets`, `sendEventBatches`. See change: split-notify-from-prompt-request.  `sendEventBatches` terminates an EMPTY payload explicitly with one `event_replay { events: [], isLast: true }` before the batch loop, so a warm empty delta / a cold zero-event session still gives the client a clearing edge; the loop's final batch already carries `isLast: true`, so an exact multiple of `REPLAY_BATCH_SIZE` must NOT get an appended terminal frame. See change: show-replay-in-flight-indicator. |
