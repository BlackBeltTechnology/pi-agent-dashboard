# process-manager.ts — index

Spawns/kills pi sessions. Exports `spawnPiSession`, `buildSpawnEnv`, `buildHeadlessArgs`, `buildInteractivePiArgs`, `buildTmuxCommand`, `shellEscape`, `setResolver`/`resetResolver`, `setKeeperManager`/`getKeeperManager`, `SessionOptions`, `SpawnResult`. Supports tmux/headless/interactive/rpc-keeper strategies. `SpawnResult` carries `spawnToken`, `keeperSockPath`, `code` (`SpawnFailureCode`). `buildSpawnEnv` takes optional `argv0`/`electronDeps`; when `argv0` is the Electron binary (`electronAsNodeRequired`) re-adds `ELECTRON_RUN_AS_NODE=1` that `resolver.buildSpawnEnv` strips (absent argv0 ⇒ byte-identical). `spawnWt`/`spawnHeadless` pass `piCmd[0]`; `spawnTmux`/`spawnWslTmux` untouched (shell token). `buildTmuxCommand` passes the spawn token per-window with `tmux -e PI_DASHBOARD_SPAWN_TOKEN=...`: `execSync(cmd,{env})` only sets the tmux CLIENT's env, so `new-window` inherited the tmux SERVER's and every window after the first carried the FIRST spawn's token (3 panes / 1 token, measured). See changes: spawn-correlation-token, add-rpc-stdin-dispatch-with-keeper-sidecar, spawn-failure-diagnostics, fix-nodescript-argv-electron-execpath-fallback, fix-tmux-session-shutdown-leak.
