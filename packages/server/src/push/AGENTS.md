# DOX — packages/server/src/push

Server push notifications: fan-out of the unread trigger to Web Push / FCM / webhook tokens. Built only when `push.enabled === true`. One row per source file.

| File | Purpose |
|------|---------|
| `build-push-payload.ts` | Pure `buildPushPayload(session, {eventType, after, payload})` → `{type:"session_attention", trigger, sessionId, title, body, url:"/session/<id>"}`. Trigger from `(eventType, after, payload)`: crash (`agent_end` + error) > input (`after.currentTool==="ask_user"`, covers payload-less `prompt_request`) > turn_end. Name falls back to cwd basename; crash body cut to 200 chars + `…`, else model id. See change: add-server-push-notifications. |
| `push-dispatcher.ts` | `createPushDispatcher({registry, transports, coalesceWindowMs, getSession, logger, now?})` → `{fanout, test, shutdown}`. `fanout` returns void, never throws, memory-only sync work, delivery via `setImmediate` + `Promise.allSettled`. Devices (`web-push`,`fcm`) only on `unreadEdge`; webhooks every trigger, coalesced per `sessionId::tokenId` (lazy expiry 2×window, dropped on `registry.onRemove`). Outcome: gone → remove, ok → touch, else recordFailure; unavailable transport → warn + skip. One log line per delivery `{tokenId, transport, target(redacted), outcome, ms, status?, errorCode?}`. `test(tokenId?)` bypasses cadence + coalescing, opaque `{tokenId, ok, gone?}`. See change: add-server-push-notifications. |
| `push-service.ts` | `createPushService({config, dataDir, getSession, selfPort, logger?, lookupAll?, webhookTimeoutMs?, transports?, now?})` → `{registry, dispatcher, vapidPublicKey, errors, vetDestination, shutdown}`. Files `push-tokens.json` + `push-vapid.json` in `dataDir`. Webhook always; web-push only with `webPush.contactEmail`; fcm only when service account loads. Init problems collected in `errors` (→ `/api/health.push.errors`), never thrown. See change: add-server-push-notifications. |
| `push-token-display.ts` | `displayPushToken(token)` — secret-free rendering: webhook `label (origin)`/`origin`; web-push `<endpoint host> browser`; fcm `fcm device`. Used by routes + dispatcher logs. See change: add-server-push-notifications. |
| `push-token-registry.ts` | `createPushTokenRegistry({path, now?})`. In-memory Map, loaded once; `add` idempotent by `deviceToken` (keeps id, bumps lastUsedAt), cap 50 → `{ok:false, reason:"capacity"}`; `add`/`remove` write through at 0600; `touch` persists ≤ 1/60 s; `consecutiveFailures` in memory; `matching(sessionId)` honours `sessionFilter`; `onRemove` listeners. Unparseable file → `<file>.corrupt-<ms>`, start empty, `errors` entry. See change: add-server-push-notifications. |
| `push-vapid.ts` | `loadOrGenerateVapidKeys(path)` → `{publicKey, privateKey}`; generated once via `web-push`, persisted 0600, reused across restarts. Only `publicKey` leaves the server. See change: add-server-push-notifications. |
