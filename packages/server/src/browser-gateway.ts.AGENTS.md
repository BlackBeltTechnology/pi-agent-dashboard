# browser-gateway.ts — index

WebSocket gateway for browser clients. Exports `BrowserGateway` interface, `createBrowserGateway`, `buildOpenSpecConnectSnapshot`. Routes `BrowserToServerMessage` switch to `browser-handlers/*`. Manages subscriptions, replay suppression, headless `headlessPidRegistry`, `pendingResumeRegistry`, `viewedSessionTracker`, pending UI/prompt request replay, `broadcastEvent`/`broadcastSession*`/`broadcastOpenSpecUpdate` (pre-serialized payload fanout), plugin `registerHandler`/`registerDisconnectHandler`. Back-pressure guard via `MAX_WS_BUFFER`. Exports `getDroppedFrameStats()` (per-hop server→browser drop counters); `recordDroppedFrame` instruments each `MAX_WS_BUFFER` drop, surfaced on `/api/health#droppedFrames`. See change: fix-stuck-tool-card-on-dropped-event. Routes `role_remove` → `piGateway.sendToSession` (mirrors `role_set`/`role_preset_*` cases; without it custom-role removal was dropped server-side). See change: add-custom-roles-ui. Routes `subagent_resync_request` → `handleSubagentResyncRequest` → `piGateway.sendToSession`. See change: fix-subagent-live-detail-reliability (D2). Routes `set_session_tags` → `handleSetSessionTags`. See change: add-session-tags. Exports `replayTailToSubscribers(sessionId)`: delivers the bounded `selectWindow` tail to subscribers in back-pressure-aware `setImmediate`-yielding 50-event batches (`kind:"tail"`, `hasOlder`), replacing the single giant `event_replay` frame the resume `replay_complete` path used to send (that frame could exceed `MAX_WS_BUFFER` + be silently dropped). `recordDroppedFrame` emits a one-shot `frames_dropped` notice per session once drops cross `DROP_NOTICE_THRESHOLD` (5) — sent bypassing the buffer guard; a `subscribe` for that session re-arms the notice. See change: bound-bridge-resume-replay (D2, D4).
