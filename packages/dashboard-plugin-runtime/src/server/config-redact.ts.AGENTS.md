# config-redact.ts — index

`redactWriteOnly(config, schema)` — strips every `writeOnly:true` property, recursing `properties` + `patternProperties` + object-shaped `additionalProperties` + array `items`; pure, same-reference no-op when nothing stripped. `redactPluginConfigForClient(pluginId, config, repoRoot?)` — discovery + schema load wrapper used at every client-facing config surface (GET /api/config, POST /api/plugins/:id broadcast, toggle broadcast, `updatePluginConfig` broadcast). **FAILS CLOSED**: an unresolvable plugin or an unloadable/unparseable declared schema returns `{}` + a log, NEVER the raw config (an unreadable schema is exactly when `writeOnly` is unknown → returning it verbatim would leak the pairing token). Only a resolved plugin with NO declared schema passes through. Tasks 2.12 / GAP A; fail-closed added by task 6.1 (Audit).
