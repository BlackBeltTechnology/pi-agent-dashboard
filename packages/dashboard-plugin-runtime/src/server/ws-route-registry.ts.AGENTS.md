# ws-route-registry.ts — index

Plugin-owned WS route scopes (add-browser-relay D1). `WsRouteRegistry` + singleton `getWsRouteRegistry()` (mirrors plugin-status-store). `register(pluginId, scope, opts)`: kebab scope; `pathPrefix` `/ws/<seg>/`-shaped; THROWS on duplicate scope, overlapping/nested prefix (both directions), reserved core scopes (`browser`/`terminal`/`live`/`bridge`), reserved core routes (`/ws` exact path — plugin prefixes legitimately live under `/ws/<scope>/`; `/ws/terminal/`, `/live/`, `/ws/bridge` reserved as namespaces), or registration outside the activation window (`beginActivation`/`endActivation`, driven by loader.ts). `resolveScope(pathOnly)` — active scope for a prefix (server wires it into `routeScopeForUrl` via `setPluginScopeResolver`). `trackSocket(pluginId, ws)` (via `meta.trackSocket`; close-event cleanup) + `teardownPlugin(pluginId)` — close tracked sockets `close(1001, "plugin disabled")`, unregister scopes, tombstone prefixes (`isTombstonedPath` → later upgrades 404); idempotent. `WsRouteRegistration` = `{pathPrefix, admitOrigins: readonly string[], handleUpgrade(request, socket, head, meta)}`; `admitOrigins` copied by value at register time. See change: add-browser-relay.
