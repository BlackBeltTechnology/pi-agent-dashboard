# app-mount.ts — index

`ctx.serveApp` engine. `mountApp(env,opts)` validates (`appId` `^[a-z0-9-]+$` default plugin id + unique, required `csp` string\|`(request)=>string`, `dir` realpath inside `packageRoot` OR `dataDir`, may be absent) then routes GET+HEAD `/apps/<appId>` (308, keeps query) and `/apps/<appId>/*` with `compress:false`: extension allowlist (`.html .js .mjs .css .svg .png .jpg .jpeg .gif .webp .ico .woff .woff2 .wasm`; `.json`/`.map`/`.gz`/dotfiles/dirs/`..`/symlink escapes → 404), root realpath resolved PER REQUEST (a `current` symlink swap applies; absent → 503 logged once; escaped → 404), extensionless unmatched → `index.html` (`no-store`), missing asset → 404, content-hashed names `immutable`, `.gz` sibling + `Accept-Encoding: gzip` → `Content-Encoding: gzip` + `Vary`, enforced `Content-Security-Policy` on every file response (function throw/invalid → 500 logged once), `crossOriginFrame` → ACAO `*` + CORP `cross-origin`, never credentials. `AppMountRegistry` + singleton `getAppMountRegistry()`/`clearAppMountRegistry()` (`has/add/list/isMountPath/coversRoute`) read by the auth plugin + namespace-coverage test. Trust gate is the host's (`packages/server/src/auth/serve-app-host.ts`). See change: add-plugin-capability-routes.
