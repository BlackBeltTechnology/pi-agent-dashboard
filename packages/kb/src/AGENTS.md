| `dox-triage.ts` | Stale-row triage. `kb dox lint` stale = bytes changed, NOT row wrong. `resolveBaseline` walks file history for the commit whose blob sha256 == acked hash → `git diff <commit> --` (working tree, NOT `..HEAD`: staleness hashes the working tree, so `..HEAD` misses uncommitted edits and yields no evidence). | `dox.ts` | DOX tree. Directory-level AGENTS.md scaffold + audit. kb agents <path> nearest-applicable chain. Detect-don't-write: dox init/--fix fill PATH columns + prune orphans only. `over-threshold` lint splits two arms: `arm:"bytes"` (actionable — bytes > `AGENTS_BYTE_CAP` 30 KB, auto-injected per turn, remedy sidecar split) + `arm:"rows"` (informational — inline count > `ROW_CAP` 40, no per-turn cost, optional foldering). `countInlineRows(af)` counts INLINE rows only (excludes sidecar-pointer rows matching `/→ see \`<File>.AGENTS.md\`/`) — sibling to `parseRowPaths` (public export consumed by kb-extension; signature untouched, stays complete path list). Splitting a heavy row to its sidecar drops both byte + counted-row totals. `ROW_CAP`/`AGENTS_BYTE_CAP` numeric values unchanged. `isMdFile` excludes `*.AGENTS.md` sidecars + `*.agent.md` companions (both DOX index artifacts, not documentable source). `DEFAULT_EXCLUDE` skips build output (`out`) + electron bundled/vendored trees (`bundled-extensions`, `electron/resources/server`) + `.reverse-spec-scratch` (transient reverse-spec experiment output) — all gitignored, fs-walk-only, else bogus missing/companion rows; `server` scoped to `electron/resources/server` so real `server` source dirs stay indexed. `resolveRowPath(agentsDir,cwd,rp)` resolves rows relative to their OWN AGENTS.md dir, repo-root `cwd` fallback (nested AGENTS.md may document a file living at project root) before orphan. `parseRowPaths` + `doxLint` scan only rows under a `# DOX —` heading (prose tables like Subagent Routing ignored). `doxLint` `walkAgents` tests `DEFAULT_EXCLUDE` on the cwd-RELATIVE path (mirrors `walkFiles`) so running inside `.worktrees/` does not exclude the whole tree. `rowPaths`/staleness keyed cwd-relative. `DEFAULT_EXCLUDE` scopes `.pi` narrowly: walks `.pi/skills/`, `.pi/agents/`, `.pi/prompts/` (carry DOX rows); skips `.pi/{dashboard,npm,git,flows}` (caches, kb index, mirrors, run state). Blanket `.pi` exclusion previously blinded the orphan check on the whole tree. `doxLint({sourceFileRows:true})` adds the D9 SOURCE arm: a `.ts`/`.tsx` in a covered area with no row in ANY ancestor AGENTS.md and no `<file>.AGENTS.md` sidecar reports `missing` with `arm:"source"` (markdown findings carry no arm). Opt-in (CLI `--source-rows`), OFF by default — 70 findings on this repo, so default-on would red-wall CI — and never auto-fixed in `--fix` (a blank purpose row is worse than an honest finding). See change: split-components-agents-dedup-rollup. See change: fix-dox-lint-false-positives. See change: fold-oversized-agents-directories. See change: fix-kb-search-retrieval-quality. |

All callers must `await`. | `render.ts` | Shared hit renderer for CLI + kb_search tool. `renderHits(hits, { leading:"score"\|"rank", parentGlyph, multiline })`. | `sources.ts` | Pluggable source resolvers. fs/npm/git/https → local dir. KB reads markdown only, never executes source. |
| `sqlite-store.ts` | Default KbStore backend over node:sqlite. FTS5. WAL + `PRAGMA busy_timeout=5000` (concurrent reader waits for a batch commit, not `SQLITE_BUSY`). Zero runtime deps. Requires --experimental-sqlite. better-sqlite3 drop-in fallback. `readonly dbPath`. `finalizeRename(dest)`: TRUNCATE-checkpoint + close BEFORE `rename` (WAL ordering load-bearing), then drop stale sidecars. `closeAndUnlink()`: close + unlink db + `-wal`/`-shm` (failed first-index cleanup). `expandParent` collapses `h.parent` to `{ headingPath }` (dropped root/path/docType/chunkId/score/snippet — same-file dups/constants). `search()` pipeline: body-hash collapse → **source dedup** (one hit per `(root,path)`, rep = best BM25, rest counted in `suppressedSections`) → MMR → optional coverage rerank → **lane interleave**. `limit` bounds distinct SOURCES (BREAKING); candidate pool `limit*6` when source dedup is on, capped 4000. Lane quota runs a SECOND FTS pass restricted to `doc_type='agents'` (shallow pool `limit*share*2`) and interleaves — `doc_type` is an UNINDEXED FTS5 column so that pass is a full match scan and is the change's main latency cost (~25→53 ms median at 31k chunks). Explicit `docType` bypasses the quota. `coverageRerank()` = IDF-weighted coverage of ORIGINAL query terms (appended PRF terms at 0.5x) with BM25 tiebreak; `prfTerms()` = RM3 mining gated on `MIN_FEEDBACK_DOCS` 5. df/IDF from a lazily created `chunks_vocab` fts5vocab shadow table keyed by exact porter stems (`stems()` temp-table `kb_stem` mapping; exact df, not prefix-range estimate; read-only-DB safe). `getChunk(root,path)` without a heading now reports `suppressedSections`; `getChunks()` returns the whole file. See change: fix-kb-index-feedback; harden-kb-index-failure-atomicity; slim-kb-search-output; fix-kb-search-retrieval-quality. |
