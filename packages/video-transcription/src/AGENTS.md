# DOX — packages/video-transcription/src

Files in this directory. One row per source file.

| File | Purpose |
|------|---------|
| `assemblyai.ts` | AssemblyAI REST client (alternate backend, opt-in). `AssemblyAIClient` implements same `TranscribeService` as Soniox. upload (RAW binary `/v2/upload`, NOT multipart) → create `/v2/transcript` → poll → `transcriptToSrt`. Auth header is RAW key, NO `Bearer` (opposite of Soniox). Base URL EU `api.eu.assemblyai.com` (data residency; US const exported). Params `speech_models:[universal-3-5-pro,universal-2]` (ordered availability fallback) + `speaker_labels:true` + `language_detection:true`; `language_code` pins lang (mutually exclusive w/ detection), `max_speakers_expected` hard cap. Hungarian not in U3.5-Pro 18 langs → auto-falls back universal-2 (99 langs) via detection. `speakerLabel` maps A/B/C → `Speaker 1/2/3`. `transcriptToTokens` flattens `utterances[].words[]` to Soniox token convention (first word of turn unspaced), falls back flat `words[]`. Retries 429/5xx honoring `Retry-After`; key never in errors. See change: add-assemblyai-transcription-backend. |
| `chunk.ts` | Long-recording chunking. `shiftAndRenumberSrt` (regex timestamp shift + renumber). `transcribeChunked` (single request under limit; else split into `chunkSeconds` pieces via `fs.mkdtemp`, merge with absolute offsets). `DEFAULT_CHUNK_SECONDS`=16200. See change: add-video-transcription-package. |
| `config.ts` | Backend selection + secret resolution. `TRANSCRIBE_BACKEND` accepts one name, `both`/`all`, or a comma list (`parseBackends`); unknown names drop, empty → `[soniox]`, duplicates collapse, order always soniox→assemblyai. Resolves to `Config.targets: BackendTarget[]` (backend, apiKey, maxChunkHours, maxChunkSeconds, srtSuffix) — NO top-level `backend`/`apiKey`/`srtSuffix` any more. `BACKENDS` table maps backend → keyVar/chunkHours/srtSuffix: soniox `SONIOX_API_KEY`/4.5h/`.srt`, assemblyai `ASSEMBLY_AI_KEY`/9h/`.diarize.srt` (chunk hours sit under each provider cap: Soniox 5h, AAI 10h). SAME resolver every backend (env first, then gitignored `.env` cwd/skillDir); EVERY selected backend's key resolved up front so `both` fails before any upload. `TRANSCRIBE_SRT_SUFFIX` ignored when >1 backend selected (would collapse outputs onto one path). Parses `MAX_CHUNK_HOURS` (applies to all targets) + `MAX_AUDIO_MB` (default 200, 0 disables) + `TRANSCRIBE_CONCURRENCY` (default 8, clamp 1–100) + `TRANSCRIBE_LANGUAGE`/`TRANSCRIBE_MAX_SPEAKERS`. Exports `loadConfig`, `parseEnvFile`, `parseBackend`, `parseBackends`, `BACKENDS`, `ALL_BACKENDS`. See change: add-video-transcription-package, parallel-transcription-file-pool, add-assemblyai-transcription-backend, both-backends-single-pass. |
| `discover.ts` | File discovery + idempotency. `resolveInputs` (no arg→`~/Movies`, dir→scan, else explicit files). video {.mkv,.mp4,.mov} audio {.m4a,.mp3}. mtime sort oldest-first. `srtPath(file, suffix=DEFAULT_SRT_SUFFIX)`/`isTranscribed(file, suffix)` skip already-transcribed — suffix param lets each backend own its sibling output, so `.srt` and `.diarize.srt` coexist for A/B on one source. `saveSrt`. See change: add-video-transcription-package, add-assemblyai-transcription-backend. |
| `ffmpeg.ts` | ffmpeg/ffprobe wrappers. Uses `execFileAsync` from `@blackbelt-technology/pi-dashboard-shared/platform/exec.js` (repo child_process invariant `no-direct-child-process`), NOT raw `node:child_process`. Wrapper applies `windowsHide:true`. `isFfmpegAvailable`, `extractAudio` (`-vn -acodec libmp3lame -q:a 2`, cleanup partial), `getDurationSeconds` (ffprobe, 0 on fail), `extractChunk` (`-ss -t`). Runner injectable for tests. Binaries resolve via the shared ToolRegistry (`ToolPathResolver` seam, default `getDefaultRegistry().resolve`) — PATH **or** ffmpeg-static; miss → gate false / 0 / throw (audio-only degrade preserved). See change: add-video-transcription-package, add-skill-tool-provisioning. |
| `run.ts` | Orchestration core. `run(args, deps)`. config→discover→extract audio ONCE if video→per target `transcribeChunked`→`saveSrt`. Exported `makeService(target, cfg)` switches backend (`assemblyai`→`AssemblyAIClient` w/ languageCode+maxSpeakers, else `SonioxClient`); one service per target built once, held in a `Map<backend, TranscribeService>`. `processFile` loops `cfg.targets`: per-target suffix decides skip/write, per-target try/catch so one backend failing still lets the other write. File outcome = best across targets (transcribed > failed > already); `isFullyTranscribed` (every target's SRT exists) drives the toProcess filter, so a file with only `.srt` still runs the AAI pass. Bounded worker pool (`cfg.concurrency`, default 8) over files: dispatch oldest-first, overlap Soniox waits, complete any order. Per-file try/catch. ffmpeg-absent skips video, processes audio. Prints summary. deps injectable for tests. See change: add-video-transcription-package, parallel-transcription-file-pool. |
| `soniox.ts` | Soniox REST client. `SonioxClient`. upload→create (stt-async-v3, diarization)→poll→`getTranscript`→`deleteFile`→`transcribeFile`. Native fetch+FormData, no SDK. api key never in errors. See change: add-video-transcription-package. |
| `srt.ts` | Pure SRT builder. `formatTimestamp(ms)`→HH:MM:SS,mmm. `groupTokens` (speaker-change + `maxSegmentMs`=5000 boundary). `renderSegments` renders cues `[Speaker] text` — shared by every backend so all emit identical SRT structure. `tokensToSrt`=`renderSegments(groupTokens(tokens))`. Byte-parity with Python preserved (parity check green after the `renderSegments` extraction). See change: add-video-transcription-package, add-assemblyai-transcription-backend. |
