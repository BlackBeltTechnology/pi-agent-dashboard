| `guard.ts` | Search-guard core (arm B). Fires at 3 consecutive searches (CHAIN_THRESHOLD); reset set = kb_search/kb_neighbors/kb_get + bash leading `kb`, processed BEFORE counting, clears chain AND firings; edits never reset; empty kb_search query resets. Ladder warn→escalate→block; block only in `block` mode; `off` inert. `resolveGuardMode(config, env)`: KB_GUARD_MODE selects off/warn only — can weaken, never enable block (D14). `guardNoteSafe` = fault-isolated feed (X1: guard failure leaves results untouched).
