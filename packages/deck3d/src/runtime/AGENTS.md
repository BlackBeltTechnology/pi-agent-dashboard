| `index.ts` | Bundle entry + engine. Reads `window.__DECK` (merged IR) + `window.__DECK_FONT` (base64 TTF) + `window.__DECK_PROPS` (prop GLBs) + `window.__DECK_LOCAL_FX` (per-deck effect `{card,src}`); builds one `THREE.Group` per slide (title/slab/diagram/background/props), rail camera + dolly/swing/fade transitions, hash deep-link (1-based; `#0`/out-of-range → slide 1), live navigation via `navTo` (keydown `ArrowRight`/`ArrowDown`/`PageDown`/`Space` forward, `ArrowLeft`/`ArrowUp`/`PageUp` back, `Home`/`End`; left-click `pointerup` advances; `hashchange` follows; clamped at both ends, mirrors index into `location.hash`), rAF loop with `setTimeout` fallback on `document.hidden`. Exposes `window.__deck3d` (`gotoSlide`, `setTime`, `ready`, `measure`, `peaks`, `effects` incl. `budget`, `debug.titleGlyphs`/`liftedMessage`, `current`). `effects()` also returns `errors[]` (`{slide,effectId,phase}`). Builds the configurator via `createHud` and suppresses navigation + the `C` toggle while a panel input has focus or a click lands inside the panel. `fxSeedFor(slideId)` seeds each effect's `ctx.rng`. Deterministic clock when `setTime` is used. See change: deck3d-cinematic-worlds. |

| `local-fx.ts` | Local-effect instantiation (design D1): `SHADOWED` global list, `compile` via `new Function` with those names bound to `undefined` and a frozen `Math` whose `random` is `ctx.rng`. See change: deck3d-cinematic-worlds. |
