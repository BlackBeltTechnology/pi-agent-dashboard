Stylistic backgrounds (Section 18, three.js example ports, NO `tags.topic` so routing is untouched): `clipped-solids` (`mode` planes|intersection|caps — one centred knot; three discards a plane's NEGATIVE side so normals lean -z to carve the camera-facing octant; caps are clipped by the NEGATED other planes; a stencil-capable composer target is required, see `runtime/post.ts`), `extruded-shapes` (built-in parametric paths + `svgPath` = SVG `d` string via `SVGLoader`, bad data falls back), `scatter` (`MeshSurfaceSampler.setRandomGenerator(ctx.rng)`), `tessellate`, `curve-flow` (`InstancedFlow` offsets SET from `t`, never accumulated), `sprites`/`billboards`/`shader-particles`/`points-on-geometry` (sprite textures are `DataTexture`s — the corpus gate has no DOM), `volume-cloud`/`volume-perlin` (`Data3DTexture` from `util.noiseVolume`; steps scale with tier and double as `userData.count`), `dynamic-instances`. `constellation` is now the real `buffergeometry_drawrange` port (`nodeShape` point|sphere|cube, triangle-wave bounce so positions are pure in `t`). `util.ts` = `num/str/bool/countFor/softSprite/makeNoise3/noiseVolume`. `post` cards are 1-line markers (`pass: "<id>"`); the pass itself lives in `runtime/post.ts`, keyed by card id — the 14 post ids (`bloom`, `selective-bloom`, `film`, `vignette`, `smaa`, `sao`, `depth-of-field`, `chromatic-aberration`, `god-rays`, `pixelate`, `outline`, `sobel`, `dot-screen`, `ascii`) ALL drive real passes since Section 17 (before it only `bloom` did). Card params are what the pass reads; `parts` enum = diagram/title/props/all. `n8ao` renamed `sao`. Promoted from the business deck via `fx promote` (design D1): `agent-depth`, `capital-flows`, `cohort-grid`, `fab-wafer`, `geo-fragments`, `horizon-gates`, `proof-gate`, `trust-ledger` — carry no deck content; `cohort-grid` takes its split via `params.share`. Promotion re-ranks `backgroundForTopic` (cheapest-wins, ties by id): `geo`→`geo-fragments`, `agents`→`agent-depth`, `trust`→`trust-ledger`, `compute`→`fab-wafer`, `money`→`capital-flows`. Topic-world backgrounds `globe-arcs`/`city-grid`/`neural-mesh`/`vault-glyphs`/`server-racks`/`market-tape`/`orbit-agents`/`paper-stack` use `ctx.rng`, expose `object.userData.count`, scale counts by `quality`, and put their own depth offset on an INNER group (the runtime pins the returned object's z). See change: deck3d-cinematic-worlds. `tokens`/`rings`/`swarm`/`particles` delegate to `runtime/backgrounds.ts`; the rest are permissive three.js-example ports behind the interface. |
