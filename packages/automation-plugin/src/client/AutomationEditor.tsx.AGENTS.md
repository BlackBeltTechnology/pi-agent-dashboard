# `AutomationEditor.tsx` — per-file record

Inline create/edit automation editor (was `CreateAutomationDialog.tsx`, modal). Rendered by `AutomationBoard.tsx` inside the editing card or the draft card; no modal shell, no title.

## Current contract (See change: inline-automation-editor)

- Export `AutomationEditor`, types `AutomationEditorProps`, `EditorSection` (`identity|trigger|runs|action|advanced`), `EditorSaveOutcome` (`save|switch`).
- Props: `onClose` (Cancel request; board guards), `onSaved(outcome, name)`, `onDirtyChange(count)`, `guard {count, closing} | null` + `onDiscard()`, `focusSeq` (bump → re-focus `initialSection`), edit seeds `initialConfig`/`initialName`/`initialScope`/`initialPromptBody`.
- Root test id `automation-editor-<scope:name>` (edit) / `automation-editor-new` (create).
- Form in `<fieldset disabled>` until git probe settles + `worktree → local` correction lands → `baselineReady` → dirty baseline frozen; untouched editor reports 0 changes.
- Submit spreads `initialConfig` first, drops `action/actions/agent/visibility`, overlays form fields → keeps `disabled`, `maxConcurrentSpawns`.
- Edit mode: no Identity group, no locked-name note; name/scope live in the card header.
- Layout: `@container` root; two `minmax(0,…)` columns at `@3xl` (Trigger + Runs as + Advanced | Action); one column otherwise; action ids/descriptions wrap; `GrowTextarea` auto-grows (`overflow-y-hidden`) for prompt + multiline payload.
- Advanced header summarises `mode · concurrency · sandbox`.
- Phone (< `sm`): planned trigger pills hidden; one `trigger-coming-soon` chip "+N coming soon".
- Save bar `editor-save-bar`: sticky `bottom-0 z-[5]`; `editor-write-path` (`folder · <cwd>/.pi/automation/<name>/…` | `global · ~/.pi/automation/<name>/…`), `editor-dirty-count` (aria-live), `create-error`, `editor-arms` (create: "Arms on create · next run …"), Cancel `editor-cancel` + Save/Create `create-submit` (edit: disabled at 0 changes); guard → `editor-guard` notice + `editor-guard-discard` + `editor-guard-save` (Save & switch | Save & close).
