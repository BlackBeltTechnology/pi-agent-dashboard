| `client.tsx` | Client entry. NOTE: peer gating is GONE — every provider is tickable because the plugin owns every contract; `useQuotaUnavailable()` reads `unavailable[]` from `/api/quota` once per mount and each ticked-but-empty row prints an inline `quota-provider-<id>-reason` (not signed in / provider refused / no quota reported / not supported) so a tick never yields silence. Provider list comes from `./providers.js`. `QuotaDialog` flags a retained snapshot with a `quota-stale-<id>` “not live” badge — dialog ONLY, the footer bar renders stale figures identically to fresh ones by explicit decision. Legacy detail below. `QuotaWidget` (content-inline-footer): ONE COMPACT LINE per provider — label + slim 56px bar, NO percentage number — from `GET /api/quota` (polled 60s), fill = pace severity of worst window, `now` tick, `title` tooltip; renders `null` when empty (honest degradation). Stays in `content-inline-footer` on purpose: the composer's context slider is draft-conditional (vanishes on empty input), so aligning with it would hide quota too. `QuotaDialog`: shared `ui:dialog` primitive via `useUiPrimitive(UI_PRIMITIVE_KEYS.dialog)`, `All · per-provider` selector, per-window pace bars + projected %, plus a `quota-now-legend` naming the vertical tick as `now`. `QuotaSettings` (settings-section): printed ToS WARNING (not a gate) + master `enabled` + per-provider toggles GATED on installed peers (`useQuotaSources()` reads `sources` from `/api/quota` once per mount; unservable rows render disabled at 0.55 opacity, forced-unchecked, with a `quota-provider-<id>-needs` hint naming the package that would unlock them — absent/failed `sources` ⇒ treat as nothing installed, i.e. disable rather than silently enable), committed through the host Settings panel's GLOBAL Save via `useSettingsDraftSource({id:"plugin:quota"})` — no local Save button. Anthropic INCLUDED. Re-exports `catalog`. Imports only client-safe modules (never the server entry / pi-quotas). See change: fix-quota-plugin-defects. |
| `pace.ts` | Pure pace/burn-rate math. `computePace({usedPercent,resetsAt,windowSeconds}, now)` → `{state, elapsedPercent, projected, overage, warn, severity}`. Guards BEFORE dividing: `windowSeconds<=0`/non-finite→unavailable; non-finite `resetsAt`→unavailable; `secondsToReset<=0`→stale; `elapsedRaw<=PACE_EPS(0.01)`→unavailable. Severity green/orange/red (`projected>=150` or `used>=90`→red). `paceLabel()` → `over by X%`/`on pace`/`pace unavailable`/`reset pending`. Never `Infinity`/`NaN`. |
