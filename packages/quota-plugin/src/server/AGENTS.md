| `index.ts` | Server entry (no bridge). TWO peer sources: routes each enabled provider to the first INSTALLED source that can serve it via `resolveSource()` from `../sources.ts`, so one peer alone yields its own coverage and both together the union; `requires.piExtensionsAnyOf` means at least one suffices. `fetchFromUsageBars()` normalizes the usage-bars payload (session 5h + weekly 7d percentages → `QuotaWindowDto`), dropping hidden windows or any window missing `resetsAt` (pace needs it), returning null on absent fetcher/missing credential/error. `computeQuota()` always reports `sources[]` (id, package, installed) — even with nothing installed — because the settings UI needs it to explain WHY a checkbox is disabled. `createAuthAdapter()` adapts the host auth abstraction (`readAuthJson` + `getModelRegistry().getApiKeyAndHeaders`, OAuth-refreshing — deep-imported from `@blackbelt-technology/pi-dashboard-server`) to the 2-method `{get,getApiKey}` shape the peer expects. Peer loaded at RUNTIME via `loadPiQuotas()` (never a bundled dep). `enabledProviders(config, supported)` = peer-supported providers gated on `enabled`+per-provider `enabled` (both default-off); Anthropic INCLUDED, no exclusion list, no ToS gate. `computeQuota()` (exported, unit-tested): empty when peer absent, zero fetch when gates closed, clears peer cache for non-enabled providers (so disabling clears cached quota), suppresses `not_applicable`/errors, normalizes windows (Date→ISO, clamp usedPercent, drop windows without valid `windowSeconds`). `toDto()` normalizer. Default `registerPlugin(ctx)`: guarded `GET /api/quota` route (skips if Fastify already listening) + `quota_update` broadcast. Logs provider id + error KIND only — never a token. See change: fix-quota-plugin-defects. |

Returns `null` (never throws) when absent/unreadable/incompatible. Exports `PiQuotasLib`/`PiQuotasResult`/`PiQuotaWindow` types + `PI_QUOTAS_PACKAGE`. |

Same peer contract as `load-pi-quotas.ts`: not an npm dep, resolved at runtime via `resolvePiPackage()` → dynamic-imports `<packageDir>/extensions/usage-bars/core.ts` (jiti loads raw TS). Memoizes success only, `warnOnce` per distinct reason, never throws, never logs the error object. Exports `UsageBarsLib`/`UsageBarsData`/`USAGE_BARS_PACKAGE`. See change: add-provider-quota-plugin. |
