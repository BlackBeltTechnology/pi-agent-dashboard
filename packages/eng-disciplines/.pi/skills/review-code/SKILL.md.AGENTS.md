Defect Classes section: 8 classes (spec/task conformance … test fidelity) each with sweep guidance; 4-step fix protocol (reproducing test → smallest fix → sibling sweep → re-read vs class); Verification asks per-class sweep summary. See change: harden-review-and-fix-loop. Distinct from cloud PR gate (`code-review`/CodeRabbit, opt-in at ship). Distilled from Google eng-practices + Conventional Comments (MIT, author: robson).
