# DOX — packages/gmail-plugin/src/server/setup

Automatic Google Cloud setup. Deterministic server-side recipe drives the Cloud console in the dedicated agent browser over CDP. No model. Secret never logged. See change: add-gmail-auto-setup.

| File | Purpose |
|------|---------|
| `browser-service.ts` | Structural contract of `browser.dedicated` (`BROWSER_DEDICATED_SERVICE`, `DedicatedBrowserService`, `BrowserRefusal`, `DedicatedBrowserStatus` incl. `downloadsDir`). Declared here, not imported: gmail has no `dependsOn` on browser plugin. See change: add-gmail-auto-setup. |
| `capture.ts` | `captureClient(env)`: read id+secret from creation dialog text in memory (`parseClientDialog`); else click "Download JSON", read newest new `client_secret_*.json` in `downloadsDir`; `finally` deletes every file the click produced. Store via `env.storeClient` (shared `storeClient`). Both reads fail → close dialog, handoff `secret_capture_failed`; `client_in_use` → handoff `client_in_use`. Never logs/returns secret. See change: add-gmail-auto-setup. |

| `run.ts` | `SetupRun` state machine + `SetupRunManager` (one live run, last 5 kept). States `starting/running/waiting_user/waiting_decision/busy/done/handoff/cancelled`. Connects `{client:"gmail-setup",private,ephemeral}`; busy → wait `takeover()` → connect with `takeover:true`. Per step: attempt with pausable 60 s `StepClock` (human waits excluded), race vs sign-in interrupt + abort; `SignInRequired` → sign-in checkpoint (run tab → `about:blank`, hidden `open` w/ `login_hint`, `focus`, wait `tabOrigin` leaves accounts.google.com or `continue`) then step restarts. Checkpoints 15 min → `timeout`; decisions unlimited. 30 s `Runtime.evaluate("1")` keep-alive; unexpected socket close → `browser_closed`. One masked log line per step `[gmail] setup step <id> <done\|skipped\|handoff:<reason>> <ms>ms`. `view()` secret-free, no instance id. `AttemptEnv` = stale-safe `StepEnv`. Inputs saved via `deps.saveSetup`; links → credentials `setup`. See change: add-gmail-auto-setup. |
