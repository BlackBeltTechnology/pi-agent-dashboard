# DOX — packages/craft-web-plugin/src/client

Files in this directory. One row per source file. See change: edit-office-in-pane-with-craft-web.

| File | Purpose |
|------|---------|
| `CraftFrame.tsx` | Sandboxed editor frame view. Owns one `FrameSession` per run (`run` = attempt+nonce+webgl; Retry/Resume bump it). Renders toolbar (Save-target toggle `craft-save-target-*`, `aria-pressed`), notices (`craft-blocked-toast`, `craft-nav-offer`, `craft-save-error`, `craft-too-large`+`craft-download-offer`), `craft-save-as` dialog, `craft-loading` overlay, fail panels (`craft-start-failed`/`open-failed`/`snapshot-error`/`reloaded`, each `-retry`). iframe: `sandbox="allow-scripts"`, `allow="clipboard-write"`, NO `allow-downloads`, src `/apps/craft-<id>/index.html[?webgl]#n=<nonce>`. Retry after start-failed → `?webgl` when WebGL2 capable. Re-exports `READY_TIMEOUT_MS`, `OPENED_TIMEOUT_MS`. |
| `CraftFrameHost.tsx` | Generic slot body. Gates before any iframe: status (`useStatus`) → snapshot preflight (`useSnapshotPreflight`; size check before app download) → `probeRenderer`. Gate panels `craft-gate-*`; `PrepareGate` shows gzip size + Prepare/Retry (`craft-prepare`) only for preparable reasons; prepare failure → "could not be prepared". Status 404 → `restart-required`; missing app entry → `not-verified` (fail closed). Static GET never provisions. |
| `CraftWebSettings.tsx` | `settings-section` claim `CraftWebSettings` (lazy `module`, tab general). Per app (status apps ∩ `CRAFT_WEB_APPS`, fallback `CLAIMED_WEB_APP_IDS`): `SettingsGroup` + status pill (Installed / Update available / Not downloaded / Disabled / Restart required / Failed), `ToggleField` enable, `SelectField` version `pinned`/`latest`, `SettingsFacts` installed (+ latest in latest channel), Download/`Update to <v>` button (preparable only; disabled while dirty/running; `prepareCraftApp` then status refetch; failure → error notice). Draft → `useSettingsDraftSource({id:"plugin:craft-web"})`; commit sends full config via `plugin_config_write`; dirty = effective values (absent key ≡ default). Status 404/unreachable → notice + retry. testids `craft-web-<id>-{status,enabled,version,installed,latest,prepare,error}`, `craft-web-status-notice`. See change: track-latest-craft-web-version. |
| `craft-api.ts` | REST client `/api/plugins/craft-web/*`: `fetchCraftStatus` (404 → restart-required, error → unreachable), `prepareCraftApp` (network error → `offline`), `reportCsp` (fire-and-forget). |
| `craft-apps-table.ts` | `CRAFT_WEB_APPS` (wordcraft/gridcraft/deckcraft: label, extension, `maxBytes` from `OFFICE_SIZE_CAPS`). Keyed by claim id. `CLAIMED_WEB_APP_IDS` (manifest-claimed ids; pinned to server `CLAIMED_APPS` by `manifest.test.ts`). See change: track-latest-craft-web-version. |
| `device-download.ts` | `downloadToDevice` (host-origin anchor + blob; frame has no `allow-downloads`), `safeDownloadName`. |
| `frame-session.ts` | Non-React protocol session per iframe mount. Acceptance: `event.source===frame.contentWindow` + nonce + known type. `ready`→`open` once (transfer); 60 s ready / 15 s opened timeouts; second `ready`/second `load` → drop frame ("reloaded", `setDirty(false)`); save mapping via `routeSave` (own → `props.save` w/ Save-target, save-as → dialog, other ext → device download, over cap → `save-result ok:false` + download offer); busy guard; dirty: `"unknown"` until first `dirty` after `opened`, copy save keeps true until next overwrite save; `csp` rate-limited (1/directive/10 s, max 20); `navigate-blocked` http(s) only. |
| `gpu-probe.ts` | `probeRenderer` (`navigator.gpu`, offscreen WebGL2), `rendererMode` → `default` / `webgl` / `none`. Runs before the iframe exists. |
| `handlers.tsx` | Claim components (manifest `claims[].module`, lazy): `WordCraftHandler` binds `CraftFrameHost` to the wordcraft row. Grid/Deck add theirs after their spike. Off the cold landing chunk. |
| `index.tsx` | Light barrel: `catalog` (from `../i18n.js`) only; the registry imports it eagerly for `i18nCatalog`. |
| `messages.ts` | English source strings `EN` + `useCraftT` (scoped `plugin.craft-web.*`, English fallback) + `formatSize`. zh-CN/hu in `../i18n.ts`; parity pinned by `__tests__/i18n.test.ts`. Settings keys (`settings*`, `status*`, `updateTo`, `saveFirst`). See change: track-latest-craft-web-version. |
| `save-routing.ts` | Pure `routeSave` → `own` / `save-as` / `download` / `too-large`; NFC + lower-case stem/ext compare; other extension wins over size. `splitName`, `baseName`. |
| `save-target-store.ts` | Save-target (`overwrite` default / `copy`) keyed by `cwd`+`path`; `useSaveTarget`, `getSaveTarget`, `setSaveTarget`. |
| `shim-protocol.ts` | Shim↔host message types, `parseShimMessage` (shape + type, cross-realm ArrayBuffer), `makeNonce`, `safeNavigateUrl`. |
| `status-types.ts` | ASSUMED server shapes for status/prepare/csp-report (documented in file); `parseStatus`, `gateFor`, `parsePrepare`, `GATE_REASONS`, `PREPARABLE`. `CraftWebAppStatus` exported; `optionalFields` parses `channel`/`installedVersion`/`latestVersion`/`enabled`/`preparing`. See change: track-latest-craft-web-version. |
| `ui.ts` | Token-only class recipes (`BTN`, `BTN_PRIMARY`, `BTN_DANGER`, `NOTICE`, `PANEL`). |
