| `CraftFrame.tsx` | Sandboxed editor frame view. Owns one `FrameSession` per run (`run` = attempt+nonce+webgl; Retry/Resume bump it). Renders toolbar (Save-target toggle `craft-save-target-*`, `aria-pressed`), notices (`craft-blocked-toast`, `craft-nav-offer`, `craft-save-error`, `craft-too-large`+`craft-download-offer`), `craft-save-as` dialog (+ `craft-save-as-hint` session-name line for `inner-title` profiles, D11 E2), `craft-loading` overlay, fail panels (`craft-start-failed`/`open-failed`/`snapshot-error`/`reloaded`, each `-retry`). iframe: `sandbox="allow-scripts"`, `allow="clipboard-write"`, NO `allow-downloads`, src `frameSrc(app, webgl, nonce)` = `/apps/craft-<id>/index.html[?<frameParams…>&webgl]#n=<nonce>` (profile URL flags only). Toolbar (D11 B2/B3): preview claim → `craft-preview-chip` "View only…", no save target; `siblingExtensions` → `craft-sibling-chip` "Save (Ctrl+S) creates <stem><ext>" + label `craft-save-target-label` "Exports to <ext>"; selected target `text-[var(--text-primary)]` on `--accent-soft` (contrast fix). See change: extend-craft-web-to-all-apps. Retry after start-failed → `?webgl` when WebGL2 capable. Re-exports `READY_TIMEOUT_MS`, `OPENED_TIMEOUT_MS`. |

Status 404 → `restart-required`; missing app entry → `not-verified` (fail closed). Static GET never provisions. |

Acceptance: `event.source===frame.contentWindow` + nonce + known type. `ready`→`open` once (transfer); 60 s ready / 15 s opened timeouts; second `ready`/second `load` → drop frame ("reloaded", `setDirty(false)`); save mapping via `routeSave` (own → `props.save` w/ Save-target, save-as → dialog, other ext → device download, over cap → `save-result ok:false` + download offer); busy guard; dirty: `"unknown"` until first `dirty` after `opened`, copy save keeps true until next overwrite save; `csp` rate-limited (1/directive/10 s, max 20); `navigate-blocked` http(s) only. v2: `start-failed` before opened → drop `start-failed` (no resend); `opened.confirmed` (absent = v1 = confirmed) → telemetry `title`\|`fallback`, ready/open timeouts → `start-failed`\|`timeout` (one per mount); preview claim: dirty ignored, `setDirty(false)` once opened, every save → device download; `inner-title` (D10) remembers the Save As answer per suggested name (`rememberedSaveAs`) and applies it as the target; own save decided by written path base name (core may turn an overwrite into a copy) → `save-result {own:true}`; `rejected` save → telemetry reject by ext. See change: extend-craft-web-to-all-apps. |
