| `craft-shim.js` | Iframe-side half of CraftFrameHost protocol (design D4). Plain ES2020 classic script, no imports, no build. Server `postInstall` copies it verbatim into a Trunk/eframe web tree as `craft-shim-<hash>.js`, loaded before the app module. Line `const SHIM_VERSION = 4;` (own line, col 0) is read by server → key `<ver>-s<shimVersion>`; bump on any behaviour change. Exports (only when `module` defined): `SHIM_VERSION`, `parseTitle(args)→{raw,name,clean}\|null`, `createShim(win,doc,{isTrusted?})→{start,dispose}`; else self-runs, sets `window.__CRAFT_SHIM_VERSION__`. Nonce from `location.hash` `#n=`; no nonce → no posts. Host msgs accepted only if `event.source===window.parent` + nonce. Shim→host: `ready` (TrunkApplicationStarted → canvas → 1 rAF), `opened{title}` (title warn names delivered doc), `dirty{value}` (deduped), `save{suggestedName,mime,bytes}` (bytes TRANSFERRED), `blocked{what}` (`file-input`\|`showOpenFilePicker`\|`showDirectoryPicker`\|`drop-files`\|`paste-files`), `csp{directive}`, `navigate-blocked{url}`. Host→shim: `open{name,bytes}` → synthetic dragenter/dragover/drop on canvas, once per mount; `save-result{ok,error?}` settles pending saves FIFO (no id), `ok:false` → `AbortError`. Title source: wrapped `console.warn` parsing `Unhandled egui viewport command: Title("…")`, original still called. Dirty: `•` title, or trusted keydown/paste/cut/drop on frame window after last title (modifier-only + Cmd/Ctrl+S ignored), or pointerdown then non-marker title change → true; clean only when latest title clean and no later input; identical re-sent title ignored. Hardening: deletes `RTCPeerConnection`/`webkitRTCPeerConnection`/`RTCDataChannel`/`RTCRtpSender`; stubs `showSaveFilePicker` (buffering writable: write/seek/truncate/close posts), `showOpenFilePicker`, `showDirectoryPicker`; anchor `download` interception (capture click + `HTMLAnchorElement.prototype.click`, `fetch(href)` called synchronously in handler; `data:` decoded locally); `<input type=file>` click/`showPicker` refused; trusted drop with files / paste with file items refused; Navigation API `navigate` cancelled (cross-document, cancelable only); Cmd/Ctrl+S default prevented. |
