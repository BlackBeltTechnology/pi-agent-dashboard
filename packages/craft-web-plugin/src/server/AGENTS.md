Files in this directory. One row per source file. See change: edit-office-in-pane-with-craft-web.

| File | Purpose |
|------|---------|
| `apps.ts` | Server app table. `CRAFT_WEB_APPS` (wordcraft: `.docx`, `approxDownloadBytes` 16.5 MB), `CLAIMED_APPS`, `mountId(app)`=`craft-<app>`, `isClaimedApp`. E1 test keeps it equal to manifest claims. |
| `config.ts` | `appEnabled(config, app)` — enabled unless `apps.<app>.enabled === false`. Read live. |
| `csp.ts` | `publicOrigin(headers)` — forwarded-aware `<proto>://<host>` (`x-forwarded-host`/`-proto` first token, else `Host`, proto default http); host regex-validated, throws otherwise (→ mount 500). Fastify has no `trustProxy` on purpose. `buildCsp(origin, app)` — exact D3 policy: script-src/connect-src name `<origin>/apps/craft-<app>/` (never `'self'`), `'wasm-unsafe-eval'`, `form-action 'none'`, `frame-ancestors 'self'`. |
| `index.ts` | Server entry `registerPlugin`. Per claimed app: `ctx.serveApp({appId:"craft-<app>", dir:<dataDir>/<app>-web/current, csp:(req)=>buildCsp(publicOrigin(req.headers),app), crossOriginFrame:true})` (throw → warn, stays unavailable) + `ctx.registerFileValidator({claimId:app, module:VALIDATOR_MODULE, enabled:()=>appEnabled})`. Then `createCraftWebService` + `registerCraftWebRoutes`. `isMounted` = `getAppMountRegistry().has("craft-<app>")`. |
| `ooxml-validator.mjs` | Worker-run validator (plain ESM, node built-ins only). Own zip central-directory reader (≤10,000 entries, no zip64/multi-disk), `[Content_Types].xml` ≤1 MB (bounded inflate), reject `<!DOCTYPE`/`<!ENTITY`, bounded `<Override>` attribute scan (no XML parser), main part content type (`.docx` wordprocessingml.document.main+xml, `.xlsx` spreadsheetml.sheet.main+xml, `.pptx` presentationml.presentation.main+xml) declared AND present in archive. `validate(bytes, ext)` → `{ok:true}`\|`{ok:false,reason}`. |
| `ooxml-validator.d.mts` | Types for `ooxml-validator.mjs`. |
| `post-install.ts` | `createPostInstall(shimPath)` → `provisionWeb` `postInstall` hook. Moves the single inline Trunk module script to `bootstrap-<sha10>.js`, copies shim as `craft-shim-<sha10>.js`, loads shim (classic) before bootstrap (module), marker `<!-- craft-shim:<v> -->`, idempotent (other version → throws). `.gz` level 9 for `.wasm/.js/.html/.css`, removes `.br`, writes `craft-build.json {app,version,shimVersion,sizeGzip}`. `readBuildInfo(dir)`, `BUILD_INFO_FILE`. |
| `routes.ts` | `registerCraftWebRoutes(fastify, service)`: `GET /api/plugins/craft-web/status` (observe), `POST .../prepare/:app` (control; non-ok → `{ok:false,reason,message}` + HTTP code), `POST .../csp-report` (control; body `{app,directive}` ≤2 KiB, directive `^[a-z][a-z0-9-]{0,39}$`, 400/429). Tiers in `packages/shared/src/route-tiers.ts`. |
| `service.ts` | `createCraftWebService(deps)` → `status()`, `prepare(app)`, `reportCsp(app, directive)`. Status per app `{status:"ok"\|reason, reason?, message?, enabled, version?, sizeGzip, shimVersion?, preparing, cspViolations}` + top `shimVersion`. Reasons: disabled, restart-required (mount absent), not-verified (no registry `webVersion`), not-prepared (also registry pin ≠ prepared version), shim-outdated, + last prepare failure offline/checksum-mismatch/launcher-source/extract-failed. `prepare`: refuses disabled 403 / restart-required,not-verified 409 / unknown 404; single-flight per app; maps `ProvisionWebError.code`; logs outcome+duration+bytes. `reportCsp`: 30/min/app, counts only. |
| `shim.ts` | `SHIM_SOURCE_PATH` (`../shim/craft-shim.js`), `parseShimVersion` (literal `const SHIM_VERSION = <n>;` at column 0), `createShimVersionReader` (re-reads on mtime change). Single source of the shim version. |
