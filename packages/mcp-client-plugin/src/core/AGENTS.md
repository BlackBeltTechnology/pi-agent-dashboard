# DOX — packages/mcp-client-plugin/src/core

Host-free logic for the `mcp-client` plugin: pi-rule mirror, two-layer reader, live-state
reader, config writer, effective-view reader, and the `mcp-client.config` service. Imports NO
React and NO dashboard runtime — the hostless `apple-tools` installer consumes `./core`
directly. See change: extract-mcp-client-plugin, migrate-mcp-to-pi-builtin.

| File | Purpose |
|------|---------|
| `config-io.ts` | `createRealConfigIO`, `writeFileAtomic` — exclusive random temp file mode 0600, fsync, rename. The ONLY place a config byte reaches disk. |
| `config-writer.ts` | Parse + write engine. `createConfigWriter({configIO,paths,knownCwds,isProjectTrusted?})`, `targetPath`, `readServerEntry`, `ensureServerEntry` (merge fields), `saveServer` (whole entry, `previousName` rename), `removeServer`, `setEnabled` (`enabled:false` / key removed), `convertAdapterLeftovers`, `previewEnsure`, `readParseStatus`. Validation order transport-conflict → pi rules (`invalid-entry`, pi's own message) → project `auth` on HTTP refused (global-only) → `-`/`_` `name-collision` (project: global+project names; global: global + every known TRUSTED folder's project names; replaced entry excluded). Folder-disable of a global-only server writes a `folderCopyOf` copy WITHOUT `headers`/`env`/`oauth.clientSecret`/`auth`, returns `omitted`; re-enabling such a copy returns `action:"needs-choice"`. Exports `NotAllowedCwdError`, `FOLDER_COPY_OMITTED`, `folderCopyOf`. Strict JSON only (`strip-json-comments` gone). See change: migrate-mcp-to-pi-builtin. |
| `effective-view.ts` | `createEffectiveViewReader({configIO,paths,isProjectTrusted?})`. Global view = Pi-global layer only; project view = global then folder (trusted only, else rows inactive `project-not-trusted` and the global row stays). Rows carry provenance `pi-global`/`pi-folder`, `overridesGlobal`, `transport`, `enabled`, `exposure`, `active`, `inactiveReason` (`disabled`/`project-not-trusted`/`invalid-entry`/`name-collision`/`global-only-auth`), `piError`, `ignoredKeys`, `adapterLeftovers`, `authMode`. GLOBAL entries redacted in project views (`redactEntry`: `headers`/`env` → `{redacted,keys}`, `oauth.clientSecret` → `{redacted}`); `isSecretKey`. See change: migrate-mcp-to-pi-builtin. |
| `index.ts` | `./core` barrel — the only entry other packages import. Re-exports the service factory, IO, layers, live-state, writer helpers, and the types. See change: migrate-mcp-to-pi-builtin. |
| `layers.ts` | NEW. Pi two-layer path + reader: `LayerPaths`, `piAgentDir`, `defaultLayerPaths`, `nullProto`, `readLayer` (strict `JSON.parse`). See change: migrate-mcp-to-pi-builtin. |
| `live-state.ts` | NEW. `createLiveStateReader({runner,timeoutMs,cacheTtlMs,now})`, `parseMcpListJson`, `LIVE_STATE_TIMEOUT_MS`=30000, `LIVE_STATE_CACHE_TTL_MS`=30000. Runs `pi mcp list --json`; stdout parsed whatever exit code; timeout aborts signal → `{ok:false,reason:"timeout"}`; failures not cached. See change: migrate-mcp-to-pi-builtin. |
| `path-utils.ts` | Dotted-path helpers: `isPlainObject`, `getByName`, `setByName` (immutable). |
| `pi-rules.ts` | NEW. Mirror of pi 1.0.0 `validateMcpServerConfig`: `validatePiEntry`, `isValidServerName` (`[A-Za-z0-9_-]+`, ≤128, not `__proto__`/`constructor`/`prototype`), `mcpNamespace`, `MCP_EXPOSURES`, `MCP_EXPOSURE_ALIASES` (`codemode-deferred`→`codemode`), `displayExposure`, `transportOf` (HTTP when `url` unless type stdio), `ADAPTER_ONLY_KEYS`, `adapterLeftovers`, `ignoredKeys`, `authModeOf` (provider/header/oauth). See change: migrate-mcp-to-pi-builtin. |
| `schema-validation.ts` | Ajv over the published schema. `validateServerEntry`, `errorFields`, `mcpConfigSchema`; keywords `x-secret`, `x-transport`, `x-global-only`. Every write path validates BEFORE IO. See change: migrate-mcp-to-pi-builtin. |
| `service.ts` | `createMcpClientConfigService({configIO,knownCwds,isProjectTrusted?,paths?,runner?,scratchCwd?,liveTimeoutMs?,liveCacheTtlMs?})` + `McpClientRuntime` (= service + `getLiveState(scope,{fresh})`) + `McpClientConfigServiceDeps`. Global live list runs in an empty `mkdtemp` scratch dir. Composes writer + layers + live-state behind one injection seam. See change: migrate-mcp-to-pi-builtin. |
| `types.ts` | Shared vocabulary: `Scope`, `ConfigIO`, `ConfigRefusal`(+closed `ConfigRefusalCode`: `unparseable`/`entry-not-object`/`invalid-name`/`name-collision`/`transport-conflict`/`invalid-entry`/`write-failed`), `ConfigWriteResult`, `ReadResult`, `RemoveResult`, `ParseStatus`, `ServerEntry` (pi 1.0.0 shape), `EffectiveView`, `EffectiveServerView`, `LayerStatus`, `LiveState`, `PiMcpListRunner`, `SetEnabledResult`, `McpClientConfigService`. See change: migrate-mcp-to-pi-builtin. |
