# runtime-overlay.ts — index

Runtime-overlay state machine, pure over `~/.pi/dashboard/runtime/` (writes `state.json` only). `planColdLaunch(dir, exclude)` → resolver inputs (local, overlays pending→current→previous minus bad/excluded), marks exhausted pending bad (`crashed_before_commit`). `shouldCountAttempt`/`beginAttempt`/`recordColdFailure` (2 attempts → bad; local → bad at once). `commitRuntime`, `pruneVersions` (keep current+previous, skip `.partial`). `pickLocalFolder` (refuse `request_unreadable`/`invalid_folder`, realpath, bind `{epoch,seq}`, clear bad+attempts), `stopUsingLocalFolder`, `activationTarget`, `watchActivationRequests` (2 s poll, per-nonce, skips `handledNonce`). `switchRuntime(targetId, deps)`: PID-gated stop (`SWITCH_OLD_EXIT_DEADLINE_MS` 60 s → `old_server_alive`), gate, extension re-point BEFORE spawn, pid+`runtime.id` health gate, commit/prune; port conflict → abort (attempt undone, prior restored); else bad + rollback previous → bundled. Finally releases ownership. See change: electron-runtime-overlay-updates. Review fixes: `ownsServer(health)` gate → `not_owned` abort (never stops foreign/attached server); health gate = reported pid ≠ old pid + runtime id; failed re-point → `extension_register_failed` abort; `kill` awaited before any fallback spawn; `createSwitchQueue` per-target serialization; `spawnColdCandidate` (exits forwarded only after acceptance, with pid; identity check for overlay/local; port conflict flagged); `undoAttempt`; `clearBad` exported. `consumeExplicitUpdate` (planColdLaunch + watcher tick): new `request.pendingNonce` → `clearBad(pending)` once, recorded as `state.handledPendingNonce`. `peekColdLaunch(dir, exclude)` = READ-ONLY twin of `planColdLaunch` (same derivation; explicit-update consumption + exhausted-pending→bad applied in memory, returned as `effects`); `planColdLaunch` = peek + persist, so they cannot drift.
