# link-handling.ts — index

Pure helpers used by Electron shell. **`isSameOriginUrl(href, serverOrigin)`** — classifies URLs as same-origin vs external (handles absolute, relative, fragment-only, malformed inputs; see change: harden-external-link-handling, #13). **`decideWillNavigate(serverOrigin, currentUrl, targetUrl) → "allow" | "open-external" | "cancel"`** — OAuth-aware decision wrapper for `will-navigate` callback: while BrowserWindow shows non-dashboard origin (mid-OAuth) returns `"allow"` so provider login flows proceed; on dashboard composes `isSameOriginUrl` to decide between `"allow"` (same-origin) + `"open-external"` (external trap-guard); fail-closes to `"cancel"` on unparseable `serverOrigin` (see change: fix-oauth-blocked-by-external-link-guard). No Electron imports; 23 unit tests in `packages/electron/src/__tests__/link-handling.test.ts`. **`isAllowedExternalUrl(url)`** / **`openExternalIfAllowed(url, open)`** — `shell.openExternal` scheme allowlist (http/https/mailto only; opener gets parsed href). See change: harden-electron-renderer-boundary (VD4). `decideServerWindowNavigation(origin, target)` → `allow` \| `external` \| `drop` for server windows (separate from `decideWillNavigate`). See change: add-electron-server-windows (D8).
