# pick-node.ts — index

`pickNodeForServer(PickNodeInput): PickNodeResult` — pure, sync. Union `{kind:"bundled"|"system"|"execpath-fallback"|"unavailable"}`. Order: bundled `Resources/node/bin/node` (POSIX) / `Resources/node/node.exe` (Win) → `systemNode` (pre-resolved by `launch-source.ts` via `resolveServerRuntime`, bundled missing only) → `process.execPath` + `ELECTRON_RUN_AS_NODE=1` only when `embeddedNodeVersion` passes `isUsableNodeVersion` → `unavailable` with `reason` naming embedded version + `SERVER_ENGINES_RANGE`. `hasBundledNode(dir, platform)` lets caller skip resolution. Sole allowed `process.execPath` site (no-electron-execpath-spawn lint). See change: eliminate-electron-runtime-install, raise-node-floor-to-26.
