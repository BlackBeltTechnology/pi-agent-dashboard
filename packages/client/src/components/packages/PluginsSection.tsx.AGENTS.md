# PluginsSection.tsx — index

Settings ▸ Plugins activation list (the activation index). Renders every plugin (enabled or not) with display name, id, status pill, enable/disable toggle, missing-requirement chips + inline Install buttons (delegates to package-queue for pi-extension requires). Renders the restart-required banner from `usePluginToggle` (which owns the `/api/health.startedAt` comparison and resolves the boot id lazily at toggle time). Disabled rows carry a "not in Settings nav" note so their absence from the rail is explained where the user looks. Presentational internals come from `plugin-row-parts.tsx`; the toggle path from `usePluginToggle`. Settings are NEVER rendered inline — the cog navigates to `/settings/plugins/<id>` (`PluginSettingsPage.tsx`); the inline expander and `PluginSettingsHost.tsx` are gone. See change: add-plugin-activation-ui, plugin-settings-pages.
