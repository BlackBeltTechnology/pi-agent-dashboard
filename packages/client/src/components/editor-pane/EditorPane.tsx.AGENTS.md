## scope-anchor-editor-pane-controls

- Two chrome rows (D1, D2): pane bar `[Files] [tabs…] [+] ··· [⌄] [✕]` (`pane-bar`; Files `tree-toggle`, `aria-pressed={railVisible}`, label at every width; `⌄` `tab-search-toggle` disabled with no tab; `✕` `editor-pane-close`) + `DocumentBar` (`doc-bar`) about the active tab. Header path text, live/terminal/search/reload icons and the standalone `FileModeSwitcher` row removed.
- Narrow fold (D3): `useNarrow` `ResizeObserver` on the root; `< 640 px` folds Open/Reveal into `⋯`.
- Search is a rail view (D4): ephemeral `railView` + `searchMode` + `searchPrefill {query?, nonce}`; `railVisible = treeVisible || (hasFileSearch && railView==="search")`; Search never writes the persisted tree-visible key. Cmd-P / Cmd-Shift-F: same mode closes, other mode switches; no `preventDefault` when `hasFileSearch` is false. Rail container handles Escape only while Search shows; closing refocuses the viewer body. State resets on `sessionId` change.
- Closing (D5, D6): `closeTabAt` = single close (terminal silent kill, handler `guardTabClose`); `runBulkClose(paths)` closes popovers, `planBulkClose`, then one `closeTabs` or `BulkCloseConfirm`; `confirmBulk` re-plans against current state, re-shows the dialog when a new risk appeared, discard = `terminal.killTerminal` + `fh.discardInstance` per entry then one `closeTabs`. `paneOverlayOpen` makes Cmd/Ctrl-W inert.
- Reveals (D11): `revealFolder` / `showInTree` dispatch `expandTreeRoots`, set `railView="files"`, `setTreeVisible(true)`.
- Wires `NewTabMenu`, `TabSearchPopover`, `TabContextMenu`, `BulkCloseConfirm`, `DocumentBar`; reads `caps.platform` for the Reveal label. See change: scope-anchor-editor-pane-controls.
