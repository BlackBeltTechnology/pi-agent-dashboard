# DOX — packages/client/src/components/editor-pane/file-handlers

Plugin `editor-pane-file-handler` host: switcher, instance layer, core save/conflict policy. One row per source file. See change: add-editor-pane-file-handlers.

| File | Purpose |
|------|---------|
| `FileHandlerDialogs.tsx` | Renders head of store dialog queue: first-overwrite notice (Cancel/Save as copy/Overwrite), conflict (Reload hidden when gone, Save as copy, Overwrite anyway hidden when gone + warning, Cancel), leave-guard confirm, cap-blocked list with per-tab Discard. testids `file-handler-{first-overwrite,conflict,confirm,blocked}[-<action>]`. |
| `FileHandlerHost.tsx` | One mounted instance. `createHostApi({store,inst,ws})` → `snapshot`/`save`/`setDirty`; `FileHandlerHost` renders claim `Component` with `FileHandlerProps` (`context={pluginId}`) in `SlotErrorBoundary`+`CurrentPluginLayer`. Overwrite via `trackedFileWrite` (only when `ws.sessionId===inst.sessionId`); copy untracked. Token = sha1 of last snapshot/overwrite; 409 → conflict loop. Statuses: 413 too-large, 503 retryable busy, other → rejected. Concurrent save → busy. |
| `FileHandlerLayer.tsx` | Page-level layer mounted ONCE in `App` under `SplitWorkspaceProvider`. `position:fixed` frame per instance over `pane.anchor` rect (ResizeObserver + resize/scroll); hidden `display:none`, never unmounted. Evicted frame → "Resume" (`file-handler-resume`); live plugin disable (claims version) → clean closes, unsaved → overlay (`file-handler-disabled`, Re-enable → `/settings/plugins`, Discard); too-large → `file-handler-unavailable`; dialogs; copy toast with Open; `beforeunload` guard. Frame attrs `data-testid=file-handler-instance` `data-instance-key` `data-claim` `data-visible` `data-dirty`. |
| `FileModeSwitcher.tsx` | Toolbar above the body: `file-mode-preview` + `file-mode-<pluginId>/<claimId>` per claim; outside cwd → buttons disabled + `file-mode-outside`. Null when no claim matches. |
| `file-handler-io.ts` | `takeSnapshot` digest bracket (size>maxBytes → too-large before raw; 3 attempts; sha1(bytes)=sha1₂), `fetchDigest`, `postWriteBinary`, `classifyWrite`, `FileHandlerError{reason,gone}`. Reads via `fetchWithoutGrantPrompt`. |
| `file-handler-logic.ts` | Pure: `MAX_LIVE_HANDLERS=3`, `claimsForPath` (via shared `extOf`; order priority→plugin id→claim id), `normalizeRelPath`, `isUnderCwd`, `instanceKey`, `planMount` (fits/evict LRU clean/blocked; `keepAlive.max` lowers claim share), `isGuarded` (`"unknown"` = dirty). |
| `file-handler-store.ts` | Singleton `fileHandlerStore` (+`useFileHandlerStore`): instances, pane registration `{sessionId,anchor,activeKey,clearMode}`, dialog queue, copy notices. `activate`/`resume`/`remount`/`destroy`/`guard`/`ask`/`setDirty`; non-keepAlive clean instance closes when its tab is inactive; blocked mount → dialog, Cancel reverts tab via `clearMode`. |
| `use-file-handler-pane.tsx` | `EditorPane` glue hook `useFileHandlerPane`: resolves claims/selected mode/`handlerActive`, registers pane + activates instance (first run after session switch skipped), guarded `select` (mode switch), `closeTabGuarded`, `refreshHandler`. |
