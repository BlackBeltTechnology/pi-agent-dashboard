# NotifyRenderer.tsx — index

`NotifyRenderer` — renders `ctx.ui.notify(...)` chat row. Reads `message`/`level` defensively from `params.message` with `params.title` as the pre-split fallback. Empty message returns null. Uses `MarkdownContent`. Notify no longer rides the prompt envelope: canonical params are `params.message`/`params.level`; the `_promptBusComponent.props.*` read is dropped, `params.title` kept as the pre-split fallback. Re-toned onto the shared `InlineMessage` primitive: the `levelColors` map and its four `text-{blue,green,yellow,red}-400` literals are GONE — colour resolves from `--severity-*` tokens via `LEVEL_PRESENTATION` (level → severity + mdi icon + i18n label). `notifyMinLevel` makes `level` the input to a visibility filter, so it must survive without colour: accent bar + per-level DISTINCT icon + level word (WCAG 2.2 §1.4.1). Unrecognized level → `info`. See changes: split-notify-from-prompt-request, gate-notify-rows-by-level.
