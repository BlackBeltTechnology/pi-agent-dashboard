# ServerSelector.tsx — index

Server selector dropdown showing persisted known servers. Availability probing runs **only on dropdown open** (once per open, not on mount, not on timer, not while closed). Accepts `inFlightSwitchKey` to render spinner on entry being switched to. Unreachable entries `disabled`, rendered with `opacity-50` + `cursor-not-allowed`, clicks no-ops. Reachable clicks delegate to transactional staging-socket switch (see `server-switch.ts`). See change: safe-server-switch See change: distinguish-offline-from-network-denied — exports isLoopbackOrigin + buildServerEntries; localhost "Local" seed gated on loopback window.location.hostname (no phantom localhost row on remote origins); probe state four-valued available/unreachable/denied/cors-blocked; 403 network_not_allowed renders "Network not allowed" not "Unreachable". See change: stabilize-mdns-server-identity — probe state adds `name-not-resolved`; a browser transport failure asks the operator-only server probe (`probeKnownServer`): `reachable` → CORS-blocked hint (`data-cors-blocked`), `name-not-resolved` → "Name not found" (or "Moved to <addr>" + Update → `acceptKnownServerMove` when the list carries `movedTo`), anything else/`null` → "Unreachable". Address class no longer selects the state (`isLanHost` removed). Every non-available row `disabled` + `aria-disabled`. Probe URL via `formatHostPort`.
