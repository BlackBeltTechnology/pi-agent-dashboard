# OpenSpecBoardView.tsx — index

Full-page OpenSpec kanban board. Route `/folder/:encodedCwd/openspec`. Columns = groups + always-present Ungrouped. Draggable proposal cards (@dnd-kit): reassign group + reorder within group. Card = name + state pill + `OpenSpecStepper` + task progress bar + session rows + `New session`/`New worktree` actions. Session rows: status dot, name, age, `OpenSpecActivityBadge` phase chip, token/context/cost stats, per-session resume/fork/hide + `SessionOpenSpecActions` command menu, worktree marker + delta. Filter bar (text + state pills + session-status pills). New-proposal dialog (name/group/worktree). Per-column manage (`OpenSpecGroupManager`) + add-group. See change: redesign-openspec-board. Threads `onReplaceProposal` callback to SessionOpenSpecActions. See change: replace-proposal-dialog-with-race-handling. BoardSessionRow renders `.card-stripes-fx` overlay (running/unread/ask_user) via shared helpers; ProposalCard paints aggregate stripe via `deriveProposalCardState`; board auto-scrolls active row into view (`boardScrollRef` + `lastClickedRef` + `askUserFingerprint` useEffect, suppresses scroll on user click); rows gain `data-session-id` + `relative isolate`. See change: port-session-card-state-visuals-to-openspec-board.

Drop targeting: `collisionDetection={pointerWithin}` with NO `closestCorners` fallback — a null `over` must stay a real cancel, else a gutter release commits into a neighbouring column. `DropSlotProbe` is a headless child of `<DndContext>` (it MUST be inside: the parent sees `droppableRects.size === 0`, so resolving there lands every drop at index 0) using `useDndContext()` + `useDndMonitor().onDragMove` — NOT `onDragOver`, whose deps are `[overId]` and which never fires on a midpoint crossing within one droppable. `pointerY = activatorEvent.clientY + delta.y`; rects read via the scroll-live `rect.top`/`rect.bottom` getters, never the frozen `rect.rect`. `handleDragEnd` only COMMITS, gated on the end event's live `over` agreeing with `dropSlot` (stale-slot frame race); `onDragCancel` + a separate window `blur` handler clear `activeDrag`+`dropSlot` (dnd-kit binds pointercancel/resize/visibilitychange, not blur). `BoardColumn` keeps the body droppable (auto-scroll walks the over node's ANCESTORS) and adds a second `col-root:<k>` droppable on the root via an explicit merged ref, so header + outer padding accept drops; split into `BoardColumnHeader`/`BoardColumnBody`/`ColumnAppendRail`/`EdgeGlow` + `deriveColumnDropState`/`useScrollRoom`/`resolveMoveSlot`. `ColumnAppendRail` = drag-only `rail:<k>` droppable, sticky to the body's visible bottom edge, ≥44px; active state driven by the RESOLVED SLOT being last, not by pointer-over-rail. Vertical `SortableContext` uses an explicit no-op strategy (`strategy={undefined}` would fall back to `rectSortingStrategy` and still displace, breaking the rect-midpoint count). Test hooks are production DOM: `data-drop-target` (column root), `data-drop-slot` (body), `data-rail-active` (rail). See change: fix-openspec-board-drop-targeting.
