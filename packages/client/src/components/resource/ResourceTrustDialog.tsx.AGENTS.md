# ResourceTrustDialog.tsx — index

Project-trust dialog for a folder-scope resource toggle. Exports `ResourceTrustDialog({cwd,message,options,onChoose,onDismiss})`. Renders through `DialogPortal`; `data-testid` `resource-trust-dialog` / `resource-trust-message` / `resource-trust-option-<id>`. Options come from the server's `403 trustRequired` response (`trust` / `trust-parent` / `decline`); the client sends back only the option id. Esc and backdrop dismiss WITHOUT choosing — nothing written, neither settings nor trust. Wording deliberately mirrors pi's own trust prompt: pi's `getProjectTrustOptions` is not reachable through the package `exports` map, so the choices are reproduced here while the decision is persisted through pi's store. See change: project-scope-disable-global-resources.
