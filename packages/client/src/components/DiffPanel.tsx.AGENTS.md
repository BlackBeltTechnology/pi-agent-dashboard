# DiffPanel.tsx — index

Diff renderer for a selected file. Exports `DiffPanel`. Modes: `diff` (split/unified via `@git-diff-view/react` + `RichDiff`), `file` (full current content via `SyntaxHighlighter`, fetched from `/api/session-file`), and `preview` (changed regions of the current file: context+added in new-file line order, removed omitted, additions tinted; `buildPreviewLines` from `gitDiff`; disabled when no parseable hunks — non-git/summed/binary). Path A: change-derived `oldText`/`newText` (`buildChangeDiffTexts`). Path B: git aggregate hunks (`extractHunks`). Toolbar toggles view + diff mode. See change: collapse-diff-file-tree.
