# chat-selection-copy.ts — index

Pure `buildSelectionClipboardText(range, container)`: rebuilds clipboard text for a transcript `copy`. `Range.cloneContents()` → block-aware serialization (BLOCK_TAGS newline, `

`→\n) gives exactly the selected chars for partial-node selections. Capping renderers opt full text into copy via `COPY_TEXT_ATTR` (`data-copy-text`); a FULLY-contained capped element (`compareBoundaryPoints` on `selectNodeContents`) substitutes its full text (prefix-guarded); partially-selected capped elements keep the clipped text. Returns "" for collapsed. Consumed by ChatView's document `copy` listener; AgentToolRenderer PromptBlock sets the attr. See change: chat-copy-fidelity-intercept.

See change: keep-oversized-chat-selection (D7) — three-part serialization for a copy whose range extends beyond the transcript: `splitRangeAroundContainer(range, container)` → `{pre, mid, post}` Ranges (`null` for a collapsed range; empty parts are `null`), `buildOutsideClipboardText(range, scope)` (same serializer scoped to `document.body`, also skips `SCRIPT`/`STYLE`/`TEMPLATE`/`NOSCRIPT` and `[hidden]`/`[aria-hidden="true"]`; not byte-identical to native copy, e.g. ignores `user-select: none`), `assembleClipboardParts([pre, mid, post])` (drops empty parts, joins with one `\n`; the container is a block boundary). `buildSelectionClipboardText` gains an optional `skipNonRendered` flag used only by the outside parts.
