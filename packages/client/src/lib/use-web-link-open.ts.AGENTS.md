# use-web-link-open.ts — index

`useWebLinkOpen(context?: Pick<ToolContext,"sessionId">)` → `(e,href)` click handler shared by `MarkdownContent.a()` + `UrlLink` (renamed from `useLoopbackLinkOpen`). Plain primary-click only (modifier/middle → native). Loopback `isLoopbackUrl(href)` + `useOptionalSplitWorkspace()` present → `preventDefault` + `ctx.openLiveTarget(href)` in any context (as before). Other http(s) → `preventDefault` + `ctx.openUrlTarget(href,{opener:"operator-click"})` ONLY when `context.sessionId === ctx.sessionId` (the session's own pane transcript; other session/surface/none → no-op). Every other scheme and a null workspace no-op (native `target="_blank"`). UX router, not a trust boundary (the web-page renderer gates its probe on the `operator-click` opener). See change: open-loopback-links-in-split-viewer, rich-chat-links (D7).
