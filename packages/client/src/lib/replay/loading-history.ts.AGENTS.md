# loading-history.ts — index

Clears per-session loading flag + safety-net timer (idempotent). Two-stage net: `beginLoadingHistory` arms short `SUBSCRIBE_ACK_MS`; cold-hydration start marker + server heartbeats re-arm long `HYDRATE_CEILING_MS` (no-op unless timer armed). Used by App.tsx (timer callback) + useMessageHandler.ts (exit + re-arm edges). Adds `REPLAY_PILL_DELAY_MS=300` (render threshold for the replay-in-flight pill, NOT a safety net; unmeasured pending transfer-phase instrumentation). Helpers are flag-generic over `(setter, timersRef, id)` — reused verbatim for the second per-session flag `replayInFlight`, which clears on the TERMINAL replay batch instead of on first content.
