# replay-cache.ts — index

Durable per-session replay cache. IndexedDB. createReplayCache({factory,maxEntries,maxBytesPerSession,schemaVersion}). Entry {sessionId,schemaVersion,maxSeq,payload:CachedEvent[],lastAccess}. get purges schemaVersion mismatch. put enforces per-session byte cap + LRU evict by monotonic lastAccess stamp (Date.now ties bumped +1 for strict order). Singleton replayCache. Strategy A: reload delta-subscribes lastSeq=maxSeq. Miss/error → full replay. REPLAY_CACHE_SCHEMA_VERSION = 2 (v1 entries carry a cursor with no provenance; bump purges them once). See change: reduce-session-replay-traffic, fix-replay-cache-partial-payload-cursor.
Entries now SERVER-SCOPED. Entry gains `serverKey` (`host:port`). `get(sessionId, serverKey)` returns null on key mismatch — `sessionId` not unique across servers, so a collision could otherwise serve another server's history. `put(sessionId, value, serverKey)` stamps it. `delete(sessionId)` stays UNKEYED by design (schema purge, over-cap evict, poisoned-entry catch, `session_state_reset` have no current-server notion). New `deriveServerKey(wsUrl)` — `host:port`, substitutes scheme default port (`ws:`→80, `wss:`→443) so `ws://box/ws` and `ws://box:80/ws` cannot key differently; scheme excluded; unparseable input returned verbatim. Identifies by network LOCATION, not instance (reused port / repointed tunnel not distinguished — design D2). SCHEMA_VERSION bumped 2→3: v2 entries carry no server identity, are UNATTRIBUTABLE, purged once. See change: purge-replay-cache-on-reset-paths.
