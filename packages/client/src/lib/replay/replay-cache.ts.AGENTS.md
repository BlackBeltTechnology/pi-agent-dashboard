# replay-cache.ts — index

Durable per-session replay cache. IndexedDB. `createReplayCache({factory,maxEntries,maxBytesPerSession,schemaVersion})`. Entry `{sessionId,schemaVersion,serverKey,maxSeq,payload:CachedEvent[],lastAccess}`. Singleton `replayCache`. Strategy A: reload delta-subscribes `lastSeq=maxSeq`; miss/error → full replay. `put` enforces per-session byte cap + LRU evict by monotonic `lastAccess` stamp (Date.now ties bumped +1 for strict order). `REPLAY_CACHE_SCHEMA_VERSION = 3`; `get` purges on schemaVersion mismatch. See change: reduce-session-replay-traffic, fix-replay-cache-partial-payload-cursor.
Entries are SERVER-SCOPED. `get(sessionId, serverKey)` returns null on key mismatch — `sessionId` is not unique across servers, so a collision could otherwise serve another server's history; a foreign entry is a miss and is deliberately NOT deleted and NOT touched (valuable to the server that wrote it, but must not hold an LRU slot warm). `put(sessionId, value, serverKey)` stamps it. `delete(sessionId)` stays UNKEYED by design (schema purge, over-cap evict, poisoned-entry catch, `session_state_reset` have no current-server notion). The schema check runs BEFORE the key check — a pre-v3 entry has no `serverKey`, so key-first ordering would call it foreign, decline to delete, and strand an unattributable zombie. Store keyPath is `sessionId` ALONE, so a colliding id written on server B evicts A's entry: a hit-rate cost on switch-back, never a wrong-history cost. `deriveServerKey(wsUrl)` → `host:port`, substituting the scheme default port (`ws:`→80, `wss:`→443) so `ws://box/ws` and `ws://box:80/ws` cannot key differently; `secure` is read from the PARSED `u.protocol`, not a case-sensitive prefix test (`WSS://box/ws` used to yield `box:80`); scheme itself excluded from the key; unparseable input returned verbatim. Identifies by network LOCATION, not instance (reused port / repointed tunnel not distinguished — design D2). v2→v3 bump: v2 entries carry no server identity, are UNATTRIBUTABLE, purged once. See change: purge-replay-cache-on-reset-paths.
