## shrink-client-entry-lazy-islands

`zh-CN`/`hu` core catalogs load on demand: `dictionaries` start `{en,"zh-CN":{},hu:{}}`; `loadCatalog(lang)` (memoized per language, `en` no-op, never rejects — failure logs, drops the memo, English fallback) merges the catalog via `Object.assign`. `registerPluginCatalog` writes into the live dict at any time; plugin keys are `plugin.<id>.*` so load/register order is irrelevant (no buffer needed). `I18nProvider.setLanguage` loads then applies; latest request wins. `detectInitialLanguage` exported; `main.tsx` awaits `loadCatalog(initial)` before first render. `translationsOf(key)` reads static generated `RESERVED_LABEL_TRANSLATIONS` ([zh-CN, hu] per built-in settings label key); `node scripts/i18n-parity.mjs --fix` regenerates, plain run fails on drift. See change: shrink-client-entry-lazy-islands.
