# sidebar-dnd.ts — index

Shared drag-and-drop helpers for sidebar `SessionList`. Exports `compatibleClosestCenter` (type-aware collision detection for nested sortable contexts), `dropIndicatorProps`, `resolveWorkspaceReorder`, `resolveWorkspaceFolderReorder` (pure reorder resolvers, null on no-op/cross-workspace/missing). See change: workspace-directory-drag-reorder.
 `sameTypeClosestCenter` → `compatibleClosestCenter`, driven by exported `DRAG_TARGETS` matrix (active `type` → allowed droppable `type`s). Typeless active → `closestCenter` over all; typed-but-unmatrixed active → same-type filter (never weaker than the shipped wall). `pinned-group` excludes `pinned-tier` (already ejected). Adds `resolveFolderMove` (pure, keyed on the (active, over) PAIR) → `{kind:"reorder-pinned"} | {kind:"reorder-folders",wsId} | {kind:"move",toWorkspaceId,index?} | null`; null on own slot, own workspace's header, already-a-member, unknown `over.wsId`. Header drop = append (no `index`); folder-slot drop = `index` computed against the TARGET's array. Adds `SPRING_LOAD_DWELL_MS = 600`, `PINNED_TIER_MIN_HEIGHT_PX = 64`. See change: drag-folders-across-workspaces.
