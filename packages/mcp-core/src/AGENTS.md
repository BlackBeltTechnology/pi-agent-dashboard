# DOX — packages/mcp-core/src

Host-free MCP config library (not a plugin): pi-rule mirror, two-layer reader, live-state
reader, config writer, effective-view reader, and the `mcp-client.config` service. Imports NO
React and NO dashboard runtime — the dashboard server, mcp-client / mcp-server plugins and the
hostless `apple-tools` installer import it directly. Moved from `mcp-client-plugin/src/core`.
See change: decouple-plugins-from-core, extract-mcp-client-plugin, migrate-mcp-to-pi-builtin.
