# DOX — packages/video-production/src

Files in this directory. One row per source file.

| File | Purpose |
|------|---------|
| `env.ts` | Veo key resolution. `KEY_NAMES` (`VEO_API_KEY`,`GEMINI_API_KEY`,`GOOGLE_API_KEY`). `resolveVeoKey({cliKey,baseDir,env,packageDir})` precedence flag→env→project `.env`→package `.env`, returns `{key,source}`. Reuses `parseEnvFile`/`envSearchDirs` from the nano-banana package. |
| `export.ts` | pi-video-gen spec export (file-format coupling, verified 0.1.18). `exportRender`→`<out>/<job>/render-input.json` (film fields + per-shot structured `prompt`, int `durationSec`, cwd-relative `firstFramePath`, SEAMLESS→`lastFramePath`=next sketch); `exportTimeline`→`timeline-input.json` (`video`/`image` abs paths, `seg-NN`, xfade, no voice/bgm/subtitles). Pure `jobIdFor`/`buildRenderSpec`/`buildTimelineSpec`. `SAFE_ID`. Frame preflight (≤20 MiB, PNG/JPEG/WebP magic, inside cwd, no symlink); media preflight. Never reuses a job dir; re-billing guard registry `<base>/.pi-veo/exports.json` `{renders}` fails closed, `--new-job` override. `formatExportReport`. See change: add-pi-video-gen-export |
| `inspect.ts` | Dry-run inspector (port of `parse_shots.py`). `inspectPackage({target,shots})` → `InspectReport` (per-shot seed/aspect/res/refs, key state, `problems`=shots missing prompt). Sidecar-enabled packages add `sidecars {enabled,timeline,problems}` + per-shot `sidecar` ok/missing/invalid; `formatReport` adds `Sidecars:` block before terminal line. No film.json → report unchanged. No SDK/key needed. See change: add-pi-video-gen-export |
| `mux.ts` | Final local mix. `runMux({target,picture,out,force,burn,runner})`: picture ambient + VO (`adelay` offset) + music → `amix normalize=0,alimiter,apad`, `-t` picture dur, `-c:v copy` unless burn; soft `mov_text` captions default. Pure `buildMuxArgs`. Injectable `Runner` (default `execFile`, no shell). Burn: SRT copied to temp cwd as `captions.srt`. VO fit check via ffprobe; temp output + rename; stderr tail 10 lines. Default out `<base>/master/master.mp4`. See change: add-pi-video-gen-export |
| `package.ts` | Layout resolver (port of `resolve_package`/`load_shots`). `resolvePackage(target)` accepts project / video_production / shots dir → `{shotsDir,baseDir}`. `loadShots(target,names?)` parses + filters by short/full id. `expandHome`. |
| `render.ts` | Veo renderer (port of `veo_render.py`). `renderShots(opts)` idempotent (skip existing mp4 unless force), sequential+`--chain` (ffmpeg last-frame handoff) or `--parallel N`, retry-without-refs, jsonl log. `buildRequest` (config+first-frame image), `planRender`, `loadImage`, `extractLastFrame`. Injectable `VeoClient` (`createGenAIClient` wraps `@google/genai`) for testability. |
| `shots.ts` | Shot parsing (port of shot parser). `Shot` type, `MODEL_ALIASES` (standard/fast→veo-3.1 ids), `parseShotFile` (fenced Full Veo/Negative blocks, seed/aspect/resolution/enhance regex, reference + first-frame image resolution, SEAMLESS-to→`seamlessNext`), `resolveImage`, `shotShort`. |
| `sidecars.ts` | Sidecar load+validate. `loadSidecars(target)` → `{enabled,baseDir,shotNames,film,shots,shotState,timeline,problems:{scope,message}[]}`; enabled iff `film.json`. Scopes film/shot/timeline/audio. Timeline bounds mirror pi-video-gen 0.1.18 (`TRANSITION_STYLES`, `OVERLAY_POSITIONS`, `OUTPUT_CODECS`). `containedFile` realpath containment, rejects symlink/escape/missing. See change: add-pi-video-gen-export |
| `storyboard.ts` | Storyboard generator (port of `gen_storyboard.py`). `generateStoryboard({target,only,force,workers})` reads `storyboard/sketch_prompts.json`, generates one PNG/key via nano-banana `batchGenerate`. |
