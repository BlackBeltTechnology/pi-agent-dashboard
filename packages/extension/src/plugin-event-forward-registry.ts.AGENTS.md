# plugin-event-forward-registry.ts — index

Plugin-declared bus forwarding. `PluginForwardRegistry(bus, deps{send(eventType,data,pluginId),isSessionReady,isActive,isConnected,isCoreChannel?})`: `attach()` listens on `dashboard:register-event-forward` then emits `dashboard:bridge-ready`; `setOwnership(table)` applies the server `plugin_ownership` table and releases held declarations (declarations are HELD until it arrives); `declare`, `flush`, `declaredChannels`, `stats`, `dispose`. Refuses a declaration forwarding as a type another plugin owns by manifest (counted in `rejected`); core/protocol types stay reserved; stamps `pluginId` on every forward. Optional per-channel `group` (latest) + declaration `maxKeys` (≤256, clamped+counted). First owner wins on channel/`as` conflicts. See change: add-plugin-bridge-contributions, move-subagents-to-plugin.
