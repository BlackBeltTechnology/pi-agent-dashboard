# provider-model-cache.ts — index

Per-provider cache of the last successful `/v1/models` discovery, read at bridge activation so a custom-provider `--model` resolves at pi startup. File `~/.pi/dashboard/custom-provider-models/<encodeURIComponent name>.json`, mode 0600, `<file>.<pid>.tmp`+rename. Exports `readProviderModelCache` (usable = version 1 + same `baseUrl` + same `keyFingerprint` + non-empty models, else `null`; never throws), `recordProviderModelCache` (writes only a non-empty result; no-op on null/empty; never throws), `keyFingerprint` (16-hex SHA-256 over `name\0resolvedKey`; `$ENV` resolved, literal/`!command` hashed raw), `providerModelCacheDir`, `providerModelCachePath`, `CachedModel`. Holds NO credentials. See change: register-custom-provider-models-at-activation (D3).
