# vcs-info.ts — index

Gathers git branch/remote/PR/worktree info via shared platform git helpers. Exports `GitInfo`, `detectBranch`, `detectRemoteUrl`, `detectPrNumber`, `detectWorktree`, `detectIsGitRepo`, `gatherGitInfo`. `detectWorktree` delegates to shared `git.checkoutRoots`; emits identity only when `isLinkedWorktree` AND a `mainCheckout` resolves AND that path carries no `.git` SEGMENT (`hasGitPathSegment`) — the consumer-side check the resolver deliberately does not make. Submodule / `--separate-git-dir` / bare → undefined; worktree-of-submodule → the submodule checkout; worktree-of-bare → undefined. `mainPath` never contains `.git`. `name` = `basename(roots.thisCheckout ?? cwd)` — the worktree ROOT, not the request cwd (a session in a SUBDIR would otherwise label the card with the subdir name). Real-repo wiring gate: `__tests__/vcs-info-worktree-wiring.test.ts` (unmocked — an injected verdict cannot catch a mis-wired probe). See change: add-git-checkout-root-resolver. `detectIsGitRepo` returns tri-state `boolean\|undefined` from `git.isGitRepo()` Result: ok→value, exit-128→false, else→undefined (never false on inconclusive probe); attached to `session_register` (session-sync.ts, bridge.ts). Builds links via `buildGitLinks`. Returns undefined if not a repo. Exports `gatherGitStatus(cwd)` → `GitStatus\|undefined` via shared `git.gitStatusV2` (`git status --porcelain=v2 --branch`). See changes: gate-session-worktree-button-on-git, add-session-uncommitted-indicator-and-commit.
