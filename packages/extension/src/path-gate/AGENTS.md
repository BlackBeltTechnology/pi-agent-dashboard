# DOX — packages/extension/src/path-gate

Agent path gate: asks the operator before pi's `read`/`write`/`edit` leave the session's roots. One row per source file. Approval control, not a sandbox (`bash`/custom tools uncovered). See change: ask-agent-file-access-in-chat.

| File | Purpose |

| `decide.ts` | Pure `decidePathAccess` → `in-root` \| `ask`. Component-wise containment via shared `isPathWithinRoots`/`isWithinRoot` (`tool-path-resolve.ts`; never string prefix, NFC) over workspace / read-only / read+write / grant roots; exact match first, case fold only after the volume probe says the volume folds (probe-free hot path). Ask carries `sensitive`, `subject` (the target itself when a directory, else its containing dir; never an ancestor), `grantable`, lexical `suppressionKey`. `buildOptions`: Always allow only for grantable + store match, else note. |
