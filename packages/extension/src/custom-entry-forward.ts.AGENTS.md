# custom-entry-forward.ts — index

Pure mappers for the bridge's custom-content forwarding: `toCustomEntryForward(entry, hidden?)` (null for non-custom/empty customType or a plugin-declared type in `hidden`) and `toCustomMessageForward({customType,content,display,details,entryId}, hidden?)` (null for `display === false` exact, or a declared type). `hidden` = the registry's declared `replayEntryTypes`; core names no plugin type. See change: update-flows-plugin. Driven by `wrapCustomPersistenceForCtx` in bridge.ts. Payload types carry optional `groupId` — server-stamped, never set extension-side. See changes: render-inline-reasoning-and-custom-entries, add-custom-event-group-filters.
