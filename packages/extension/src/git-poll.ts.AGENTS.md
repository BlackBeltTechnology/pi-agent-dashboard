# git-poll.ts — index

Exports `runGitPollTick(deps): Promise<void>`, `createGitPollState()`, `GitPollDeps`, `GitPollState`. Shared poll-tick body for the session-start + session-change timers so they cannot drift. Inactive → no-op. cwd present → `tickGit(cwd)` (git-tracker tick: cheap checks + one slow-lane probe REQUEST; rejection logged once, never blocks the rest) + `sendCwdMissingIfChanged`. cwd absent → skip git/cwd, still name + model every active tick. pi version re-read on ticks 1, 11, 21, …; a failed read (`sendPiVersionIfChanged() === false`) retries next tick; cadence state in `deps.state`. See change: fix-stale-ctx-cwd-crash, restore-pi-version-skew-surface, optimize-polling-hot-paths.
