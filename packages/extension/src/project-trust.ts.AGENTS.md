`project_trust` auto-decision (pure gate + defensive cwd read). `decideProjectTrust({dashboardSpawned,isHeadless,eventCwd,activationCwd})` → `"trust"` ONLY when all hold (dashboard-spawned AND headless AND `eventCwd===activationCwd`); every other case (incl. `eventCwd` undefined) → `"defer"` (deny-by-default). `readEventCwd(event,ctx)` reads `event.cwd` then `ctx.cwd` inside try/catch (stale/replaced ctx throw → undefined → defer); never a cached ctx. Bridge registers a `project_trust` handler at activation returning `{trusted:"yes",remember:false}` (per-run) / `{trusted:"undecided"}`; captures `activationCwd` at module scope (event fires pre-`session_start`, during resource-loader reload). `project_trust` bridge decision, snapshot-only (no server round trip): `decideBridgeProjectTrust(input, deps)` → yes/undecided + reason code. Order: unreadable store → recorded pi entry → activation rule (canonical cwd, not forbidden) → mirror rule (`coverSnapshot`; dashboard-spawned headless, else only `coverInteractive`). Per-event reads, no caches. `readEventCwd`. See change: mirror-dashboard-trust-to-pi.

`decideBridgeProjectTrust` is async: snapshot rule, then live query only on a snapshot miss when `enabled ∧ liveQuery ∧ session allowed ∧ !denied ∧ (liveCount>0 ∨ remote)`. One deadline `liveQueryTimeoutMs` (race + per-call AbortController) covers request + folder proof. Local proof = recorded identity; remote proof = recomputed digest. Reason codes `live-timeout|unreachable|refused|unsupported|rate-limited|not-covered|error`, `identity-weak`. See change: mirror-dashboard-trust-live-remote.
