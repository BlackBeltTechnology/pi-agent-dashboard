# ask-user-tool.ts — index

Register `ask_user` pi tool at `session_start` (avoids static-name conflict). Exports `registerAskUserTool`. Methods `confirm`/`select`/`multiselect`/`input`/`batch`; flat root JSON-Schema object keeps OpenAI strict-mode happy; per-method validation enforced at runtime in `execute`. CWD-INDEPENDENT: pure `ctx.ui` interaction — resolves no filesystem path, spawns no process, never reads `ctx.cwd` (starts-with-cwd audit result, change: update-pi-core-0-85-adopt-apis task 5.1).

Inline Other: schema `allowOther` (optional boolean, top-level + sub-question; description dashboard-only, default true). `prepareArguments`/`normalizeSubQuestion` rescue via `rescueAllowOther` (strings "true"/"false" coerced, other non-booleans dropped, `allowCustom` aliases then deleted; never appends a literal option). Dispatch: single select/multiselect pass `allowOther:true` in opts unless `allowOther===false`; batch map sets `allowOther:true` per select/multiselect sub when `(sq.allowOther ?? params.allowOther) !== false`. Result text: `customValues(answer, options)` drives note line `Custom answer (not one of the options).` / `Custom values (not among the options): [...].` before the unchanged final `User responded: <json>` line; batch select/multiselect lines get ` (custom)`. `details` unchanged.
