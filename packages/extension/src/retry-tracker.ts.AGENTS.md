# retry-tracker.ts — index

Pure `RetryTracker` observes pi events and synthesizes `auto_retry_start` / `auto_retry_waiting` / `auto_retry_end`; no transcript JSON and no provider-error regex. Pi ExtensionAPI hides native retry events from extensions.

State model: assistant `message_end(error)` opens/refreshes chain. Error `agent_end` advances attempt, arms next `agent_start`, emits waiting while within configured budget. Armed `agent_start` emits in-flight start. First assistant completion whose stop is neither `error` nor `aborted` closes immediately with success, including pi-owned continuation with no user message. `agent_settled` closes unresolved native chains with retained disposition/error. Missing assistant disposition never implies success.

Abort installs per-session cancellation tombstone before pi abort runs. Delayed start/message/end/settle events cannot reopen chain. Observed user `message_start` calls `noteExplicitRun`, clearing cancelled or stale floor chain.

Settings injected read-only: `{enabled,maxRetries,baseDelayMs,maxAgentDelayMs}`. Delay = pi's capped curve `min(baseDelayMs * 2^max(0,attempt-1), maxAgentDelayMs ?? 60000)` (unsafe product saturates to `MAX_SAFE_INTEGER`). Source: pi-ai `retryDelayMs` once `installPiAiDelayFn(tracker, importer?)` resolves it (fire-and-forget, rejection swallowed); else exported mirror `cappedDelay(policy, attempt)`. `delayFor` guard: base `<=0` or attempt `<1` → 0 without calling fn; fn throw / non-number / non-finite → `cappedDelay`; final non-finite or negative → 0 (elapsed-only). Parity vs pi-ai enforced by `__tests__/retry-delay-parity.test.ts`. Exports `RetryTracker`, `SyntheticRetryEvent`, `ObservedAssistantMessage`, `RetrySettings`, `RetryDelayPolicy`, `RetryDelayFn`, `cappedDelay`, `installPiAiDelayFn`. API: `setDelayFn`, `observeAgentStart`, `observeMessageEnd`, `observeAgentEnd`, `observeAgentSettled`, `noteAbort`, `noteExplicitRun`, `isRetrying`. See changes: retry-forever-with-stop-control, fix-retry-error-lifecycle, update-pi-core-0-85-adopt-apis (removed `isAwaitingRetry` with the floor-pi reconcile path), fix-retry-delay-cap (capped delay = pi's real sleep).
