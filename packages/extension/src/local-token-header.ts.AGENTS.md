# local-token-header.ts — index

Bridge side of D6: `readLocalToken(env?)` + `localCredentialPlan(endpoint, deps?)` → `DialPlan` for a CLEARTEXT LOOPBACK TCP dial only (undefined for `ws+unix:`, remote, `wss:`, or no token and no marker; no pre-connect then). It pre-connects TCP itself (`net.connect({host,port})`, injectable `connect`), binds a fresh `X-Pi-Local-Proof` to `canonicalBinding(socket.remoteAddress, socket.remotePort)`, and hands the socket to `ws` via `createConnection`; the raw token is never sent. `markerEnforces(marker, endpoint)`: empty ⇒ unmarked; parsed marker enforces only on the same endpoint (host case-insensitive literal, port after default); an unparsable non-empty marker enforces on every loopback dial. A marked dial adds `verifyUpgrade` (counter-proof from `X-Pi-Local-Proof-Server`, causes `server-proof-missing`/`server-proof-invalid`); no token + marked ⇒ fails closed. Wired as `planDial` in `bridge.ts`. See change: add-pi-gateway-transport-identity (task 5.3); loopback-credential-proof (D1, D6, D7).
