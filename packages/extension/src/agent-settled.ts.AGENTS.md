# agent-settled.ts — index

Bridge `agent_settled` normalization helpers. `nativeAgentSettledSupported(piVersion)` detects pi ≥ 0.80.4. `settleFollowUp(eventType,nativeSupported,ts)` creates floor-pi compatibility settles after `agent_end`. `markFloorSettle(event,false)` adds `data.retryPending:true`; client preserves retry/cancellation state. `floorRetryReconcileDelay(delayMs)` returns finite positive observed delay + 1 s grace, with 2 s fallback for unknown, non-positive, `NaN`, or infinite input. `synthesizeAgentSettledEvent(ts)` creates terminal payload-less settle. Bridge terminalizes floor errors only when no waiting signal exists or the expected armed attempt misses its `agent_start` deadline. Exports `NATIVE_AGENT_SETTLED_FLOOR`, `FLOOR_RETRY_UNKNOWN_DELAY_MS`, `FLOOR_RETRY_GRACE_MS`. See changes: adopt-pi-074-080-features, fix-retry-error-lifecycle.
