# browser/references/dashboard-relay.md — index

AUTHORED (not vendored). Preferred login-state recipe when the pi session runs on the dashboard host. Primary: `browser_connect {target?}` → result table (`dedicated`/`profile` → `agent-browser connect <cdpUrl>`; `headless` for a login task = stop; `unavailable` → `ask_user` options or stop). Dedicated profile: login wall → `POST /api/browser/dedicated/open {url}` (hidden tab, https only) + `ask_user`, then reload own tab; `browser_await_human` only for Chrome profiles and non-sign-in steps; password-manager detach diagnosed from `GET /api/browser/audit` (`closed:`/`extension:`) → suggest dedicated; same-user limit; agent NEVER reads/copies/launches a browser on `~/.pi/dashboard/agent-chrome` nor reads `agent-chrome-downloads` unless the task names a file; `browser_connect` never uses Panerelay. REST fallback (no `browser_connect`): `POST /api/browser/dedicated/connect`, else the legacy flow: `GET /api/browser/status` → `GET /api/browser/profiles` → `POST /api/browser/connect {profileDirectory}` → `agent-browser connect <cdpUrl>` → `web.md` workflow → `POST /api/browser/disconnect?instanceId=`. Branch table on 404 / `enabled:false` / `canOpenChrome:false` / 409 `not-installed` / 409 `busy` / 503 / 504 (token mismatch and no-allow are indistinguishable → one 504). Policy denials are LOUD: CDP error `-32000` `Denied by dashboard relay policy: <method>` (cookie verbs + `file:`/`javascript:`/`vbscript:`/`data:`/`blob:` and `allowedDomains` fence); `Browser.setDownloadBehavior` is ack-and-drop (`{}`, never forwarded, audit `dropped`). Documents the pi tools `browser_show_in_pane {instanceId, tabId?}` (5 s rate limit; errors `disabled`/`unknown-instance`/`unknown-tab`/`no-tab`/`rate-limited`) and `browser_await_human {instanceId, reason}` (blocks on a confirm the pane's Done answers; `done`/`cancelled`, `no-ui`). See change: add-browser-editor-pane-tab — report, never retry. One tab group per instance; one CDP client per instance (second closed `Another CDP client already connected`); DevTools takes a tab (`Target detached: devtools`); loopback-only endpoints. NEVER fall back to the bundled browser for a login-state task. Supersedes `own-browser.md` (legacy) on the dashboard host. See change: add-dedicated-agent-browser.
