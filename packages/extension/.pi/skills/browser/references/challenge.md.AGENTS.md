# browser/references/challenge.md — index

AUTHORED (not vendored). Pause/resume discipline for interactive anti-bot challenges (Cloudflare Turnstile, hCaptcha, reCAPTCHA, browser-check interstitial). Test = content withheld until a human acts; signature text on a page still serving content is NOT a challenge. Check snapshot text + `get url` + `get title` + Bash `agent-browser eval` on `iframe[src]` — a snapshot inlines iframe content, not its host. Pause = stop driving, keep the same `--session`/`--profile`/CDP target, report URL + kind + the driven session name (never a bare `agent-browser session`, which prints the env/default name). Takes precedence over recipe troubleshooting (`own-browser.md` fresh-`--session` row, `web.md` `close --all`). Completion branches on route: visible browser → user completes there; bundled headless + user at the machine → session-scoped `close` (never `--all`) then relaunch original flags verbatim + `--headed` on the challenged URL (empty cookies unless `--restore`/`--profile`/`--state`); no display → stop + offer relay/desktop host, no Xvfb. Reappearing challenge → stop, no retry loop. Never-list: solvers, token/clearance-cookie injection, cookie copying, proxy rotation, UA/header/`set device` changes, `--args --disable-blink-features=AutomationControlled`, stealth JS. See change: add-browser-challenge-pause.
