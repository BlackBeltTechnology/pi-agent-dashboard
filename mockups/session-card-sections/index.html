Discoverable path (no settings trip)

  1. Hover / focus a section → a ⋯ appears in its legend capsule.
  2. Menu: Hide in this folder · Hide everywhere · Section settings… (opens view A).
  3. Undo toast (6 s). Every card in the folder updates at once — it's folder state, not card state.
  4. A quiet footer "2 sections hidden · show" keeps hidden stuff recoverable from the card itself. It opens view A pre-scrolled.

Why a footer, not nothing

  • Without it, a teammate / future-you sees "no GIT section" and assumes a bug.
  • Footer renders only if a hidden section would have had content — no permanent noise.
  • Global pref can turn the footer off for power users.

Safety valve

  • PROCESS hidden + a background process running → the warning collapses into the footer as ⚠ 1 bg process instead of vanishing. Hiding must never hide a runaway process.

Resolution order

built-in default (all on) → global → folder override → auto-hide when empty

Folder settings store only the diff (sparse). Changing a global default flows to every folder that hasn't overridden that section — mirrors how displayPrefs + session override already merge.

Per-row "N folders override"

Each global row shows how many folders diverge, so flipping a global doesn't silently fail to take effect where you expect.

Not a session-level setting

Deliberately no per-session layer: cards in one folder should look alike (scan-ability), and it avoids a third state to reason about.
