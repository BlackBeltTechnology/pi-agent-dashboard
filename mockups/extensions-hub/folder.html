What this folder view answers

Today the folder Packages page shows the browser for folder installs. Its recommended panel repeats global install state, and nothing says what a session started here will actually load. The answer is spread over five Resources pages.
Here, a summary strip gives the answer (Global + added here − turned off here). Each add-on appears once, labelled with its scope. The per-folder off switch (a project-scope exclusion; pi enforces it) is on the row. Loose .pi/ files are counted. Dashboard plugins are explained as always global.
