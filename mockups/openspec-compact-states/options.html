What gets cut (all options)

  • Explore node + button when attached — always disabled/done there; pure noise.
  • State pill — duplicates the rail; state = rail + primary action.
  • Tasks + Apply merge into one "Implement" segment — today both go orange at once (two "current" nodes).
  • Disabled Archive button — the Archive node already says "not yet".
  • Exactly one primary action by state: Continue → Apply → Archive. FF, Verify, Archive anyway, Detach → ⋯.

What must survive

  • Click P/D/S → artifact preview; click tasks segment → TasksPopover.
  • Label via title + aria-label (letters alone fail 1.3.1 otherwise).
  • Color is never the only cue: ✓ vs letter vs fill-width.
  • Streaming → primary disabled with tooltip (unchanged gating).
  • Compact variant on Board keeps working (same derive fn).

Trade-offs

  • A: closest to today's mental model, 60% shorter, 16px nodes are ok hit-targets with padding.
  • B: densest; loses artifact detail once implementing (chips swap to bar). Good as a "collapsed" mode.
  • C: clearest progress read, but 6px segments are poor click targets → needs label row as hit area.
  • Hybrid: A default, B for non-selected / collapsed cards.
